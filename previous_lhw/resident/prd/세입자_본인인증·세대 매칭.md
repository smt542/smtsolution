## 1. 목적

카카오 로그인 직후, **카카오 계정의 전화번호로 관리주체가 등록한 세대를 자동 조회·매칭**하는 진행(인터스티셜) 화면. 사용자 입력 없이 진행되며, 결과에 따라 확인(`resident-verify`) 또는 매칭 실패(`resident-nomatch`)로 자동 분기한다.

---

## 2. 권한

| 사용자 | 접근 |
|---|---|
| resident (미매칭 사용자) | O — 자동 진행(입력·조작 없음) |

- 세대 매칭은 **관리주체(staff)가 등록한 입주자 연락처**를 신뢰 소스로 한다. 세입자는 자료를 수정하지 않는다.

---

## 3. UI

### 3.0 진행 메시지 + 단계 표시
- **기능**: 인증·매칭 진행 상황을 단계로 표시.
- **규칙**:
  - 점 3개(단계 인디케이터)로 **3단계 자동 진행**(각 단계 약 0.9초):
    1. **"카카오 계정으로 확인 중"** / 잠시만 기다려 주세요
    2. **"세대 정보를 찾고 있어요"** / 연락처로 등록된 세대를 조회해요
    3. **"거의 다 됐어요"** / 확인 화면으로 이동합니다
  - **사용자 액션 없음**(자동 진행).
  - **매칭 규칙**: **카카오 계정 전화번호 ↔ 관리주체가 등록한 입주자 연락처**([_data-dictionary.md](../../_data-dictionary.md) C2) 대조로 세대를 찾는다.
  - **본인인증 수단**: 카카오 계정(이름·전화번호)만 신뢰 — **별도 휴대폰 본인인증(PASS/SMS) 없음**.
  - **1인 1세대 전제** — 한 연락처가 여러 세대에 매칭되는 상황은 없다고 본다(다중 매칭 분기 없음).

### 3.1 완료 후 자동 분기
- **기능**: 매칭 결과에 따라 다음 화면으로 이동.
- **규칙**:
  - **매칭 성공** → `resident-verify`(세대 확인).
  - **매칭 실패**(등록된 세대 없음) → `resident-nomatch`.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 진행 중 | 진입 | 3단계 순차 애니메이션 |
| 성공 | 세대 매칭됨 | `resident-verify`로 이동 |
| 실패 | 매칭 세대 없음 | `resident-nomatch`로 이동 |
| 에러 | 조회 실패(서버) | 재시도 안내(공통 표준, [_service-policy.md](../../_service-policy.md) 6절) |
