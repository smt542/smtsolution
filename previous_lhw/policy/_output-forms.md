# 주택관리ERP — 출력물 / 서식 정의 (Output Forms)

> 고지서·검침대장·명세서·영수증·정산내역서·청구서 등 **출력물의 종류·구성·공통 규칙**을 정의한다. 여러 화면이 출력물을 생성하므로 공통으로 관리한다.
> 상위 참조: [_service-policy.md](_service-policy.md) · 필드 [_data-dictionary.md](_data-dictionary.md) · 계산 [_calculation-rules.md](_calculation-rules.md)

## 0. 공통 출력 규칙

- **회사명 워터마크**: 모든 출력물(입주자정보·관리비부과내역서·미납대장·고지서 등)에 회사명 워터마크(기능정의서 I-6, D-7).
- **QR 코드**: 종이 고지서에 QR 인쇄 — **카카오(스마트) 고지서 신청 세대** 대상(D-7). QR → resident 관리비 상세 guest 링크([_notification-policy.md](_notification-policy.md) 6절).
- **출력 방식**: 인쇄(print) 또는 이미지(PNG) 다운로드. 프로토타입은 localStorage 데이터 기반.
- **자동이체 세대 표시**: 자동이체 세대의 고지서·카톡 고지서에 자동이체 표시(D-8).
- **그룹 출력**: 납기일·출금신청일이 다른 그룹(자동이체 2그룹 등)은 그룹별로 구분 출력(D-1).

## 1. 고지서 (bill-publish)

| 형식 | 내용·규칙 |
|------|-----------|
| **지로 고지서** | 현행 지로 서식 유지. QR·회사명 워터마크·자동이체 표시 자동 포함 |
| **팩스 고지서** | 건물주·관계처 팩스 발송(발신 팩스번호 지정) |

> bill-publish 화면 출력에서 **A4 고지서·카톡 고지서 발송은 제거됨**(현재 발송은 팩스만). 카카오(스마트) 고지서 신청·수신은 resident 앱 기능([_notification-policy.md](_notification-policy.md) 6절).

**공통 고지서 요소**: 고객 안내사항(setup 등록, 최대 250자), 연체료 합산 구분 표시, 수도단가·관리비 기간 출력 선택, 증감량 표시 선택.
**부속 서류**: 조정명세서(전월 대비 조정 내역, 건물별), 자동이체 세대 출력(자동이체 세대 목록·청구금액). 출력기준 연·월 선택.

## 2. 검침대장 (utility-electric/water/gas)

`년/월분, 주소·빌라명, 키번호, 수도/전기 정보(공동모), 호별 지침·사용량·금액, 소계`
- 건물 다중 선택 + 전체선택 후 인쇄. 코드·건물명·주소 검색.
- 계량기 없는 호실: "계량기없음(N톤 고정)" 적요·고정 사용량 표기.

## 3. 수납 명세서 / 영수증 (receipt-management, moving-settlement)

| 출력물 | 구성 |
|--------|------|
| **호실 명세서** | 년월/수납일, 당월계·연체료·수납액, 전기·수도·가스 금액, 금월/전월/량, 단가. 표시옵션(전기/수도/가스 표시, 전체/미납만) |
| **영수증** | 건물·호실·세대주, 년월, 당월계, 연체료, 수납액, 수납일자, 은행, 합계 |

## 4. 이사정산 내역서 (moving-settlement, mobile-ms-new)

- 정산 항목별 상세 + 합계(공과금·관리비·기타·청소·미납·수납·미수금).
- PNG 이미지 생성/다운로드. **미수금 < 0(음수)이면 내역서 생성 차단**([_calculation-rules.md](_calculation-rules.md) 6절).
- 퇴실자·건물주에게 문자 전송(스마트폰 캡처 발송 가능, 기능정의서 M-2).

## 5. 미납대장 / 부과내역서 / 입주자카드 (overdue, building-list)

| 출력물 | 화면 | 구성 |
|--------|------|------|
| 미납대장 | overdue-management | 건물별 미납내역(동호·거래처명·년월·연체·미납액·연체료·합계·전화·이름), A4 |
| 관리비 부과내역서 | building-list | 세대 부과 내역(연·월 기준) |
| 입주자카드 | building-list | 세대 입주자 정보 카드(연·월 기준) |

## 6. 청구서 (admin usage)

`청구서 번호(INV-YYYYMM-nn), 발행일, 공급자(예금주·사업자등록번호·담당), 공급받는자(업체·발송월), 항목별(알림톡·문자·팩스 건수·단가·금액), 공급가액, 부가세(10%), 청구 합계, 입금 계좌·기한`
- 전체 발행(일괄)·개별 발행. PNG 다운로드. 설정(단가·청구계좌·청구기준)은 admin `settings` 반영.

## 7. 화면 PRD로 넘긴 사항
- 각 출력물의 물리 규격(지로 폼·A4 레이아웃 등 실제 서식) — 해당 화면 PRD/디자인.
- 카톡·팩스 채널별 첨부·표기 세부 — 해당 화면 PRD.
