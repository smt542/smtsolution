# 주택관리ERP — 프로젝트 규칙

## 셀렉터(드롭다운) 규칙 — 반드시 지킬 것
셀렉터를 만들거나 수정할 때 **버튼(닫힌 상태)과 드롭리스트(열린 목록)를 항상 함께** 디자인 시스템 UI로 적용한다.

- 네이티브 `<select>`를 쓰지 않는다. 네이티브 select의 드롭리스트는 CSS로 스타일할 수 없어 디자인이 깨진다.
- 커스텀 드롭다운으로 구현한다. 기준 구현은 `staff/utility-water/utility-water.dc.html`의 `.uc-dd` / `.uc-dd-btn` / `.uc-dd-menu` / `.uc-opt` 패턴.
- 드롭리스트에 반드시 포함할 것:
  - 12px 라운드 팝오버 + 그림자
  - hover 하이라이트
  - 선택 항목: 브랜드 배경 + 체크 아이콘
  - 열릴 때 셰브론 180° 회전
  - 바깥 클릭 / ESC로 닫힘, 동시에 여러 개가 열리지 않음
- 셀렉터 작업 후 **닫힌 상태만 확인하고 끝내지 말고 열린 목록까지 확인**한다.

## 모달 버튼 규격
모달 안의 액션 버튼은 **height 40px · radius 11px · font-size 13.5px · weight 700 · gap 7px**로 통일한다 (`.fmpc-btn` 기준). 페이지의 `.hf-btn`과 같은 크기.

## 기타
- Primary 컬러(브랜드 컬러)를 남용하지 않는다. 강조가 꼭 필요한 곳에만 쓴다.
- **마이너스(음수) 값은 빨간색(`var(--red)`)으로 표시한다.** 증감·차액·감면액 등 모든 수치에 적용. 양수는 별도 색을 쓰지 않는다.
