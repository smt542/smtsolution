## 1. 목적

현장관리자가 선택한 건물의 **기본 정보·협력업체·건물주 정보**와 **입주자(호실) 목록**을 조회하고, 검침 입력(`mobile-meter`)이나 입주자 상세(`mobile-tenant`)로 이동하는 조회 화면.

---

## 2. 권한

| 사용자 | 접근 |
|---|---|
| partner (현장관리자) | **R (읽기 전용)** — 건물·입주자 열람 |
| staff / resident | — (별도 표면) |

- 건물 정보·세입자 정보 열람은 partner **읽기 전용**([_permission-matrix.md](../../_permission-matrix.md) 3절, [_service-policy.md](../../_service-policy.md) 2.3). 이 화면에서 건물 데이터 수정 불가.
- 예외: **검침 입력**(`mobile-meter`)은 partner 쓰기 가능 기능이므로 이동 버튼을 노출(입력은 해당 화면에서 수행).
- **발송 없음**. 연락처는 전화 걸기 링크만.

---

## 3. UI

### 3.0 상단 헤더
- **기능**: 뒤로가기 + 건물명 + `검침 자료` 버튼.
- **규칙**: 뒤로가기 → `mobile-inquiry`. `검침 자료` → `mobile-meter`(세대별 수도·전기·가스 검침 입력).

### 3.1 탭 (건물 정보 / 입주자 정보)
- **기능**: 조회 영역 전환.
- **규칙**: `건물 정보`(기본) · `입주자 정보(N)`(호실 수 뱃지). 단일 선택.

### 3.2 건물 정보 탭 (읽기)
- **기능**: 건물 상세 정보 조회.
- **규칙**:
  - **기본 정보**: 건물 코드 · 건물명 · 건물 유형([_status-codes.md](../../_status-codes.md) 4절) · 건물주소 · 공동현관(도어 비밀번호). 필드 [_data-dictionary.md](../../_data-dictionary.md) B1.
  - **업체 정보**: 협력업체 구분별 업체명·전화(전화 걸기 링크)·청소 요일. 구분 목록은 [_status-codes.md](../../_status-codes.md) 12절, 필드 [_data-dictionary.md](../../_data-dictionary.md) B4.
  - **건물주 정보**: 건물주명·전화번호(주)·전화번호(부). [_data-dictionary.md](../../_data-dictionary.md) B2.
  - 모두 읽기 전용(입력 컨트롤 없음).

### 3.3 입주자 정보 탭
- **기능**: 호실 목록 조회 + 입주자 상세 진입.
- **규칙**:
  - 셀 표시: **호수 · 입주자명 또는 `공실` 뱃지**. 호수 오름차순 정렬.
  - 셀 탭 → 선택 세대 전달 후 `mobile-tenant`로 이동.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 성공 | 건물 로드 | 정보·목록 표시 |
| 빈 상태 | 호실 없음 | 공통 빈 안내 준용 |
| 공실 | 입주자명 없는 호실 | `공실` 뱃지 |
| 로딩/에러 | 조회 중·실패 | 공통 표준 준용 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 건물 기본·업체·건물주 | 건물 데이터([_data-dictionary.md](../../_data-dictionary.md) B절) · 프로토타입 로컬 | 진입 시 로드(선택 건물) |
| 입주자(호실) 목록 | 세대·입주자 데이터([_data-dictionary.md](../../_data-dictionary.md) C절) | 진입 시 로드 |
| 검침 이동 | `mobile-meter` | `검침 자료` 버튼 |
| 입주자 상세 이동 | `mobile-tenant` | 호실 셀 탭 |

- 발송 트리거 **없음**. 건물·입주자 데이터는 읽기 전용(수정은 staff 화면).
