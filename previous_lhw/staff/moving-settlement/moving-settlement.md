## 1. 목적

관리업체 직원이 **퇴실(예정) 세대의 최종 이사정산**을 입력·계산·완료하는 화면. 퇴실일까지의 관리비(일할)·공과금(이사 검침)·미납·청소비·기타를 합산해 정산요금과 미수금을 산출하고, 정산내역서를 출력하며, 세대를 **중도퇴실** 또는 **퇴실완료**로 마감한다. 좌측에서 건물→호실→정산 건을 고르면 우측 폼에서 작성한다.

## 2. 권한

| 사용자 | 접근 |
|---|---|
| staff (마스터) | O |
| staff (일반) | LNB "이사정산" 권한 부여 시 O (계정별 설정형) |

- 권한 모델은 [_permission-matrix.md](../../_permission-matrix.md) 2절을 따른다. 마스터가 `staff-management`에서 계정별로 이 메뉴 접근을 부여/제한.
- 퇴실 처리·삭제 등 되돌릴 수 없는 액션은 확인 모달을 거친다([_permission-matrix.md](../../_permission-matrix.md) 6절). 정산·퇴실 확정은 감사 로그 기록 대상([_service-policy.md](../../_service-policy.md) 8절).
- partner(현장관리자)도 이사정산을 입력하나, 그 화면은 별도(`mobile-ms-new`, "계산+저장"만)이며 본 화면과 표면이 다르다.

## 3. UI

### 3.1 상단 헤더 · 공통 인프라
- **기능**: 화면 제목("이사정산 입력"), 좌측 공통 LNB, 우측 공통 RNB.
- **규칙**: RNB "A/S 접수·퇴실 신청 현황" 패널을 공유한다. RNB **퇴실 신청 탭**의 카드(신규/확인, [_status-codes.md](../../_status-codes.md) 2절)를 누르면 해당 세대로 진입해 정산을 작성한다. 카드의 "처리 완료"는 퇴실 신청 접수를 마감 표시(정산 완료와 별개 동작).

### 3.2 좌측 레일 — 건물 → 호실 → 정산 건 선택
- **기능**: 건물 목록 → 호실 목록 → 해당 호실의 이사정산 이력에서 대상 건을 고른다. 3단 드릴다운.
- **규칙**:
  - 건물 목록: 코드·건물명·주소. **건물명·주소 검색**(마우스 중심, [_service-policy.md](../../_service-policy.md) 5절)과 **그룹(1~5) 필터**([_status-codes.md](../../_status-codes.md) 7절 부과 그룹). 선택한 건물명은 페이지 이동 시 유지.
  - 호실 목록: 호수·세대주. 입주자명이 없으면 **「공실」**로 표시.
  - **「새 이사정산 입력」**: 선택한 호실에 신규 정산 건을 만든다. 초기 상태 **「작성중」**([_status-codes.md](../../_status-codes.md) 2절).
  - 같은 호실에 이미 작성된 정산 건 목록(No · 이사정산 입력 날짜, [_data-dictionary.md](../../_data-dictionary.md) G1)에서 과거 건을 선택해 조회·수정.
  - **이사정산시 적요**: 선택 세대의 적요를 별도 패널에 표시(건물/호실 미선택 시 안내 문구).

### 3.3 이사정산 이력 조회 · 검침정보(보조 레일)
- **기능**: 날짜별 이사정산 이력 조회, 선택 세대의 검침정보 표시.
- **규칙**:
  - 이력 조회: 날짜 선택(달력, [_service-policy.md](../../_service-policy.md) 5절)으로 해당일 정산 건 목록을 보고 클릭 시 그 세대로 이동.
  - 검침정보: 선택 세대의 수도/전기/가스 검침(전월·이사 지침·사용량)을 요약 표시. 건물/호실 미선택 시 안내 문구.

### 3.4 정산 폼 — 기본 정보
- **기능**: 퇴실일과 계산일수 입력.
- **규칙**: **퇴실일자**(필수, 달력) · **계산일수(기준)** · **계산일수(부과)**. 일할 계산의 분모/거주일수 산정에 쓰이며, 관리비 항목 일할은 [_calculation-rules.md](../../_calculation-rules.md) 1.1(분모 고정 30일)을 따른다.

### 3.5 공과금 정산
- **기능**: 전기·수도·가스(·공용전기)의 이사 검침 기반 요금 산출.
- **규칙**: 구분별 **전월 지침 · 이사 지침 · 단가 · 량(자동) · 금액(자동) · 입금계좌 · 입금일**([_data-dictionary.md](../../_data-dictionary.md) G1/G3). 량=이사−전월, 금액=량×단가([_calculation-rules.md](../../_calculation-rules.md) 6절 ②). **① 공과금 소계** 자동 집계.
  - **연동**: "저장" 시 호실별 이사 지침값을 공유 저장소에 기록해, 공과금 관리(수도·전기·가스)에서 해당 호실 지침을 **새로 생성**할 때 「전월」로 사용한다. 이미 생성·저장된 지침에는 **소급 적용하지 않는다**.

### 3.6 관리비 항목
- **기능**: 관리비 항목별 부과액·정산액(일할) 입력.
- **규칙**: 항목별 **부과액 / 정산액(일할 자동)**. 항목은 건물 유형(빌라/빌딩)별 설정을 따르며 일할 여부·반올림은 `fee-item` 설정([_calculation-rules.md](../../_calculation-rules.md) 1절)을 표시·적용. **전기·수도료·가스**는 공과금 정산(3.5)에서 다루므로 관리비 항목에서 제외. **가수금·연락처** 입력 가능. **② 관리비 소계** 자동 집계.

### 3.7 기타
- **기능**: 자유 기타 항목 입력.
- **규칙**: 항목명·금액. **최대 15개**, 첫 행 외 삭제 가능. **③ 기타 소계** 자동 집계.

### 3.8 청소
- **기능**: 청소비 정산.
- **규칙**: **청소담당**(협력업체 관리의 청소 업체 목록 참조) · **청소처리**(완료/미결) · **청소완료일** · **청소금액** · **청소계좌** · **청소 적요**([_data-dictionary.md](../../_data-dictionary.md) G3).

### 3.9 정산(수납)
- **기능**: 수납액 입력.
- **규칙**: **수납액** · **최종 수납일**(달력). 미수금 산출 기준.

### 3.10 정산 체크 · 비고
- **기능**: 정산 체크 항목과 비고 메모.
- **규칙**: 정산 체크 항목 다건 입력, 비고 텍스트.

### 3.11 하단 합계 바
- **기능**: 정산 결과 요약.
- **규칙**: ① 공과금 · ② 관리비 · ③ 기타 · 청소 · 미납 소계 · 수납액 · **미수금**을 표시. **미수금 = 정산요금 − 수납액**([_calculation-rules.md](../../_calculation-rules.md) 6절). **음수(환급)는 빨간색**(`CLAUDE.md`).

### 3.12 하단 액션 버튼
- **기능**: 정산 저장·완료·출력·삭제.
- **규칙**(버튼별):
  | 버튼 | 동작 |
  |---|---|
  | **새 이사정산 입력** | 선택 호실에 신규 정산 건 생성(상태 「작성중」). 좌측 레일 위치. |
  | **저장** | 현재 입력 계산·저장(상태 「작성중」 유지). 이사 지침값 공유 저장소 기록(3.5). 결과 토스트. |
  | **정산완료+중도퇴실** | 상태 → **「중도퇴실」**. 공실 처리 안 함. 알림톡 수신 「동의」로 전환, 수납·민원 적요에 "중도퇴실" 기재([_calculation-rules.md](../../_calculation-rules.md) 6절). 확인 모달. |
  | **정산완료+퇴실** | 상태 → **「퇴실완료」**. 퇴실 시점 타임스탬프를 전출정보에 추가, 입주자 정보 초기화(세대 공실화)([_calculation-rules.md](../../_calculation-rules.md) 6절, [_data-dictionary.md](../../_data-dictionary.md) C6). 확인 모달. |
  | **출력** | 이사정산 내역서 생성(정산 건 선택 필요). [_output-forms.md](../../_output-forms.md) 4절. |
  | **빈양식** | 빈 정산내역서 서식 출력(세대 선택 없이 가능). |
  | **삭제** | 현재 정산 건 삭제(확인 모달, 되돌릴 수 없음). |
- **완료 처리 가드**: **미수금 > 0이면** 중도퇴실/퇴실 완료 불가 — 수납액을 먼저 입력해 미수금을 0으로 맞추도록 안내(수납액 입력으로 포커스 이동). 미수금 < 0(음수)이면 내역서 생성 차단([_output-forms.md](../../_output-forms.md) 4절, [_calculation-rules.md](../../_calculation-rules.md) 6절).
- 완료 후에는 폼·액션이 잠금(읽기)으로 전환된다.

| 항목 | 출처 / 연동 | 트리거 · 비고 |

| 정산문자 전송 | staff `messaging` 공용 발송 모듈 | 정산내역서 문자 전송(발송은 messaging 허브 경유, [_notification-policy.md](../../_notification-policy.md) 3절) |

- 이 화면 자체에는 별도 발송 버튼이 없다. 정산내역서 문자는 `messaging` 공용 모듈로 일원화([_notification-policy.md](../../_notification-policy.md) 3절).
