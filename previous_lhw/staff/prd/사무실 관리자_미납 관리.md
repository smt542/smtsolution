## 1. 목적

선택 기간(년·월까지) 기준으로 **미납 세대를 조회**하고, 장기 미납 세대에 **독촉 문자를 발송**하며, 미납 현황을 **A4로 출력**하는 화면.

## 3. UI

### 3.0 상단 조회 툴바
- **기능**: 조회 기간·범위 설정 + 독촉/출력 액션.
- **규칙**: 좌→우 `년도(2023~2026) · 월(1~12) · "…까지" · 독촉 대상 세그(전체/독촉 대상) · 범위 세그(전체/당계) · 건물명 검색 · 독촉 문자 발송 · 출력`.
  - **독촉 대상 세그먼트**: 이전의 "연체 개월수"·"금액 구간" 드롭다운을 대체(삭제됨). 독촉 기준을 만족하는 세대만 필터.
  - **범위(전체/당계)**: `당계`는 선택 년·월에 해당하는 행만, `전체`는 누적 미납 전체.

### 3.1 미납 세대 표
- **기능**: 조건에 맞는 미납 내역 표시(조회 위주, 행 편집 없음).
- **규칙**: 컬럼 `동호 · 거래처명(건물명) · 년월 · 연체(개월) · 미납액 · 납.연체료 · 납.후연체 · 연체료계 · 합계 · 비고 · 전화 · 이름`.
  - 호별 소계행(`[호합]`), 하단 sticky 합계행(`항목 N / M건` + 컬럼 합).
  - 독촉 기준 충족 행은 강조 표시.
  - 금액 계산(연체료 등)은 [_calculation-rules.md](../../_calculation-rules.md) 3절.

### 3.2 독촉 문자 발송
- **기능**: 장기 미납 세대에 독촉 SMS 발송.
- **규칙**:
  - **독촉 대상 기준: 연체 2개월 이상 AND 합계(미납액+연체료계) 10만원 이상.** (세대 단위로 최대 연체 개월·합산 합계로 판정.)
  - 현재 뷰에서 대상 세대를 추려 수신자로 담고(세대 주/부번호 포함), 미납 안내 템플릿을 발송 작성창(공용 Messenger)에 채운다. "N세대를 수신자로 담았어요" 토스트, 없으면 "발송할 대상이 없어요".
  - 발송 채널·과금(포인트 차감)은 [_notification-policy.md](../../_notification-policy.md).
  - 템플릿: `[관리비 미납 안내]` + 건물명·호수·미납 개월·미납 금액(연체료 포함) + "2개월 이상·10만원 이상 장기 미납" 문구.

### 3.3 출력 (미납대장)
- **기능**: 미납 현황 A4 출력.
- **규칙**: 모달 없이 A4 세로 출력. 제목 `[ 미납관리 현황 {년}년 {월}월 ]`. 출력 컬럼은 표와 동일하되 **비고 제외**(11컬럼) + 호합 소계·합계. 대상 없으면 "출력할 내역이 없어요". 출력물 규칙은 [_output-forms.md](../../_output-forms.md) 5절.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 빈 상태 | 기간 미선택 | "년도와 월을 선택해 주세요" 안내 |
| 결과 없음 | 기간 선택·0건 | "조회 결과가 없어요" |
| 성공 | 미납 있음 | 표 + 합계 |
| 에러 | 조회·발송 실패 | 실패 안내([_service-policy.md](../../_service-policy.md) 6절) |
