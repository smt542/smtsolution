## 1. 목적

도시가스사가 **고객번호 단위 총액**으로 청구한 가스요금을, 그 고객번호에 속한 **호실별 사용량(㎥) 비례**로 안분·부과하는 화면. 전기 화면과 **동일 골격**이며(고객번호 표 + 호실별 지침 표), 가스 특성(가스회사·가스전화·계좌번호 등 공급자 정보, 계량기 없는 호실 고정 톤)만 다르다. 검침대장 출력도 이 화면에서 한다.

- 배분 계산의 정본은 `staff/utility-electric/부과액-계산-정책.md`(전기·수도·가스 공통).

## 3. UI

### 3.0 상단 헤더
- **기능**: 화면 제목("공과금 관리 › 가스")과 상단 액션.
- **규칙**: 공통 LNB/RNB 공유. 헤더 우측 액션 **`검침대장 출력`**(3.5) · **`전체 이월`**(이번 달 지침·설정 다음 달 일괄 이월).

### 3.1 조회조건 / 전체 건물 (좌측 패널)
- **기능**: 대상 **연·월분**과 **건물** 선택.
- **규칙**: 연도·월분 커스텀 드롭다운(`CLAUDE.md`), 건물명·주소 검색(즉시 필터). 표 컬럼 `코드 · 건물명 · 주소 · 가스(고객번호 수)`. 헤더 고정, 선택 행 브랜드 배경 유지.

### 3.2 편집 바 (우측 상단)
- **기능**: 선택 건물·기간 표시 + **부과기준일** + 편집 액션.
- **규칙**: `건물명` / `2026년 7월분 부과 편집` 표기. **부과기준일** `시작일 ~ 종료일`(달력, 기본 전월16일~당월15일, [_calculation-rules.md](../../_calculation-rules.md) 2.4). 액션 `수정` → `계산`·`저장`·`취소(X)`. 건물 변경 시 조회 모드 복귀.

### 3.3 고객번호 표 (우측)
- **기능**: 고객번호(라인)별 총부과액·집계 표시. 행 클릭 시 해당 라인 호실만 필터.
- **규칙**:
  - 컬럼: `L · 고객번호 · 월 · 량 · 수동입력 · 할인금액 · 전월금액 · 부과액 · 전단가 · 단가 · 금-전1 · 금-전2 · 금월량 · 전월량`([_data-dictionary.md](../../_data-dictionary.md) D1). **수도·가스에는 `고지금액 · 감면 · 이사` 컬럼이 없다**(부가금 가산·감면·이사 컬럼은 전기 계열 전용).
  - **부과액**은 도시가스사 청구 총액(할인 반영 순액)을 복사·붙여넣기. 량·단가는 자동 파생.
  - **공급자 정보**(가스회사·가스전화·계좌번호·부과시 참조사항)는 건물 부가정보에서 관리([_data-dictionary.md](../../_data-dictionary.md) B5). 검침대장/고지 출력에 활용.
  - **고지금액 = 부과액**(가스는 부가금 가산 없음; 전기만 ×1.11, [_calculation-rules.md](../../_calculation-rules.md) 2.3). **할인유형(수급자·다자녀·기타)** 은 gross-up으로 반영([_calculation-rules.md](../../_calculation-rules.md) 2.2).

### 3.4 호실별 지침 표 (우측)
- **기능**: 호실별 검침 지침 입력·편집 → 부과액 자동 배분.
- **규칙**:
  - 컬럼: `호수 · 입주일자 · 퇴실일자 · 퇴실예정일자 · 전월 · 금월 · 량 · 전.량 · 증감 · 수동입력 · 할인유형 · 할인금액 · 부과액 · 적요 · 처리일자 · 부과기준 · 이름 · 전화 · 라인 · 인원`([_data-dictionary.md](../../_data-dictionary.md) D2).
  - **량 = 금월 − 전월**. 계량기 없는 호실은 **고정 톤**. **호실 부과액 = max(0, 량×단가 − 할인)**, 수동입력 시 고정. 단가·gross-up·할인 캡·절사·검산은 **정본 `부과액-계산-정책.md`가 근거**([_calculation-rules.md](../../_calculation-rules.md) 2.1 요약).
  - **할인금액**은 입주민 상세 값을 읽기 전용 표시. 등록 할인액 신뢰(정본 7장).
  - **값 고정(자물쇠)**: 량·수동입력을 "해당 월부터 고정", 다음 달 자동 상속(정본 6장). 계량기 없는 호실 고정 톤은 량 고정으로 분모 포함.
  - **행 플래그(범례)**: `퇴실 예정`(파랑) · `공실 사용량`(빨강) · `최근 입주`(초록). 증감 음수는 빨강(`CLAUDE.md`).
  - **미측정 기간**: 단가·부과액 `-`. **월중 입·퇴실 일수 안분 안 함**(월 단위 배분, 정본 8장).
  - **빈 상태**: 검침 미등록 달은 "아직 검침이 등록되지 않은 달이에요 / 수정을 눌러 부과기준일을 지정하면 / 호실 목록이 표시돼요".

### 3.5 검침대장 출력 (모달)
- **기능**: 건물별 가스 검침대장 인쇄물 출력.
- **규칙**: 건물 다중 선택 + 전체선택 후 인쇄, 코드·건물명·주소 검색. 계량기 없는 호실 "계량기없음(N톤 고정)" 표기. 회사명 워터마크. 서식은 [_output-forms.md](../../_output-forms.md) 2절.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 건물 미선택 | "건물을 선택해 주세요" |
| 기준일 미설정 | 부과기준일 없음 | "부과기준일을 먼저 설정해 주세요" + 설정 버튼 |
| 성공 | 건물·기간 선택 완료 | 고객번호 표·호실별 지침 표 표시 |
| 편집 중 | `수정` 클릭 | 입력 활성, 계산/저장/취소 노출 |
| 저장 완료 | `저장` 성공 | 처리일자 갱신 + 완료 토스트 |
| 결과 없음 | 건물 검색 0건 | "검색 결과가 없습니다" |
| 에러 | 조회·저장 실패 | 실패 안내·재시도([_service-policy.md](../../_service-policy.md) 6절) |
