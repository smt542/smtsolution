## 1. 목적

건물별 **장기수선충당금(적립금)의 입·출금 내역**을 기록·관리하는 화면. 건물을 선택하면 해당 건물의 적립금 원장(일자·번호·적요·입금·출금·차인잔액·영수증·사진)을 조회·편집하고, 입금/출금 합계와 현잔액을 집계한다. 적립 목적(수선공사비 등) 사용을 증빙(영수증·공사사진)과 함께 남긴다.

## 3. UI

### 3.0 공통 프레임
- **기능**: 공통 LNB·RNB 공유. 제목 "장기수선비 관리".
- **규칙**: 본문은 좌(적립 건물 목록) + 우(적립금 내역) 2단 구성.

### 3.1 적립 건물 목록 (좌측)
- **기능**: 적립금을 관리하는 건물 선택.
- **규칙**:
  - 컬럼: **코드 · 명칭**. 행 클릭 시 우측 내역이 해당 건물로 전환.
  - 건물 미선택 시 우측은 "좌측에서 건물을 선택해 주세요" 안내.

### 3.2 적립금 내역 툴바 (우측 상단)
- **기능**: 조회 기간·모드 전환·출력.
- **규칙**:
  - **조회일 기간**: 시작(년·월) ~ 종료(년·월) 드롭다운(커스텀 `.uc-dd`, 네이티브 `<select>` 금지).
  - **출력** 버튼: 현재 건물 내역을 인쇄(3.5).
  - **추가** 버튼: 신규 입·출금 행 추가(편집 모드).
  - **수정 / 취소 / 저장**: 조회 모드 ↔ 편집 모드 전환. 「수정」 진입 시 "내역을 수정할 수 있어요", 「취소」 시 "변경을 취소했어요", 「저장」 시 "적립금 내역을 저장했어요" 토스트.
  - 편집 없으면 「저장」 비활성. 건물 미선택 상태에서 추가/출력 시 "건물을 먼저 선택해 주세요".

### 3.3 적립금 내역 표
- **기능**: 선택 건물의 입·출금 원장.
- **규칙**:
  - 컬럼: **일자 · 번호 · 적립금 적요 · 적립금입금 · 적립금출금 · 차인잔액 · 적요 · 영수증 · 사진** ([_data-dictionary.md](../../_data-dictionary.md) B6).
  - 「영수증사진」을 **「영수증」 + 「사진」 2개 컬럼으로 분리**하고, 별도 **「적요」 컬럼을 신설**(최근 변경 반영). 즉 적요는 두 종류: **적립금 적요**(내용 설명)와 **적요**(부가 메모).
  - **차인잔액 = 직전 잔액 + 입금 − 출금**(행 누적). 자동 계산(직접 입력 아님).
  - 편집 모드에서 일자·번호·적립금 적요·입금·출금·적요 입력, 행 삭제(확인 후 "행을 삭제했어요").
  - 금액은 천단위 콤마 표기. 음수는 빨간색(`CLAUDE.md`).

### 3.4 첨부(영수증·사진)
- **기능**: 행별 증빙 이미지 첨부·열람.
- **규칙**:
  - **영수증** = 영수증 이미지, **사진** = 공사사진(별개). 각 셀에서 첨부 뷰어 열람("N장" 표기).
  - 뷰어에서 **인쇄** 가능. 첨부 열람은 조회 모드에서도 가능.

### 3.5 합계 & 출력
- **기능**: 집계·인쇄물.
- **규칙**:
  - 하단 요약: **적립금입금 합계 · 적립금출금 합계 · 현잔액**([_data-dictionary.md](../../_data-dictionary.md) B6 요약).
  - 출력물 표: 일자·번호·적립금내용·입금액·출금액·차인잔액 + "합계 >> 현잔액" 행 + **회사명 워터마크**([_output-forms.md](../../_output-forms.md) 0절). 결과 없으면 "출력할 내역이 없어요".

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기(미선택) | 건물 미선택 | 우측 "좌측에서 건물을 선택해 주세요" |
| 빈 상태 | 선택 건물 내역 없음 | 빈 원장 + 추가 유도 |
| 성공 | 내역 있음 | 원장 표 + 합계 |
| 편집 모드 | 수정/추가 클릭 | 입력 활성·저장/취소 노출 |
| 저장 비활성 | 편집 없음 | 「저장」 비활성 |
| 성공(저장) | 저장 | "적립금 내역을 저장했어요" 토스트 |
| 제한(권한) | 메뉴 미부여 | LNB 숨김 |
| 에러 | 저장 실패 | 실패 안내·재시도([_service-policy.md](../../_service-policy.md) 6절) |
