## 1. 목적

관리업체 직원이 **신규 건물의 기본정보·협력업체·건물주·공과금 고객번호 등 관리에 필요한 전체 정보를 등록**하는 화면. 등록 후 이 건물의 세대·부과·공과금 관리가 시작된다.

## 3. UI (섹션 순서)

### 3.1 기본정보
- **기능**: 건물 식별·기본 속성 입력.
- **규칙**: `건물 코드* · 건물명 · 건물 유형 · 공동현관(도어 비밀번호) · 주소*(주소검색) · 고지서 부과 그룹 유형(1~5) · 수도 고객번호 보유 수 · 상시 공지문 · 계약일 · 해지일`
  - **건물 유형**: 빌라·빌딩 등([_status-codes.md](../../_status-codes.md) 4절).
  - **부과 그룹 유형(1~5)**: 부과기간·납기가 다른 건물 그룹을 묶는 값(그룹별 출력·부과 대응).
  - **수도 고객번호 보유 수**: 선택 값 `1~8·10`(9 결번).
  - **상시 공지문**: 입력 시 **세입자 앱 홈의 건물 공지에 상시 노출**, 비우면 미표시(→ resident 앱 연동).
  - **건물 코드**: 등록 시 시스템이 **순번으로 자동 채번**(중복 방지)하되, 사용자가 **수정 가능**.

### 3.2 업체 및 담당자
- **기능**: 담당자 지정 + 협력업체 배정·계약 상세.
- **규칙**:
  - `사무 담당자* · 현장 관리자*` 지정.
  - 9종 협력업체 블록(청소·정화조·인터넷·전기안전·유선방송정보·승강기보수·승강기정기검사·소방검사·CCTV). 각 블록 공통 `업체명·전화번호·계좌번호·계약서 사진(최대 10)·비고` + 구분별 추가 필드(계약일·검사일·금액 등, [_data-dictionary.md](../../_data-dictionary.md) B4).
  - **업체는 협력업체 마스터(`vendor-management`)에서 선택 배정**하고, 건물별 계약 상세를 여기 기록한다([vendor-management.md](../vendor-management/vendor-management.md)).
  - 반영 방식: 구분별로 **마스터 업체를 드롭다운으로 선택** → 건물별 계약 상세(금액·일자 등)를 입력.

### 3.3 적립금
- **기능**: 건물 적립금 유형·메모.
- **규칙**: 유형 `적립금 · 장기수선충당금 · 기타 · 없음`, 메모. (실제 입출금 내역은 `long-term-repair`.)

### 3.4 건물주 정보
- **기능**: 건물주 연락·주소.
- **규칙**: `건물주명 · 전화번호(주) · 전화번호(부) · 주소(주소검색) · 비고`.

### 3.5 부가정보 (공과금 고객번호)
- **기능**: 수도/공용전기/전기/가스 **고객번호 단위 검침·부과 설정**.
- **규칙**: 각 블록 `고객번호 · 성명/계약자 · 입금(당월/전월) · 월분(당월/전월) · 계산(자동/수동) · 계산법 · 이체구분 · 검침일(1~31) · 고지기간(당월/전월/전전월) · 고지기간 출력(Y/N) · 메모` + 가스 블록 `가스회사·가스전화·계좌번호` + `부과시 참조사항`.
  - 계산법: `기본·인원·시조례·시+톤당·시+인원·기타`([_status-codes.md](../../_status-codes.md) 6절).
  - **공용전기 블록은 축소형**(계산·계산법·고지기간 출력 없음).
  - 고객번호 `＋추가`로 블록 증설.
  - 드롭다운의 미완성 "XX" 옵션은 **제거**(불필요 자리). 공용전기 월분=당월/전월, 계산법은 기존 목록만 유지.

### 3.6 건물 메모
- **기능**: 자유 메모.

### 3.7 하단 액션
- **기능**: 등록 저장 / 뒤로가기.
- **규칙**: "등록 저장" 시 검증 통과하면 저장 후 `building-list`로 이동. "뒤로가기"는 입력 중이면 확인 모달. (상세 화면은 여기에 "건물 삭제"(빨강) 추가 — 되돌릴 수 없어 확인 모달.)
  - **필수값**: 건물 코드·주소·사무 담당자·현장 관리자. 미입력 시 저장 차단.
