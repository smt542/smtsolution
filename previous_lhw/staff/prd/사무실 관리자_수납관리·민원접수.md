## 1. 목적

건물·호실을 선택해 세대별 **수납 이력·입주자 정보·A/S(민원) 현황을 통합 관리**하는 핵심 화면. 부과금액/미납/수납 조회, 명세서·영수증 출력, 지로·은행 자동수납, A/S 접수·처리·확인문자까지 한 화면에서 처리한다.

## 3. UI

### 3.0 상단 탭/도구
- **기능**: 조회·부과금액·출력·자동수납 진입.
- **규칙**: 상단 버튼 `조회 · 월별 부과금액 · 빌라▾(부과금액·미납내역·수납내역) · 호실▾(명세서·영수증 출력) · 자동수납▾(지로수납처리·지로수납원장·처리일자 확인·은행 입금내역 업로드·은행 양식 다운)`. 좌측 레일에서 건물명·주소 검색 → 건물·호실 선택.
  - **「조회」는 통합검색 모달**: 금액으로 찾기 / 입금자명·전화번호·동호로 찾기 → 청구금액·이사정산·세입자·건물주 조회. **결과 행 클릭 시 해당 세대로 전환**(좌측 선택 + 이력·입주자·A/S 패널 이동, `jumpTo`).
  - **수납 건물 메모 / 부과시 참조사항 편집 블록**: 좌측 건물 영역에 선택 건물의 수납 메모·부과시 참조사항을 표시하고 **「수정」→「저장」**으로 편집한다(건물 단위 참조 정보).

### 3.1 수납 이력 (월별)
- **기능**: 세대 월별 수납 내역 조회·편집.
- **규칙**: 컬럼 `처리 · 년월 · 당월계 · 연체 · 수납액 · 수료(수수료) · 수납일자 · 은행 · 구분 · 비고 · 기한` + 합계(미납·연체료·미납합계).
  - 은행 `무통장입금/지로입금`, 구분 `일반/지로/이체/무통`([_status-codes.md](../../_status-codes.md) 3절). 연체료 계산은 [_calculation-rules.md](../../_calculation-rules.md) 3절.
  - 이력 추가/수정/저장/취소.
  - 미납 합계 영역에 **「문자 전송」 버튼**: 해당 세대의 미납 안내 문자를 공용 Messenger로 발송(staff 화면이므로 발송 가능 영역).

### 3.2 입주자 정보
- **기능**: 해당 호실 입주자 정보 조회·수정.
- **규칙**: `입주자명 · 입금자명 · 전화번호 · 입주일 · 퇴거일 · 적요 · 문자(동의/비동의) · 알림톡(동의/비동의) · 부과(Y/N) · 출력(Y/N)`. 수정/저장/취소. 필드 정의는 [_data-dictionary.md](../../_data-dictionary.md) C절.

### 3.3 A/S(민원) 현황·접수
- **기능**: 세대 A/S 접수·처리 관리.
- **규칙**: 컬럼 `No · 호수 · 접수일시 · 유형 · 접수내용 · 입주자 전화번호 · 처리결과 · 처리결과 내용 · 시행일자 · 시간 · 접수자 · 담당자`.
  - 처리결과 `미결/보류/완결/반복`, 유형 6종([_status-codes.md](../../_status-codes.md) 1절), 담당자 목록.
  - 접수 추가/저장·삭제. A/S 확인 문자는 상세 폼의 **「확인문자 보내기」 단문 방식으로 단일화** — 담당자에게 단문(건물·호수·주소·접수내용·전화)을 조립해 공용 Messenger로 발송. (별도 3종 템플릿[접수확인/방문예정/처리완료] 모달은 사용하지 않음.)

### 3.4 자동수납 (지로·은행)
- **기능**: 지로/은행 입금 자동 수납.
- **규칙**: 지로 수납처리·지로수납원장·처리일자 확인. 은행 입금내역 엑셀 업로드로 자동 매칭(키: 고객번호·이름·금액), 미매칭 수동. 에러체크 `정상/이중수납`. 포맷은 [_data-exchange.md](../../_data-exchange.md) 2절.

### 3.5 출력 (명세서·영수증)
- **기능**: 호실 명세서·영수증 출력.
- **규칙**: 명세서(년월·당월계·연체료·수납액·전기/수도/가스 금액·단가), 영수증(건물·호실·세대주·년월·수납액·은행·합계). [_output-forms.md](../../_output-forms.md) 3절.
