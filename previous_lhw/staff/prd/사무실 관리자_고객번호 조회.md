## 1. 목적

건물의 **수도·공용전기 고객번호를 한눈에 조회**하는 **조회 전용** 화면. 고객번호·건물명·주소·구분·적요로 검색해 어느 건물의 어떤 고객번호가 어떤 설정인지 빠르게 확인한다. (전기·수도·가스 검침/부과 편집은 각 공과금 화면에서.)

## 2. 권한

| 사용자 | 접근 |
|---|---|
| staff (마스터) | O (조회) |
| staff (일반) | LNB "공과금 관리" 권한 부여 시 O ([_permission-matrix.md](../../_permission-matrix.md) 2절) |

- **조회 전용**: 등록·수정·삭제·발행·수납 액션 없음.

---

## 3. UI

### 3.0 상단 헤더 / 유형 세그먼트
- **기능**: 조회 대상 공과금 유형 전환.
- **규칙**: 세그먼트 `수도 / 공용전기`. 선택에 따라 목록의 고객번호 컬럼 헤더·일부 값이 동적으로 바뀐다.

### 3.1 검색
- **기능**: 목록 필터링.
- **규칙**: **고객번호·건물명·주소·구분·기타적요**로 검색. 건수(N건) 표시.

### 3.2 고객번호 목록
- **기능**: 조건에 맞는 고객번호 행 표시(조회 전용).
- **규칙**: 컬럼 `코드 · 빌라명 · 주소 · LIN(라인) · {수도/공용전기}고객번호 · 일금일 · 구분 · 계산 · 기타적요`.
  - **일금일**: 1~28 (납부/기준 일자).
  - **구분**: `당월 · 전월` (수도·공용전기 공통. 기존 미완성 "XX" 옵션은 제거).
  - **계산**: 수도=`자동 · 수동`, 공용전기=`자동`.
  - **기타적요(값 예)**: (없음) · 계량기 없음·3톤 고정 · 전월 대비 급증 확인 · 분할 납부 협의 · 검침 불가·추정 · 명의 변경 예정.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 성공 | 고객번호 있음 | 목록 표시 |
| 결과 없음 | 검색 0건 | "검색 결과가 없습니다" |
| 에러 | 조회 실패 | 실패 안내·재시도([_service-policy.md](../../_service-policy.md) 6절) |
