> 이 화면은 **건물 목록 + 선택 건물의 호수·입주민 목록**을 한 화면에서 다루는 진입 허브다. 건물 상세는 [building-detail.md](../building-detail/building-detail.md). **입주민 목록은 이 화면에서 건물 선택 시 인라인으로 표시**한다(별도 세대 목록 화면 `tenant-list`는 삭제·미사용).

---

## 1. 목적

관리업체 직원이 등록된 **건물 전체를 한눈에 조회**하고, 특정 건물을 선택해 그 **호수·입주민 목록**을 확인하며, 건물 상세·신규 건물 등록·호수 등록으로 빠르게 진입하는 관리업무 시작점.

## 2. 권한

| 사용자 | 접근 |
|---|---|
| staff (마스터) | O |
| staff (일반) | LNB "건물·입주자 관리" 권한 부여 시 O (계정별 설정형, [_permission-matrix.md](../../_permission-matrix.md) 2절) |

- partner(현장관리자)는 이 화면에 접근하지 않는다(모바일 `mobile-building` 열람 전용).

## 3. UI

### 3.0 상단 헤더
- **기능**: 화면 제목 + **「입주자카드 및 부과내역 출력」** 버튼(**선택한 건물 기준** 출력; 건물 미선택 시 안내/비활성).
- **규칙**: 좌측 공통 LNB, 우측 공통 RNB("A/S 접수·퇴실 신청 현황")를 공유한다. 출력물(입주자카드·관리비 부과내역서)은 [_output-forms.md](../../_output-forms.md) 5절, 회사명 워터마크 포함.

### 3.1 검색·필터 박스
- **기능**: 건물명·주소 검색 + 접이식 필터 패널.
- **규칙**:
  - 검색: **건물명·주소** 키워드(마우스 우선, [_service-policy.md](../../_service-policy.md) 5절 건물명 검색 규칙).
  - 필터 항목: **등록일**(최신순·오래된 순) · **사무 담당자** · **현장 관리자** · **검침일** · **청소 담당자**.
  - **검침일 필터**: 기준 없음 / 수도·전기·가스·공용전기 중 택1 → 선택 시 방향(**빠른 순·늦은 순**) 노출. 검침일 기준 정렬 시 목록에 **검침일 컬럼**이 함께 표시된다.
  - 필터·검색 결과는 목록과 엑셀 다운에 함께 반영된다.

### 3.2 전체 건물 목록
- **기능**: 등록 건물을 행 단위로 표시, 행 선택 시 하단 호수·입주민 목록 로드.
- **규칙**:
  - 컬럼: 코드 · 건물명 · 유형 · 주소 · 건물주명 · 건물주 연락처 · 공동현관 · 관리(사무 담당자) · 검침(현장 관리자) · 청소 · (검침일: 검침일 필터 시 노출) · 등록일 · 동작.
  - **「상세」** 버튼 → [building-detail](../building-detail/building-detail.md). 상단 건수 뱃지("N곳") 표시.
  - **엑셀 다운**: 현재 필터 결과 기준([_data-exchange.md](../../_data-exchange.md) 5절).
  - **대량 목록**: 건물이 많으면 **무한 스크롤**로 로드(스크롤 시 이어서 불러옴).
  - **＋ 건물 등록** → [building-register](../building-register/building-register.md).

### 3.3 호수·입주민 목록 (선택 건물)
- **기능**: 상단에서 선택한 건물의 세대(호실) 목록 표시.
- **규칙**:
  - 건물 미선택 시 **"건물을 선택해 주세요"** 안내(빈 상태). 선택하면 해당 건물 세대가 로드된다.
  - 컬럼: 호실·입주자명·입금자명·룸·인원·전화번호·차량번호·입주일·관리비·퇴실일자·입주예정일·인상액·평형·수도·전기·공용전기·가스·부과금 여부·고지서 출력 여부·이름 출력 유형·연체료 부과 여부·단수 출력 여부·이체 방식·문자 수신·적요·인증·홈피 비번·발송·한전고객번호·한전계기번호·부과일·등록일 (필드 정의 [_data-dictionary.md](../../_data-dictionary.md) C절).
  - **엑셀 다운**(선택 건물 세대) · **＋ 호수·입주민 등록** → [tenant-register](../tenant-register/tenant-register.md).
  - 세대별 상세/수정은 인라인 입주민 목록의 행을 클릭해 [tenant-detail](../tenant-detail/tenant-detail.md)에서 처리.

### 3.4 LNB/RNB (공통 인프라)
- **규칙**: **「문자·알림톡 관리」 LNB 항목은 숨김**(발송은 `messaging` 허브로 일원화 중, 현재 노출 제외). RNB는 A/S 접수·퇴실 신청 카드(클릭 시 receipt-management/moving-settlement 이동).

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 빈 상태 | 등록 건물 0개 | "등록된 건물이 없습니다" + 건물 등록 유도 |
| 로딩 | 목록 조회 중 | 스켈레톤/로딩([_service-policy.md](../../_service-policy.md) 6절) |
| 성공 | 건물 1개 이상 | 목록 표시 |
| 결과 없음 | 검색·필터 결과 0건 | "검색 결과가 없습니다" |
| 없음(하위) | 건물 미선택 | 호수·입주민 영역 "건물을 선택해 주세요" |
| 제한 | 권한 없음 | LNB 숨김/액션 비활성 |
| 에러 | 조회·다운로드 실패 | 실패 안내·재시도 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 건물 목록 | 내부 DB(테넌트 격리) | 진입 시 조회 |
| 호수·입주민 목록 | 내부 DB | 건물 선택 시 조회 |
| 담당자(필터) | 직원 데이터 | 필터 오픈 시 |
| 엑셀 다운(건물·세대) | 조회 결과 기준 | 버튼 클릭 · 포맷 [_data-exchange.md](../../_data-exchange.md) |
| 입주자카드·부과내역서 출력 | 출력물 모듈 | 버튼 클릭 · [_output-forms.md](../../_output-forms.md) 5절 |

- 발송 트리거 **없음**(문자·알림톡 관리 LNB 숨김).
