## 1. 목적

관리업체 직원이 **건물·월(부과기준일) 단위**로 그 건물 세대들의 관리비 항목 부과 여부·금액을 세팅하는 화면. 항목별 금액을 직접 입력하거나, **전월 자료 반영**(빌라/전체 자료 추가)과 **공과금 부과액 자동 채우기**(공과금 관리에서 산출된 전기·수도·가스 부과액을 세대별 항목으로 끌어오기)으로 채운다. 건물별 **「부과시 참조사항」**과 **「중요 건물」** 지정으로 세팅 실수를 예방한다.

- 관리비 항목 자체의 등록·수정·삭제는 `fee-item`(항목등록 관리)에서 처리한다.
- 공과금 부과액의 호실 배분 계산은 이 화면이 재정의하지 않고 정본 `부과액-계산-정책.md`·공과금 화면 결과를 참조한다.

## 3. UI

### 3.0 상단 헤더
- **기능**: 화면 제목("관리비 부과 세팅").
- **규칙**: 좌측 공통 LNB, 우측 공통 RNB("A/S 접수·퇴실 신청 현황") 공유. 본문은 좌측(건물·참조사항) + 우측(편집 바·공과금 정보·세대별 항목) 2단.

### 3.1 조회조건 / 전체 건물 (좌측 상단 패널)
- **기능**: 대상 **연·월분**·**그룹**과 **건물** 선택.
- **규칙**:
  - **연도**·**월분** 커스텀 드롭다운(`CLAUDE.md`). **그룹** 필터 `전체 · 1~5`(부과 그룹 유형, 납기·부과기간이 다른 그룹 구분, [_status-codes.md](../../_status-codes.md) 7절).
  - **건물명·주소 검색**(즉시 필터). 표 컬럼 `코드 · 건물명 · 주소`. 헤더 고정, 선택 행 브랜드 배경 유지.
  - **중요 건물** 지정된 건물 클릭 시 "중요 건물로 지정된 건물이에요 — {건물명} 셋팅 시 확인이 필요합니다. 계속하시겠습니까?" 확인 모달 → `계속` 시 진입, 취소 시 선택 취소.

### 3.2 「부과시 참조사항」 패널 (좌측 하단)
- **기능**: 선택 건물의 **부과 시 유의사항 메모** 표시·편집 + **중요 건물** 토글.
- **규칙**:
  - 메모 영역은 건물별 자유 텍스트(건물 부가정보 「부과시 참조사항」, [_data-dictionary.md](../../_data-dictionary.md) B5). 없으면 "등록된 참조사항이 없어요".
  - **「중요 건물」 체크박스**: 켜면 그 건물은 3.1 진입 시·전월 자료 반영 시 확인 모달 대상이 된다. 지정은 이 패널에서 토글로 저장.

### 3.3 편집 바 (우측 상단)
- **기능**: 선택 건물·기간 표시 + **부과기준일** + 편집 액션.
- **규칙**: `건물명` / `2026년 7월분 부과 세팅` 표기. **부과기준일** `시작일 ~ 종료일`(달력, 기본 전월16일~당월15일, [_calculation-rules.md](../../_calculation-rules.md) 2.4)과 **납기일**(달력)을 함께 설정한다. **여기서 설정한 해당 월분 납기일이 고지서 발행(`bill-publish` 지로 고지서)에 반영**된다(고지서 화면에서 납기일을 따로 수정하지 않음). 액션 평소 `수정` → 수정 진입 시 `저장`·`취소(X)`. 건물 변경 시 편집 중이면 조회 모드 복귀(입력값 유지 규칙은 저장/취소로만 확정).

### 3.4 공과금 정보 (우측, 탭)
- **기능**: 공과금 관리에서 등록된 건물 공과금 현황을 유틸별로 참조 표시.
- **규칙**: 탭 `수도 · 전기 · 공용전기 · 가스`. 각 탭은 해당 유틸의 고객번호·부과 정보를 **읽기 참조**로 노출(등록·수정은 공과금 화면/건물 부가정보에서). 세대별 항목의 공과금 계산 근거로 쓰인다.

### 3.5 세대별 관리비 항목 표 (우측)
- **기능**: 선택 건물 세대별로 관리비 항목 금액을 세팅.
- **규칙**:
  - 고정 컬럼 `호수 · 이름`(+ 합계). 가변 컬럼은 `fee-item`에 등록된 **건물 유형별 항목**마다 1컬럼([_data-dictionary.md](../../_data-dictionary.md) E). 항목 순서·필수항목(전기·수도료·가스)은 `fee-item` 규칙을 따른다.
  - **일할 계산**: 일자계산 `적용` 항목은 중간 입·퇴실 세대를 **실거주 일수 ÷ 30** 일할([_calculation-rules.md](../../_calculation-rules.md) 1.1). 셀에 일할 근거(체류/총 일수) 툴팁 표기.
  - **도구 버튼** (툴바에는 아래 두 버튼만 있다):
    - `빌라자료추가`(mfFillBld): **선택 건물**의 전월 자료를 이번 달에 반영. 확인 모달 → 중요 건물이면 추가 확인 모달 선행.
    - `전체자료추가`(mfFillAll): **모든 건물**의 전월 자료를 이번 달에 일괄 반영. 확인 모달.
    - **두 버튼 공통 — 전월에서 가져오는 값**:
      - **이월(carry=yes) 항목의 전월 부과액만** 세대별로 상속한다(`fee-item`의 항목별 이월 설정 기준, [_data-dictionary.md](../../_data-dictionary.md) E1). **이월=no 항목은 가져오지 않고 기존값 유지**.
      - **부과기준일(시작일 · 종료일 · 납기일)**도 전월 기준일을 가져와 **모두 +1개월** 이동해 반영한다(예: 전월 납기일 → 그대로 한 달 뒤로).
      - 확인 모달 안내: "전월 자료를 그대로 반영하기 전에 항목과 금액을 반드시 확인해 주세요".
  - **공과금 부과액 자동 채우기**: 별도 `공과금 계산` 버튼은 없다. 공과금 관리에서 산출된 전기·수도·가스 부과액을 세대별 항목으로 끌어오되, 부과액이 미산정이면 **안내 모달**("공과금 관리에서 먼저 부과액을 입력해 주세요")로 안내한다. 공실 세대는 규칙에 따라 0 처리.
  - **행 플래그(범례)**: `공실 사용량`(빨강) · `최근 입주`(초록)([_status-codes.md](../../_status-codes.md) 6절). 음수 값은 빨강(`CLAUDE.md`).
  - 편집(수정 모드)에서 항목 금액 입력. 저장 시 처리일자 스탬프.

### 3.6 신규 입주자 당월 부과 확인
- **기능**: 당월 세팅 이후 신규 입주자 등록 시 해당월 부과 여부 확인.
- **규칙**: 신규 입주 등록 시 "이번 달 관리비를 부과하시겠습니까?" 확인 → 확인: 당월 부과 / 취소: 다음달부터([_calculation-rules.md](../../_calculation-rules.md) 1.1, 기능정의서 C-2). 이 확인은 입주자 등록 흐름과 연동.

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 관리비 항목(유형별·순서·반올림·일자계산·이월) | `fee-item`([_data-dictionary.md](../../_data-dictionary.md) E1) | 항목 변경 시 가변 컬럼 반영 |
| 세대 목록·룸타입·입주일·이름 | 건물 상세/입주민([_data-dictionary.md](../../_data-dictionary.md) C) | 건물 선택 시 |
