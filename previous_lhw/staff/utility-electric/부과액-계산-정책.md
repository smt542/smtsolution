# 공과금 부과액 계산 정책

> 대상: 공과금 관리 — 전기 / 수도 / 가스 (`staff/utility-electric`, `staff/utility-water`, `staff/utility-gas`)
> 범위: 관공서 청구액을 호실별 부과액으로 배분하는 계산 규칙

---

## 1. 기본 개념

관공서는 **고객번호 단위로 총액 하나만** 청구합니다. 이 총액을 그 고객번호에 속한 호실들에게 **사용량(량) 비례**로 나누는 것이 계산의 핵심입니다.

한 건물에 고객번호가 여러 개일 수 있고, 각 호실은 정확히 하나의 고객번호(=라인)에 속합니다. 계산은 **고객번호 단위로 독립 수행**합니다.

---

## 2. 입력값

| 값 | 입력 위치 | 성격 |
|---|---|---|
| 총부과액 | 고객번호 리스트 · 부과액 | 관공서 청구액을 복사·붙여넣기 (할인 반영된 순액) |
| 호실별 량 | 호실별 지침 · 량 | 검침값 (금월 − 전월). 계량기 없으면 고정 량 |
| 호실별 할인금액 | 입주민 상세 (읽기 전용으로 표시) | 정액 할인 (수급자·다자녀·기타) |
| 수동입력 | 호실별 지침 · 수동입력 | 해당 호실 부과액을 금액으로 못 박음 |

**파생값** (자동 계산, 입력 불가): 고객번호의 량·금월량·단가, 호실별 부과액.

---

## 3. 계산 순서

### 1단계 — 수동입력 호실 분리

수동입력된 호실은 금액이 이미 확정이므로 단가 계산에서 **분자·분모 모두에서 제외**합니다.

```
고정액 합계 = Σ(수동입력 호실의 금액)
잔여부과액  = 총부과액 − 고정액 합계
잔여량      = 총량 − Σ(수동입력 호실의 량)
```

> 분모에서 량을 빼지 않으면 단가가 낮게 산출되어 합계가 총부과액과 어긋납니다.

### 2단계 — 할인 되돌리기(gross-up) 후 단가 산출

```
단가 = (잔여부과액 + 잔여호실 할인합계) ÷ 잔여량
```

**왜 할인을 더하는가** — 관공서 총부과액은 이미 할인이 적용된 금액입니다. 그대로 나누면 특정 호실의 할인이 전 호실 단가에 녹아들어 할인 대상이 아닌 호실도 싸게 냅니다. 할인을 더해 단가를 원상복구하면 진짜 단가가 나오고, 할인은 해당 호실에서만 차감됩니다.

### 3단계 — 호실별 부과액

```
수동입력 있음 → 부과액 = 수동입력 금액
수동입력 없음 → 부과액 = max(0, 량 × 단가 − 그 호실 할인)
```

### 4단계 — 할인 캡 수렴

할인이 그 호실 요금(량 × 단가)보다 큰 경우, **요금 한도까지만** 적용하고 초과분은 소멸합니다(이월하지 않음). 사용하지 못한 할인만큼 gross-up 금액을 줄여 단가를 다시 계산하며, 최대 24회 반복해 수렴시킵니다.

### 5단계 — 절사 잔액 흡수

원 단위 반올림으로 생긴 차액을 **수동입력이 아닌 호실**에 분배합니다. 몫(`차액 ÷ 호실 수`)을 먼저 균등 배분하고 나머지를 앞쪽 호실부터 1원씩 더합니다. 음수 차액은 부과액이 0보다 큰 호실에서만 차감해 음수 부과액이 생기지 않게 합니다.

---

## 4. 검산 규칙

각 고객번호(라인)마다 아래가 **항상 성립**해야 합니다.

```
Σ(그 고객번호에 속한 호실 부과액) = 고객번호 부과액
```

증명:
```
Σ호실 = 고정액 합계 + Σ(량 × 단가 − 할인)
      = 고정액 합계 + (잔여부과액 + 할인합계) − 할인합계
      = 고정액 합계 + 잔여부과액
      = 총부과액  ✓
```

---

## 5. 계산 예시

**조건** — 총부과액 100,000원 / 총량 200 / 201호 수동입력 30,000원(량 50) / 301호 할인 4,000원(량 20)

| 단계 | 계산 | 결과 |
|---|---|---|
| 잔여부과액 | 100,000 − 30,000 | 70,000 |
| 잔여량 | 200 − 50 | 150 |
| 단가 | (70,000 + 4,000) ÷ 150 | 493.3 |
| 201호 | 수동입력 고정 | 30,000 |
| 301호 | 20 × 493.3 − 4,000 | 5,867 |
| 나머지 호실 | 130 × 493.3 | 64,133 |
| **검산** | 30,000 + 5,867 + 64,133 | **100,000 ✓** |

## 6. 값 고정 (다음 달 연동)

**량**과 **수동입력**은 자물쇠 토글로 고정할 수 있습니다.

- **저장 방식** — "해당 월부터 이 값 고정"이라는 **시작월 기준 규칙**으로 저장합니다. 미래 월에 값을 미리 복사하지 않습니다.
- **상속** — 다음 달·다다음 달을 열면 그 규칙이 자동 적용되며, 목록에 자물쇠 아이콘 + 옅은 배경으로 표시됩니다.
- **갱신** — 상속된 값을 특정 월에서 수정·저장하면 **그 월부터** 새 고정으로 갱신되고 이전 월은 그대로 유지됩니다.
- **해제** — 자물쇠를 끄면 그 월부터 자동 계산으로 복귀합니다.
- **저장 범위** — 건물 · 유형(전기/수도/가스) · 호수 · 항목별로 독립 저장되어 서로 간섭하지 않습니다.

### 두 고정값의 성격 차이

| 항목 | 의미 | 계산에 미치는 영향 |
|---|---|---|
| 량 고정 | 계량기 없는 호실의 추정 사용량 (예: 3톤 고정) | 분모(잔여량)에 **포함**됨 — 총액을 나누는 기준에 참여 |
| 수동입력 고정 | 계산 결과를 무시하고 금액 확정 | 분자·분모에서 **제외**됨 — 나머지 호실이 잔액을 나눔 |

두 값이 동시에 걸린 호실은 **수동입력이 우선**합니다(부과액이 이미 확정이므로).

## 7. 예외 처리

| 상황 | 처리 |
|---|---|
| 부과액 미입력 (미측정 기간) | 단가·부과액을 계산하지 않고 `-`로 표시. 량은 입력·상속된 값 유지 |
| 잔여량 = 0 (전 호실 수동입력) | 단가 계산 불가 → 전체 량 기준 참고 단가만 표시 |
| 할인 > 그 호실 요금 | 요금 한도까지만 적용, 초과분 소멸 (이월 없음) |
| 공실이지만 량이 측정됨 | 정상 계산. 목록에서 파란색 강조 (좌측 액센트 + 량 값) |
| 관공서 실제 감면액 ≠ 등록 할인액 | 등록 할인액을 신뢰 (관공서에서 확인받아 등록하는 값) |

---

## 8. 확인 필요 사항 (미결)

- 월중 입·퇴실 호실의 **일수 안분** 계산 — 현재 미반영
- 고객번호별 총액 이상값 감지 장치 — 현재는 전월 대비 증감 컬럼으로 담당자가 육안 확인
