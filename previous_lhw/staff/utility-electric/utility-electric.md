## 1. 목적

한전이 **고객번호(라인) 단위 총액**으로 청구한 전기요금을, 그 고객번호에 속한 **호실별 사용량(량) 비례**로 안분·부과하는 화면. 건물·연월을 선택해 고객번호별 총부과액을 입력하고, 호실별 지침(검침값)을 편집하면 부과액이 자동 배분된다. 검침대장 출력도 이 화면에서 한다.

- 배분 계산의 정본은 `staff/utility-electric/부과액-계산-정책.md`이며, 이 화면이 **정본 계산의 기준 화면**이다(수도·가스는 동일 골격).

## 3. UI

### 3.0 상단 헤더
- **기능**: 화면 제목("공과금 관리 › 전기")과 상단 액션.
- **규칙**: 좌측 공통 LNB, 우측 공통 RNB("A/S 접수·퇴실 신청 현황") 공유. 헤더 우측 액션 **`검침대장 출력`**(3.5) · **`전체 이월`**(선택 건물의 이번 달 지침·설정을 다음 달로 일괄 이월).

### 3.1 조회조건 / 전체 건물 (좌측 패널)
- **기능**: 대상 **연·월분**과 **건물** 선택.
- **규칙**:
  - 상단 **연도**(예: 2026년) · **월분**(예: 7월분) 드롭다운(커스텀 드롭다운, `CLAUDE.md`). 선택 시 그 달 기준으로 우측 표가 갱신.
  - **건물명·주소 검색**(입력 즉시 필터). 표 컬럼: `코드 · 건물명 · 주소 · 전기(고객번호 수)`. 헤더 고정, 선택 행은 브랜드 배경 유지(hover에도 유지).

### 3.2 편집 바 (우측 상단)
- **기능**: 선택 건물·기간 표시 + **부과기준일** + 편집 액션.
- **규칙**:
  - 좌측에 `건물명` / `2026년 7월분 부과 편집` 표기.
  - **부과기준일** `시작일 ~ 종료일`(달력 방식, [_service-policy.md](../../_service-policy.md) 5절). 기본 **전월 16일 ~ 당월 15일**([_calculation-rules.md](../../_calculation-rules.md) 2.4, 건물별 설정). 부과기준일 미설정 시 호실 표는 잠금(3.4의 "부과기준일 먼저 설정" 안내).
  - 액션: 평소 `수정`만 노출 → 수정 진입 시 `계산`·`저장`·`취소(X)`로 전환. 건물 변경 시 편집 중이면 조회 모드로 복귀.

### 3.3 고객번호 표 (우측)
- **기능**: 선택 건물의 고객번호(라인)별 총부과액·집계를 표시. 행 클릭 시 해당 라인 호실만 필터.
- **규칙**:
  - 컬럼: `L(라인) · 고객번호 · 고지금액 · 부과액 · 량 · 단가 · 금월량 · 전월량 · 감면 · 이사`([_data-dictionary.md](../../_data-dictionary.md) D1).
  - **부과액**은 한전 청구 총액(할인 반영 순액)을 복사·붙여넣기로 입력. **량·단가·금월량·전월량**은 자동 파생(입력 불가).
  - **고지금액 = 부과액 × 1.11**(전기 11% 가산). 근거: [_calculation-rules.md](../../_calculation-rules.md) 2.3, 정본 계산 정책.

### 3.4 호실별 지침 표 (우측)
- **기능**: 호실별 검침 지침 입력·편집 → 부과액 자동 배분.
- **규칙**:
  - 컬럼: `호수 · 입주일자 · 퇴실일자 · 퇴실예정일자 · 전월 · 금월 · 량 · 전.량 · 증감 · 수동입력 · 할인유형 · 할인금액 · 부과액 · 적요 · 처리일자 · 부과기준 · 이름 · 전화 · 라인 · 인원`([_data-dictionary.md](../../_data-dictionary.md) D2).
  - **량 = 금월 지침 − 전월 지침**. 계량기 없는 호실은 **고정 량**(예: 3톤). **호실 부과액 = max(0, 량×단가 − 할인)**, 수동입력 시 그 금액 고정. 단가·gross-up·할인 캡·절사 흡수·검산은 **정본 `부과액-계산-정책.md`가 근거**이며 이 화면은 재정의하지 않는다([_calculation-rules.md](../../_calculation-rules.md) 2.1 요약).
  - **할인금액**(수급자·다자녀·기타)은 입주민 상세 값을 **읽기 전용 표시**. 등록 할인액을 신뢰(정본 7장).
  - **값 고정(자물쇠)**: `량`·`수동입력`은 자물쇠 토글로 "해당 월부터 고정"으로 저장, 다음 달 자동 상속(자물쇠 아이콘+옅은 배경). 상세는 정본 6장.
  - **행 플래그(범례)**: `퇴실 예정`(파랑) · `공실 사용량`(빨강, 공실인데 사용량 있음) · `최근 입주`(초록)([_status-codes.md](../../_status-codes.md) 6절).
  - **증감**은 전월 대비 차이, 음수는 빨간색(`CLAUDE.md`). 고객번호별 총액 이상값은 **증감 컬럼 육안 확인**으로 처리(자동 감지 없음).
  - **미측정 기간**(부과액 미입력): 단가·부과액을 `-`로 표시, 량은 상속값 유지(정본 7장).
  - **월중 입·퇴실 호실의 일수 안분은 하지 않는다**(검침 사용량 기준 월 단위 배분, 정본 8장).

### 3.5 검침대장 출력 (모달)
- **기능**: 건물별 검침대장 인쇄물 출력.
- **규칙**: 건물 **다중 선택 + 전체선택** 후 인쇄. 코드·건물명·주소 검색. 계량기 없는 호실은 "계량기없음(N톤 고정)" 적요·고정 사용량 표기. 회사명 워터마크 포함. 서식·구성은 [_output-forms.md](../../_output-forms.md) 2절.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 건물 미선택 | "건물을 선택해 주세요" 안내, 표 비표시 |
| 기준일 미설정 | 건물 선택·부과기준일 없음 | "부과기준일을 먼저 설정해 주세요" + 설정 버튼 |
| 성공 | 건물·기간 선택 완료 | 고객번호 표·호실별 지침 표 표시 |
| 편집 중 | `수정` 클릭 | 지침·수동입력·부과액 입력 활성, 계산/저장/취소 노출 |
| 저장 완료 | `저장` 성공 | 처리일자 갱신 + 완료 토스트 |
| 결과 없음 | 건물 검색 0건 | "검색 결과가 없습니다" |
| 에러 | 조회·저장 실패 | 실패 안내·재시도([_service-policy.md](../../_service-policy.md) 6절) |
