## 1. 목적

관리업체 직원(staff)이 발급받은 계정으로 **업무 시스템(ERP)에 로그인**하는 화면. 인증 성공 시 업무 화면으로 진입한다. 계정 발급·권한은 마스터 관리자가 별도로 관리하며, 이 화면은 **아이디·비밀번호 입력과 인증**만 담당한다.

## 2. 접근

- **누구나 접근(로그인 전).** 권한 게이트 없음 — LNB/RNB 등 공통 인프라도 노출하지 않는 독립 화면.
- 계정 자체는 마스터 관리자가 `staff-management`에서 발급·관리(회원유형 마스터/일반, [_status-codes.md](../../_status-codes.md) 9절). 로그인 후 접근 범위는 부여된 LNB 권한을 따른다([_permission-matrix.md](../../_permission-matrix.md) 2절).

## 3. UI

### 3.0 레이아웃
- **기능**: 좌측 브랜드 소개 패널 + 우측 로그인 폼 2단 구성.
- **규칙**: 좌측은 서비스명("관리비서")·소개 카피. 우측이 실제 입력 영역.

### 3.1 아이디
- **기능**: 계정 아이디 입력.
- **규칙**: "아이디를 입력해 주세요" placeholder. 미입력 후 로그인 시 "아이디를 입력해 주세요" 오류·포커스 이동.

### 3.2 비밀번호
- **기능**: 비밀번호 입력.
- **규칙**: 기본 마스킹(●) 입력. **표시/숨김 토글**(눈 아이콘)로 평문 확인 가능. 미입력 후 로그인 시 "비밀번호를 입력해 주세요" 오류·포커스 이동.

### 3.3 자동 로그인
- **기능**: 다음 접속 시 아이디 유지.
- **규칙**: 체크박스. 체크 시 아이디를 로컬에 저장(프로토타입 localStorage), 다음 방문 시 자동 채움. 해제 시 저장값 제거.

### 3.4 로그인 버튼
- **기능**: 인증 실행.
- **규칙**:
  - 클릭 또는 Enter로 제출. 아이디·비밀번호 검증 후 진행.
  - 진행 중 "로그인 중…" 표시 + 버튼 비활성(중복 제출 방지).
  - 성공 시 "로그인되었습니다" 토스트 후 업무 화면(수납관리·민원접수)으로 이동.
  - 실패 시 폼 상단 오류 영역에 사유 표시(원본 입력 유지).

### 3.5 계정 문의 안내
- **기능**: 계정 발급·문의 경로 안내.
- **규칙**: "계정 문의는 마스터 관리자에게 요청해 주세요 · 문의 : 042-632-8770" 고정 안내. 이 화면에는 **회원가입·비밀번호 찾기 기능 없음**(계정은 마스터가 발급).

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 기본 | 진입 | 빈 폼(자동 로그인 저장 시 아이디 채움) |
| 검증 오류 | 아이디/비밀번호 미입력 | 인라인 오류 문구·포커스 이동 |
| 진행 중 | 로그인 클릭 | "로그인 중…" + 버튼 비활성 |
| 성공 | 인증 통과 | "로그인되었습니다" 토스트 후 이동 |
| 실패 | 인증 실패 | 오류 영역에 사유 표시, 입력 유지 |
