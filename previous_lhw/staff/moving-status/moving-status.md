## 1. 목적

전 건물의 이사정산 내역을 **전기·가스 공과금을 한 표로 통합**해 조회·출력하는 화면. 세대별로 전기·가스 검침·정산금액·입금일자, 당월계, 입력검사 결과, 청소비용, 정산 상태를 한눈에 보고, **입금일자·청소비용**을 편집·저장한다. 개별 채널 화면(`moving-elec`/`moving-water`/`moving-gas`)이 채널별 조회라면, 이 화면은 **전기·가스 통합 현황** 성격이다. 이사정산 입력·계산은 `moving-settlement`에서 수행한다.

## 2. 권한  ([_permission-matrix.md](../../_permission-matrix.md) 2절)

| 사용자 | 접근 |
|---|---|
| staff (마스터) | O |
| staff (일반) | LNB "이사정산" 권한 부여 시 O (계정별 설정형 ◐) |

- 마스터가 `staff-management`에서 계정별로 이사정산 메뉴 접근을 부여/제한한다.
- 편집 가능한 값은 **전기·가스 입금일자**와 **청소비용**이다.

## 3. UI

### 3.0 공통 프레임
- **기능**: 공통 LNB·RNB 공유. 브레드크럼 "이사정산" + 제목 "전체 이사조회".
- **규칙**: LNB/RNB는 공통 인프라. 본문은 조회 툴바 + 통합 결과 표.

### 3.1 조회 툴바
- **기능**: 조회 조건 설정 + 출력·저장 액션.
- **규칙**:
  - **조회일 기간**: 시작(년·월) ~ 종료(년·월) 드롭다운.
  - **상태 세그**: `전체 · 완결 · 미결`([_status-codes.md](../../_status-codes.md) 2절). 기본 `전체`.
  - **정렬 세그**: `코드순 · 일자순`.
  - **검색**: "건물명·소재지" 즉시 필터.
  - 날짜는 드롭다운/달력 방식. 드롭다운은 커스텀(`.uc-dd`), 네이티브 `<select>` 금지(`CLAUDE.md`).
  - 채널 화면과 달리 **신청일 필터는 없다**(기간·상태·정렬·검색만).
  - **출력** 버튼: 통합표 인쇄(3.3). **저장** 버튼: 입금일자·청소비용 반영(3.2).

### 3.2 통합 결과 표
- **기능**: 전기·가스를 한 행에 통합한 이사정산 현황.
- **규칙**:
  - 컬럼: **NO · 소재지 · 건물명 · 호실 · 해약일자 · 입주일 · [전기] 전기검침·전기이주·량·금액·입금일자 · [가스] 가스검침·가스이주·량·금액·입금일자 · 당월계 · 입력검사 · 청소비용 · 상태** ([_data-dictionary.md](../../_data-dictionary.md) G2 통합).
  - **건물 단위 소계 행**: 같은 건물 세대들 사이에 전기금액·가스금액·당월계 합계 소계 행을 삽입.
  - **량 = 검침 − 이주**(전기·가스 각각, [_calculation-rules.md](../../_calculation-rules.md) 6절 ②). **금액·당월계**는 `moving-settlement` 산출값 조회(재계산 안 함).
  - **입금일자(전기·가스)**: 셀 인라인 편집(달력 방식).
  - **청소비용**: 셀 인라인 편집(숫자).
  - **입력검사**: 정산 입력 완성도 검증 결과 표시. **필수 항목(검침·정산금·입금일 등) 누락 시 '이상'으로 표시**(금액 불일치까지는 판정하지 않음).
  - **상태**: `완결 · 미결` 칩([_status-codes.md](../../_status-codes.md) 2절). 완결은 강조 표시.
  - 편집 시 「저장」 활성 → "변경사항 N건을 저장했어요" 토스트.
  - 하단 합계(tfoot): 건수·전기금액·가스금액·당월계·청소비용 합계. 음수는 빨간색(`CLAUDE.md`).

### 3.3 출력(통합표 서식)
- **기능**: 조회 결과 인쇄.
- **규칙**: 표 컬럼 동일(전기·가스 통합) + **회사명 워터마크**([_output-forms.md](../../_output-forms.md) 0절). 결과 없으면 "출력할 내역이 없어요". 상세는 [_output-forms.md](../../_output-forms.md).

### 3.4 RNB 퇴실 카드 연동
- **기능**: 공통 RNB "A/S 접수·퇴실 신청 현황"과 연결.
- **규칙**: 퇴실 신청 처리 시 "퇴실 신청을 처리 완료했어요" 토스트(공통 RNB 동작).

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 결과 없음 | 조건 매칭 내역 없음 | "조회 결과가 없어요 · 조회 기간이나 검색어를 바꿔 보세요" |
| 성공 | 내역 있음 | 통합표 + 건물 소계 + 합계 |
| 저장 비활성 | 편집 없음 | 「저장」 비활성 |
| 성공(저장) | 입금일자·청소비용 저장 | "변경사항 N건을 저장했어요" 토스트 |
| 제한(권한) | 이사정산 메뉴 미부여 | LNB 숨김 |
| 에러 | 저장 실패 | 실패 안내·재시도([_service-policy.md](../../_service-policy.md) 6절) |
