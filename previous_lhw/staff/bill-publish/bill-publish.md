## 1. 목적

부과 확정된 관리비 **고지서 및 부속 서류를 출력**하고, 건물주·관계처에 **팩스로 발송**하는 화면. 문서 종류를 카드로 고르면 공통 출력 모달에서 기간·건물을 선택해 미리보기·인쇄·발송한다.

## 3. UI

### 3.0 문서 카드(랜딩)
- **기능**: 출력/발송할 문서 종류 선택.
- **규칙**: 3개 섹션의 카드 —
  - **고지서 출력**: `지로 고지서`(QR·회사명·자동이체 표시 자동 포함)
  - **부속 서류**: `조정명세서`(전월 대비 조정 내역, 건물별) · `자동이체 세대 출력`(자동이체 세대 목록·청구금액)
  - **발송**: `팩스 발송`(건물주·관계처)
  - > **A4 고지서·카톡 고지서는 이 화면에서 제거됨**(발송은 팩스만). 카카오 고지서 신청·수신은 resident 앱([_output-forms.md](../../_output-forms.md) 1절).

### 3.1 출력 모달 (공통)
- **기능**: 기간·건물 선택 + 미리보기 + 인쇄/다운로드/발송. 4개 문서 종류가 이 모달을 공유.
- **규칙**:
  - 상단: **출력 연도(2019~2026) · 월분(1~12) · 검색(코드·건물명·주소)**. 자동이체 출력은 **부과 그룹 세그(전체/1~5)** 추가.
  - 건물 선택 목록(코드·건물명·주소, 다중 선택) → 선택 세대/호수. 미리보기 확대/축소.
  - 하단: 선택 카운트 + `인쇄`(지로·조정), `다운로드`(자동이체 CSV), `발송`(팩스). 건물 미선택 시 비활성.

### 3.2 지로 고지서
- **기능**: 지로 서식 고지서 미리보기·인쇄.
- **규칙**: QR·회사명·자동이체 표시 자동 포함.
  - **건물 → 세대(호수) 선택**: 건물 선택 후 그 건물의 호수 목록(호수·세대주·핸드폰·이체)에서 세대를 체크해 출력 대상을 지정한다.
  - **미리보기 스코프**: `개별 / 전체` 토글 — 선택 세대를 개별로 볼지, 전체를 볼지 전환.
  - **스탬프 토글**: `재발행 · 단수 · 자동이체`.
  - **납기일**: 이 모달에서 수정하지 않는다. **`management-fee-setting`(관리비 부과 세팅)에서 해당 월분에 설정한 납기일**이 지로 고지서에 반영된다.
  - **이름/코드 출력**: 모달 토글 없음. 세대별로 **`tenant-detail` 5.고지서의 "고지서 이름 출력 유형"**(이름 미출력 / 이름 출력 / 코드번호 출력, [_status-codes.md](../../_status-codes.md) 4절)을 따른다.
  - 계산·항목은 [_calculation-rules.md](../../_calculation-rules.md), 출력 규칙은 [_output-forms.md](../../_output-forms.md) 1절.

### 3.3 자동이체 세대 출력
- **기능**: 자동이체 세대 청구 목록 출력·다운.
- **규칙**: 부과 그룹별 필터. CSV 다운로드(`효성CMS_자동이체청구_YYYYMM[_N그룹].csv`) + 인쇄. 포맷은 [_data-exchange.md](../../_data-exchange.md) 3절.

### 3.4 팩스 발송
- **기능**: 고지서 팩스 발송.
- **규칙**: 발신 팩스번호(선택) · 수신 팩스번호(9자리↑ 검증) · 건물별 요약(N세대·N장). 발송 채널·과금은 [_notification-policy.md](../../_notification-policy.md).
