## 1. 목적

본사 **팝빌 발송 포인트**(알림톡·문자·팩스 발송 시 차감)의 **잔액·소진·충전 이력**을 관리하는 화면. 포인트는 **본사 단일 풀**(전 테넌트 공통)이며, 충전은 마스터·운영이 수행한다.

## 3. UI

### 3.0 헤더/안내
- **기능**: 제목 + 포인트 정책 안내.
- **규칙**: "포인트 관리" + "팝빌 포인트 · **1원 = 1P** · 알림톡·문자·팩스 **공통 차감**".

### 3.1 잔액·충전 카드
- **기능**: 현재 잔액 + 충전.
- **규칙**: **현재 잔액**(임계 이하이면 "충전 필요" 경고) · **「포인트 충전」**(마스터·운영, 3.4) · **이번 달 사용량(P)**. "충전 필요" 경고 **임계 잔액**은 `admin/settings`(잔액 알림 기준)에서 설정.

### 3.2 채널별 소진
- **기능**: 당월 채널별 사용 현황.
- **규칙**: **알림톡 · 문자 · 팩스** 각 **소진 P · 건수**, **이번 달 합계**.

### 3.3 충전 이력
- **기능**: 충전 내역.
- **규칙**: **충전 금액(P) · 일자 · 충전자** 목록, 페이지네이션.

### 3.4 포인트 충전 모달
- **기능**: 충전 기록.
- **규칙**: **충전 금액 입력 → 이력에 기록**(수동). **실결제 연동 아님**(실제 팝빌 충전은 외부에서 하고 여기서는 금액·이력만 관리). 마스터·운영. 확인 모달.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 성공 | 데이터 있음 | 잔액 + 소진 + 이력 |
| 충전 필요 | 잔액 임계 이하 | "충전 필요" 경고 |
| 확인 | 충전 시도 | 확인 모달 |
| 로딩/에러 | 조회 중·실패 | 공통 표준 준용 |

---

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 포인트 잔액·소진 | 팝빌 포인트/발송 데이터 | 진입 시. **본사 단일 풀** |
| 채널별 소진(건수·금액) | 발송 데이터(청구 `admin/usage`와 동일 소스) | 진입 시 |
| 충전 이력 | 충전 기록 | 충전 모달 저장(마스터) |

- 발송 트리거 없음. 실제 발송·차감 주체는 발송 인프라(팝빌).
