## 1. 목적

본사 콘솔 **내부 계정을 조회·추가·수정·정지**하는 화면. 계정 관리는 **마스터·운영**만 가능하다.

---

## 2. 권한

| 사용자 | 접근 |
|---|---|
| admin **마스터 · 운영** | O — 계정 추가·수정·정지 |
| admin 지원·영업 | 조회만(관리 불가) |

- **역할(마스터·운영·지원·영업)은 "회원 분류" 라벨**이다. 단, **계정 관리(추가·수정·정지) 권한은 마스터·운영에게만** 있다.

---

## 3. UI

### 3.0 헤더
- **기능**: 제목 + 계정 추가.
- **규칙**: "계정·권한" + **「＋ 본사 계정 추가」**(마스터·운영) → 추가 모달(3.2, 신규 모드).

### 3.1 계정 목록 표
- **기능**: 본사 계정 목록 + 수정 진입.
- **규칙**:
  - 컬럼: **이름 · 역할 · 아이디 · 전화번호 · 메모 · 상태 · 생성일**.
  - 역할: `마스터`/`운영`/`지원`/`영업`(분류 라벨). 상태: `활성`/`정지`.
  - **행 클릭 → 수정 모달**(마스터·운영).

### 3.2 계정 추가/수정 모달 (동일 폼)
- **기능**: 신규 등록 · 기존 수정.
- **규칙**:
  - 입력: **이름 · 역할(마스터/운영/지원/영업) · 아이디 · 비밀번호(신규 시) · 전화번호 · 메모 · 상태(활성/정지)**.
  - **상태 `정지`** → 해당 계정의 콘솔 로그인 차단.
  - 확인 모달 후 저장. 필수 미입력 시 인라인 에러.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 성공 | 계정 있음 | 목록 |
| 확인 | 추가·수정·정지 시도 | 확인 모달 |
| 권한 없음 | 마스터·운영 아님 | 관리 액션 비노출/차단 |
| 로딩/에러 | 조회 중·실패 | 공통 표준 준용 |
