# 주택관리ERP — 데이터 사전 (Data Dictionary)

> 서비스가 다루는 **엔티티와 필드**의 표준 정의. 화면 PRD는 필드를 새로 만들지 말고 이 사전을 참조·확장한다. (62개 화면 실제 검토 기반)
> 열거형 값은 [_status-codes.md](_status-codes.md) · 상위 참조 [_service-policy.md](_service-policy.md)
> 표기: `*`=필수, (다중)=여러 개 입력, 값 목록은 상태코드 문서 참조.

---

## A. 관리업체 · 본사 (admin 도메인)

### A1. 관리업체(테넌트)
`상호*, 대표자*, 사업자등록번호*(000-00-00000), 대표 전화*, 팩스*, 이메일*, 주소*, 운영 시간, 최초 계약일, 계약 시작일*, 계약 만료일*, 자동연장, 계약 형태, 이용 범위, 상태, 관리자 아이디*, 초기 비밀번호(숫자 4자리), 계약서 사진(다중)`
파생/집계: `건물 수, 세대 수, 직원 수, 세입자 수, 포인트 잔액, 90일 내 만료 여부`
사용: admin `tenants`, `tenant-detail`

### A2. 본사 계정
`이름*, 역할*, 아이디*, 비밀번호(숫자 4자리), 전화번호*(010-0000-0000), 메모, 상태, 생성일`
사용: admin `accounts`, `login`

### A3. 포인트 · 충전이력
포인트: `잔여 포인트(P), 이번 달 사용(P), 채널별 소진(알림톡·문자·팩스 각 P·건수)` (1원=1P)
충전이력: `날짜, 충전 금액(P), 처리자, 비고`
사용: admin `points`

### A4. 청구서 (발송비)
`청구서 번호(INV-YYYYMM-nn), 발행일, 공급자(예금주·사업자등록번호·담당), 공급받는자(업체·발송월), 항목별(알림톡·문자·팩스 건수·단가·금액), 공급가액, 부가세(10%), 청구 합계, 입금 계좌·기한, 상태`
사용: admin `usage`, 설정값은 `settings`(단가·청구계좌·청구기준)

## B. 건물

### B1. 건물 기본
`건물 코드*, 건물명, 건물 유형, 공동현관(도어 비밀번호), 주소*, 고지서 부과 그룹 유형(1~5), 수도 고객번호 보유 수, 상시 공지문(세입자 앱 홈 건물공지에 노출, 비우면 미표시), 계약일, 해지일, 등록일, 건물 메모`
사용: building-list/detail/register, mobile-building

### B2. 건물주
`건물주명, 건물주 전화번호(주), 건물주 전화번호(부), 건물주 주소, 비고`

### B3. 담당자
`사무 담당자*(관리), 현장 관리자*(검침), 청소 담당자`

### B4. 협력업체(건물별 상세) — 구분별 공통 `업체명·전화번호·계좌번호·계약서 사진(최대 10)·비고` + 구분별 추가 필드
- 청소: `청소 횟수·요일·금액` / 정화조: `구분·날짜·금액·용량` / 인터넷: `고객번호·인터넷전화·금액·출력·납부일·만료일`
- 전기안전: `관리금액·안전구분` / 유선방송정보: `납부일·인터넷전화·금액`
- 승강기보수: `승강기금액·설치일·담당자·구분·계약일자` / 승강기정기검사: `검사일·금액·안전관리·선임일·일련번호·고유번호·운행층·비상통화`
- 소방검사: `검사일·금액·담당·보고일자·선임일자` / CCTV: `카메라대수·녹화보관일수·관리금액·담당자·설치일·계약일`
사용: building-detail, vendor-management(마스터)

### B5. 건물 공과금 부가정보 (수도/공용전기/전기/가스 각 블록)
`고객번호, 성명/계약자, 입금(당월/전월), 계산(자동/수동), 계산법, 이체구분, 검침일(1~31), 고지기간, 고지기간 출력(Y/N), 메모` + `가스회사, 가스전화, 계좌번호, 부과시 참조사항`

### B6. 적립금 / 장기수선
적립금: `유형, 메모`
장기수선비 내역: `일자, 번호, 적요, 적립금입금, 적립금출금, 차인잔액, 영수증 사진` / 요약 `입금합계·출금합계·현잔액`
사용: long-term-repair, building-detail

## C. 세대 · 입주자

### C1. 기본
`호실*, 입주자명, 입금자명, 룸, 인원, 평형, 입주일, 입주예정일, 퇴실일자, 할인 유형, 할인 금액, 기타적요, 이사정산시 적요`

### C2. 연락처·차량
`전화번호*(다중, 주/부), 차량번호(다중), 문자 수신(동의/거부), 알림톡 수신(동의/거부), 홈피 비밀번호`
> 알림톡·단체문자 발송 시 세대 **주번호·부번호 모두 수신 대상**(정책서 참조).

### C3. 관리비·부과
`관리비, 이사청소, 인상액, 부과금 여부(Y/N), 부과일, 이체 방식, 효성 회원번호(숫자 8자리), 계약번호(숫자 3자리), 연체료 부과 여부(O/X), 단수 출력 여부(O/X), 부과시 참조사항`

### C4. 공과금 고객번호
`수도/전기/공용전기/가스 고객번호·계량기 번호, 한전고객번호, 한전계기번호`

### C5. 고지서
`출력 여부, 이름 출력 유형, 발송(문자/우편), 인증`

### C6. 전출정보(퇴실 이력, 읽기 표)
`이사일, 이름, 집전화, 전화번호(주/부), 입주일`
> 개인정보 — 보유기간 정책 적용(계약종료 후 5년, [_service-policy.md](_service-policy.md) 8절).

### C7. 임대 정보
`임대구분, 개시일, 만료일, 보증금, 보증금일, 임대료, 전세금, 은행, 계좌`

### C8. 부동산 정보
매물: `물건명·주소·구분·거래형태·면적(㎡)·보증금·전세금·월세·관리비 내용·입주가능일·위치` / 시설정보 / 이사정산체크(최대 24항목)
사용(C1~C8): tenant-detail, tenant-register, building-list

## D. 공과금 검침 · 부과

### D1. 고객번호 표 (건물·고객번호 단위)
`라인(L), 고객번호, 고지금액, 부과액, 량, 단가, 금월량, 전월량, 감면, 이사` (가스/수도는 추가: `월·수동입력·할인금액·전월금액·전단가·금-전1·금-전2`)
파생: `고지금액 = 부과액 × 1.11`(전기)

### D2. 호실별 검침 지침 표
`호수, 입주일자, 퇴실일자, 퇴실예정일자, 전월(지침), 금월(지침), 량, 전.량, 증감, 수동입력, 할인유형, 할인금액, 부과액, 적요, 처리일자, 부과기준, 이름, 전화, 라인, 인원`

### D3. 최근 이력 / 검침대장
이력: `일시(YYYY-MM), 고지금액, 증감, 부과액, 부과액 증감, 단가, 증감` (최근 6개월)
검침대장(출력물): `년/월분, 주소·빌라명, 키번호, 수도/전기 정보, 호별 지침·사용량·금액, 소계`
> 계량기 없는 호실: "계량기없음(N톤 고정)" 적요·고정 사용량.
사용: utility-electric/water/gas, utility-lookup(고객번호 조회), mobile-meter, mobile-utility-charge

### D4. 고객번호 조회(전용)
`코드, 빌라명, 주소, 라인, {수도/공용전기}고객번호, 일금일(1~28), 구분, 계산, 기타적요`

## F. 수납 · 미납

### F1. 수납 이력(월별)
`처리, 년월, 당월계, 연체, 수납액, 수수료, 수납일자, 은행, 구분, 비고, 기한` / 합계 `미납·연체료·미납합계`

### F2. 월별 부과금액
`년월(건수), 당월분, 수수료, 당월수납액, 연체료, 실수납액, 미납액, 납기내금액`

### F3. 미납 내역
`동호(코드), 거래처명(건물명), 년월, 연체(개월), 미납액, 납.연체료, 납.후연체, 연체료계, 합계, 비고, 전화, 이름`

영수증: `건물·호실·세대주, 년월, 당월계, 연체료, 수납액, 수납일자, 은행, 합계`

### F5. 자동수납 / 자동이체
지로·은행: `지로입금일, 수납일, 구분, 동, 빌라명, 호, 년, 월, 수납액, 에러체크` / 효성CMS: `회원번호, 청구금액(엑셀 대량청구)`
사용: receipt-management, payment-processing, overdue-management

전기 추가: `계기번호, 고객번호, 한전입금일` / 통합(status): `전기·가스 검침·이주·량·금액·입금일, 당월계, 입력검사, 청소비용, 상태`

### G3. partner 이사정산 (mobile-ms-new) — 상세판
`퇴실일자, 계산일수(기준·부과)` / 공과금(전기·수도·가스: 전월지침·이사지침·단가·입금계좌·입금일·사용량·금액) / 관리비 항목(일반관리비·청소비 일할, 승강기·수선유지·화재보험: 부과액·정산액·가수금·가수금연락처) / 기타(항목명·금액, 최대 15) / 청소(담당·처리·완료일·금액·계좌·적요) / 정산(수납액·최종수납일) / 정산체크(24) / 비고 / 합계(공과금·관리비·기타·청소·미납·수납·미수금)
