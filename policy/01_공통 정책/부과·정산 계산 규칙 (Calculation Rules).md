# 주택관리ERP — 부과·정산 계산 규칙서 (Calculation Rules)

> 관리비·공과금·연체·이사정산의 **계산식**을 한 곳에 정의한다. 여러 화면이 같은 방식으로 계산해야 하므로 공통으로 관리한다. 화면 PRD는 계산식을 새로 정의하지 말고 이 문서를 참조한다.
> 상위 참조: [_service-policy.md](_service-policy.md) · 필드 [_data-dictionary.md](_data-dictionary.md) · 코드값 [_status-codes.md](_status-codes.md)
> **공과금 호실별 배분(고객번호 총액 → 호실 안분)의 상세 규칙은 별도 정본:** `staff/utility-electric/부과액-계산-정책.md`

---

## 1. 관리비 항목 계산 (fee-item 규칙)

각 관리비 항목은 세 가지 속성으로 계산 방식이 결정된다(항목별 설정, `fee-item`).

### 1.1 일자 계산 (일할)
- **적용**: 실거주 일수로 안분(중간 입·퇴실 반영). 고정금액이 아니라 거주 일수 비율로 부과. **분모는 고정 30일**(그 달 실제 일수와 무관).
  ```
  부과액 = 월 기준금액 × (실거주 일수 ÷ 30)
  ```
- **안함**: 고정금액(일수와 무관하게 정액).
- 중간입주자 일할 부과는 서비스 요구사항(기능정의서 C-2). 신규 입주 등록 시 해당 월 부과 여부를 확인(팝업).

### 1.2 반올림
| 옵션 | 처리 |
|------|------|
| 절상 | 무조건 10원 올림 |
| 4사5입 | 일반 반올림 |
| 절하 | 무조건 10원 내림 |
| 그대로 | 반올림 미적용 |

### 1.3 이월
- **이월**: 전월 부과금액을 다음 달에 유지(예: 미확정·분납 항목).
- **안함**: 매월 새로 산정(예: 수리비는 이월 안 함).

## 2. 공과금 계산 (전기·수도·가스)

### 2.1 호실별 배분 — 정본 참조
관공서는 **고객번호 단위 총액**으로 청구하고, 이를 호실별 **사용량(량) 비례**로 안분한다. 수동입력 분리 → 할인 gross-up 단가 → 호실 부과액 → 할인 캡 수렴 → 절사 잔액 흡수의 상세 절차와 검산식은 **`staff/utility-electric/부과액-계산-정책.md`가 정본**이다. 여기서는 요약만 둔다.

```
사용량(량)   = 금월 지침 − 전월 지침   (계량기 없으면 고정 량, 예: 3톤)
단가         = (잔여부과액 + 잔여호실 할인합계) ÷ 잔여량
호실 부과액  = max(0, 량 × 단가 − 그 호실 할인)   (수동입력 시 그 금액 고정)
검산: Σ(호실 부과액) = 고객번호 부과액
```
- **단가 상수(기본)**: 전기 120 · 수도 800 · 가스 950 (참고값, 실제는 위 배분 계산).
- **계량기 없는 호실**: 월 고정 사용량 지정(예: 매월 3톤/5톤 자동 고정).

### 2.2 수도 할인 (수급자·다자녀)
- 대상 세대에 **정액 할인 자동 적용**, **퇴실 시 리셋**.
- 관공서 총액은 이미 할인 반영 상태 → 단가 산출 시 할인을 **되돌려 더한 뒤(gross-up)** 나누고, 할인은 해당 호실에서만 차감(2.1 정본 참조).

### 2.3 고지 금액 (부가금 포함)
```
고지금액(전기) = 부과액 × 1.11
```
- 전기는 부과액에 11% 가산해 고지금액 산출. (수도·가스 등 채널별 부가 규칙은 해당 화면 PRD에서 확정.)

### 2.4 부과기간·기준일
- 부과기준일 기본 **전월 16일 ~ 당월 15일**(건물별 설정 가능).
- 건물별 검침일·부과기간(전월/당월), 출력 Y/N 설정.

## 3. 연체료

- 방식: **단리** 기준(설정에서 단리 on/off).
- 경과 **개월수별 요율(%)** 을 미납액에 적용(1~12개월차 요율을 `setup`에서 건물별 설정).
  ```
  연체료 = 미납 원금 × 경과 개월수별 요율(단리 누적)
  합계   = 미납 원금 + 연체료
  ```
- 세대별 **연체료 부과 여부(O/X)** 로 대상 제어(`tenant-detail`).
- **수동 연체료**(수납 이력 `추가` 행 연체 입력, 0291): 그 달 연체료를 자동 계산 대신 지정 금액으로 둔다(미납 원금이 남은 달만).
- **수.연(연체료 이전, 0292)**: 그 달 연체료를 나눈 시점 금액으로 미수금에 고정한다. 모든 화면이 같은 규칙으로 계산한다(0293·0295).
  ```
  미납 원금     = 당월계 − (연체료 이전 행에서 받은 수납을 뺀) 수납 합계
  그 달 연체료  = max(자동·수동 연체료 − 나눈 연체료, 0) + 아직 받지 못한 연체료 미수금
  ```
  - 원금을 다 냈어도 연체료 미수금이 남은 달은 **미납 달**로 본다(미납 세대·개월 수 포함).
  - 적용 화면: 수납 이력 · 미납관리(빌라 미납내역 포함) · 대시보드 미납 세대 수 · 정산서(미납연체료) · 고지서 이월 미납/연체료 · 세입자 관리비 내역·상세·공유 링크(미수금만 남은 달은 `부분납부`) · 이사정산 ③ 미납 합산·자동수납(원금만) · 파트너 검침 카드 미납·입주자 수납 내역.

## 4. 단전·단수 예고 (미납 독촉)

- **2개월 이상 연체** 시 **3개월째 고지서에 단전·단수 예고 인쇄**(개월수 임계는 `setup`에서 변경 가능).
- 독촉 문자 대상: 연체 2개월↑ **AND** 합계 10만원↑ 세대 자동 추출(`overdue-management`).

## 5. 端數(단수) 표기 — 고지 금액 끝자리

- 고지 금액의 끝자리 절사/표기를 세대별 **단수 출력 여부(O/X)** 로 제어(`tenant-detail`).
- 고지서 출력 화면에서 **단수표기·단수해지** 설정 가능(`bill-publish`).
> ⚠️ 용어 주의: 위 4장 "단전·**단수(斷水)**"(수도 끊음 예고)와 본 5장 "**단수(端數)**"(금액 끝자리)는 다른 개념이다.

## 6. 이사정산 계산

퇴실 세대의 최종 정산액. 퇴실일까지 일수로 관리비를 산출하고 공과금·미납을 합산한다.

```
① 관리비        = 관리비 항목 일할 계산(1.1) 합계 (퇴실일까지)
② 공과금        = 이사 검침(최종−이주 지침) × 단가 (전기·수도·공용전기·가스)
③ 미납 합산     = 미납관리비 + 미납액(연체료 포함)
④ 청소비·기타   = 청소비 + 기타 항목
정산요금 = ① + ② + ④ + ③ − 당월수납액
미수금   = 정산요금 − 수납액   (음수면 환급, 미수금<0은 내역서 생성 차단)
```
- **중도퇴실**: 공실 처리 안 함, 종이고지서→카톡고지서 전환, 수납 적요 "중도퇴실" 표시.
- **정산완료+공실**: 미납 관리비 전부 수납 처리, 수도 지침값 자동 이월, 입주자정보 적요 리셋.
- 관리비 항목 중 **일할 대상**(일반관리비·청소비 등)은 1.1 규칙을 따른다.
- ② 공과금 사용량 = **max(0, 최종(이사) 지침 − 이주(전월) 지침)**. 누적 계량기라 이사 지침이 전월보다 작은 경우(검침 오기·계량기 교체·한 바퀴)는 음수 요금을 막으려 0으로 계산하되, **화면에서 경고**해 사람이 확인하게 한다(저장은 막지 않음). 교체·한 바퀴는 전월 지침을 고쳐 실제 사용량을 반영한다(2026-10-10).
- 상세 항목·합계 필드: [_data-dictionary.md](_data-dictionary.md) G절.

## 7. 값 고정·이월 (다음 달 연동)

- **량 고정**(계량기 없는 호실 추정 사용량)과 **수동입력 고정**은 "해당 월부터" 규칙으로 저장, 다음 달 자동 상속. 상세는 정본 `부과액-계산-정책.md` 6장.
- 이사정산·검침 시 수도 지침값 자동 이월(공실 처리 시).

---

## 8. 화면 PRD로 넘긴 사항

공통 계산 규칙 자체는 확정. 아래는 각 화면 PRD에서 세부 확정:
- 공과금 **월중 입·퇴실 일수 안분**(현 공과금 배분은 미반영, 정본 8장) — 해당 화면 PRD에서.
- 4사5입의 반올림 단위, 수도·가스 부가금 규칙 등 채널별 세부 — 해당 공과금 화면 PRD에서.
- 연체료 실제 요율표·단전단수 임계 개월수 — `setup`/건물 설정값(운영 입력).
