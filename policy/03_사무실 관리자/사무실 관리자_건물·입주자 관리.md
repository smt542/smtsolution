## 0. 화면 구조 (통합 master-detail)

- 한 화면에서 **위 = 건물 목록(마스터)**, **아래 = 선택 건물의 입주민(디테일)** 을 동시에 다룬다.
- 건물 행을 선택하면 그 행이 선택 상태로 강조되고, 하단 입주민 표가 해당 건물로 채워진다.
- 입주민(디테일) 영역의 조회와 관리카드 모달 규칙은 아래 3.3절에 함께 정의한다.
- 앱바의 `입주자카드 및 부과내역 출력` 버튼은 **출력 모달**을 연다(§3.4).

## 1. 목적

관리업체 직원이 등록 건물 전체를 한눈에 파악하고, 건물을 선택해 곧바로 해당 건물의 호수·입주민까지 관리하며, 건물 단위 입주자카드와 관리비 부과내역서를 미리보고 출력하는 진입 허브.

## 3. UI

### 3.0 상단 앱바

- **기능**: 화면 제목 + 출력 모달 진입
- **규칙**:
  - 좌측 제목: `건물·입주자 관리`
  - 우측 `입주자카드 및 부과내역 출력` 버튼 → **출력 모달**(§3.4)을 연다.
  - 출력 모달은 건물 미선택 상태에서도 열 수 있으며, 이미 건물을 선택했다면 그 건물을 초기 선택값으로 사용한다.
  - `＋ 건물 등록`은 앱바가 아니라 건물 목록 카드 헤더에 위치(§3.2).

### 3.1 검색 바

- **기능**: 건물명·주소로 목록 검색
- **규칙**:
  - 필터 버튼 + `건물명·주소 검색` 입력 + `검색` 버튼
  - `검색` 버튼 클릭 또는 Enter 시 목록을 재조회한다(실시간 필터 아님).
  - 담당자 필터는 필터 버튼 뒤 패널에서 사무 담당자·현장 관리자·청소 담당자 역할별 단일 선택으로 제공하고, 선택 시 목록을 서버에서 재조회한다.

### 3.2 건물 목록(마스터) 카드

- **기능**: 등록된 건물을 행 단위로 표시하고, 행을 선택해 하단 입주민을 로딩
- **규칙**:
  - 헤더: `전체 건물` + 건수 배지(`N곳`) + `⤓ 엑셀 다운` + `＋ 건물 등록`
  - 표시 컬럼(12): **코드 / 건물명 / 유형 / 주소 / 건물주명 / 건물주 연락처 / 공동현관 / 관리 / 검침 / 청소 / 등록일 / 동작**
    - 유형=건물 유형 라벨, 공동현관=공동현관 비밀번호, 등록일=건물 등록일. (`list_buildings` 확장으로 배선 완료 — 마이그 0116)
  - 행 **클릭** → 해당 건물 선택(청록 틴트) + 하단 입주민 표 로딩
  - 행의 `동작 > 상세` → `/staff/buildings/:id` (건물 상세·등록 화면)
  - `＋ 건물 등록` → `/staff/buildings/new`
  - `⤓ 엑셀 다운` → 현재 검색 조건이 적용된 목록을 `.xlsx` 로 다운로드 (파일명 `건물목록_YYYYMMDD.xlsx`)
  - 기본 정렬: 등록일 최신순
  - 페이지네이션: 페이지 번호 방식, 페이지당 노출 건수 드롭다운(10 / 20 / 50건, 기본 20)
  - 마스터를 컴팩트하게 유지하기 위해 목록 영역은 고정 높이 내에서 세로 스크롤(헤더 고정)

### 3.3 호수·입주민 목록 및 관리카드 모달 (선택 건물)

- **기능**: 선택한 건물의 호실·입주민을 행 단위로 조회하고, 선택 세대의 입주민 관리카드를 모달로 연다.
- **규칙**:
  - 건물 미선택 시 `건물을 선택해 주세요` 안내를 표시하고 엑셀·등록 액션을 비활성화한다.
  - 건물 선택 시 `{건물명} 호수·입주민`과 인원 배지, 세대 표를 표시한다.
  - 표는 33개 컬럼을 가로 스크롤로 제공한다. 인상액·입주예정일·홈피 비번·부과일은 데이터 원본 연결 전까지 빈 셀이다.
  - 공실 세대는 입주자명 대신 `공실`로 표시한다.
  - 입주민 행 **클릭** 또는 포커스 후 **Enter/Space** → 해당 건물 `buildingId`와 세대 `unitId`의 **입주민 관리카드 모달**을 표시한다.
  - 행 클릭은 출력 모달을 열지 않는다. 출력 모달은 상단 `입주자카드 및 부과내역 출력` 버튼으로만 진입한다.
  - 관리카드는 기본정보·연락처·부과 설정·계량기/고객번호·고지서 설정·퇴실 이력·임대차·매물 정보를 조회·수정한다.
  - 관리카드에서 `저장`하면 선택 세대 정보를 저장한다. `닫기`, 배경 클릭, `Esc`로 닫고, 미저장 변경이 있으면 확인한다.
  - `＋ 호수·입주민 등록` → `/staff/buildings/:id/tenants/new`.
  - 입주민 엑셀 다운로드는 `/api/buildings/[id]/tenant-cards`로 선택 건물의 입주자카드를 xlsx(호실명·입주자명·룸타입·인원·입주일)로 내려받고 반출 감사 로그를 기록한다.

### 3.4 입주자카드 및 부과내역 출력 모달

- **기능**: 건물을 선택하고 연·월 기준의 입주자카드와 관리비 부과내역서를 미리보고, 문서별로 또는 함께 인쇄한다.
- **레이아웃**: 좌측 건물 선택 패널 + 우측 미리보기 영역(입주자카드 / 관리비부과내역서 **좌우 2단**).
- **규칙**:
  - 좌측: `코드·건물명·주소 검색` + 건물 목록(**단일 선택**). 본 화면에서 이미 건물을 선택했다면 그 건물을 **초기 선택값**으로 사용한다.
  - 우측 상단: 출력 기준 **연도·월** 드롭다운(기본=당월, 연도 2019~현재 연도).
  - **건물 미선택 상태**: `왼쪽에서 건물을 선택해 주세요` 안내, 푸터 `둘 다 인쇄` 비활성.
  - **건물 선택 상태**: 좌우 2단 미리보기.
    - **입주자카드**(좌): 세대 1장당 A4 카드 1장. 코드·빌라명·주소 + 호실/입주자/룸타입/거주인원/입주일/연락처/공실·연체 여부. 패널 상단 `총 N장` 배지 + 페이지 이동(‹ N / N ›) + `카드만 인쇄`.
    - **관리비부과내역서**(우): 세대(행)×관리비 항목(열) 표를 **14세대/쪽**으로 페이지네이션, 마지막 쪽에 항목별·총 합계 행. 패널 상단 `총 N장` 배지 + 페이지 이동 + `내역서만 인쇄`.
  - 두 문서 배경에 **회사명 워터마크**(조직명, 없으면 `관리비서`)를 옅게 표시한다.
  - **부과내역서 게이팅(P5)**: 선택 연·월에 **확정 부과가 없으면** 표 대신 `확정된 부과 내역이 없습니다 / 관리비 부과 확정(P5) 후 표시됩니다` 안내를 노출하고 `내역서만 인쇄`를 비활성화한다.
  - 세대 자료 로딩 중에는 카드 패널에 `불러오는 중…`을 노출한다.
  - **인쇄 3종**: `카드만 인쇄`(입주자카드 전량) / `내역서만 인쇄`(부과내역서 전량) / 푸터 `둘 다 인쇄`. 인쇄는 A4·여백 0으로 해당 문서를 **전량 페이지 분할** 출력한다(미리보기 현재 페이지에 한정하지 않음).
  - 푸터 좌측에 `{건물명} 선택됨 · 카드 N장 · 내역서 N장` 요약을 표시한다.
  - `취소`, 닫기(×), 배경 클릭, `Esc` → 모달 닫기. 열려 있는 동안 배경 스크롤을 잠근다.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 빈 상태 | 등록된 건물이 0개 | "등록된 건물이 없습니다" 안내 + `건물 등록` 노출 |
| 결과 없음 | 검색·필터 결과 0건 | "조건에 맞는 건물이 없습니다" 안내 |

| 건물 선택 | 건물 행 또는 모달 목록 선택 | 행 강조 + 입주민 목록/문서 미리보기 |
| 관리카드 열림 | 입주민 행 클릭/Enter/Space | 선택 세대의 입주민 관리카드 폼을 모달로 표시 |
| 로딩 | 건물·세대 조회 중 | 해당 영역 로딩 인디케이터 |
| 에러 | 건물·세대 조회 실패 | "데이터를 불러오지 못했습니다. 다시 시도해 주세요." |
