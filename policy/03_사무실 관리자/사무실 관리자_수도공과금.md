## 1. 목적과 성공 기준

상수도 사업소가 고객번호 단위로 청구한 수도요금을 건물·호실의 검침 지침과 사용량에 따라 조회·편집·저장하고, 최근 이력 확인과 검침대장 출력, 다음 달 이월까지 한 화면에서 처리한다.

성공 기준:
- 건물 미선택, 조회, 수정, 출력 모달, 이월 확인의 5개 상태가 Figma와 같은 정보 구조로 전환된다.
- 건물·연월 변경 시 고객번호 요약과 호실 지침이 같은 범위로 다시 조회된다.
- 조회 모드에서는 값이 읽기 전용이고, `수정` 이후에만 `전월 · 금월 · 량 · 수동입력 · 적요` 5개 항목을 편집한다.
- 검침대장은 다중 건물을 선택해 출력할 수 있고 완료 결과를 토스트로 알린다.
- 권한이 없는 사용자는 화면에 접근할 수 없다.

## 2. 권한

| 사용자 | 접근/동작 |
|---|---|
| staff (마스터) | 조회·수정·저장·출력·이월 가능 |
| staff (일반) | `utilities` 권한 부여 시 동일 기능 사용 가능 |
| 권한 없음 | LNB 메뉴 숨김 및 직접 접근 차단 |

권한은 마스터가 계정별로 부여한다. 화면의 조회·편집 권한 기준은 `utilities` 모듈이다.

## 3. UI 및 동작 규칙

### 3.0 공통 셸과 상단 헤더
- 좌측 LNB의 `공과금 관리` 아래에 `수도 · 전기 · 가스` 하위 메뉴를 표시한다.
- 현재 유형은 밝은 브랜드 배경과 브랜드 색상으로 구분한다.
- 헤더에는 `공과금 관리 / 수도`, `검침대장 출력`, `전체 이월`을 표시한다.
- 모바일의 메뉴 버튼은 공통 셸 서랍을 연다.

### 3.1 전체 건물 / 조회 조건
- 연도와 월분을 선택하면 조회 기간을 해당 월 1일 기준값(`YYYY-MM-01`)으로 변경한다.
- 검색은 건물 코드·건물명·주소를 즉시 필터링한다.
- 표 컬럼은 `코드 · 건물명 · 주소 · 수도`이며 선택 행은 브랜드 틴트 배경을 유지한다.
- 건물을 바꾸면 조회 모드로 복귀하고 선택 호실·열린 설정 모달을 초기화한다.
- 검색 결과가 없으면 “검색 결과가 없습니다.”를 표시한다.

### 3.2 최근 6개월 이력
- 호실 또는 고객번호 요약 행을 선택하면 대표 호실의 최근 6개월 부과월·단가·부과액을 표시한다.
- 미선택 시 “고객번호를 선택해 주세요 / 선택한 고객번호의 최근 6개월 이력이 표시돼요.”를 표시한다.
- 현재 데이터 API는 `unitId` 기준 이력 조회다. 고객번호에 여러 호실이 연결된 경우 최근 6개월 이력은 대표 호실(고객번호 그룹의 첫 호실) 기준으로 표시한다.

### 3.3 건물 편집 바
- 선택 건물명과 `YYYY년 M월분 수도 부과 편집`을 표시한다.
- 부과기준일은 기본 전월 16일~당월 15일이며, 저장된 설정이 있으면 저장값을 우선한다.
- 조회 상태 액션은 `수정`.
- 수정 상태 액션은 `계산 · 저장 · 취소(X)`이며 바 테두리를 브랜드 색상으로 강조한다.
- `계산`은 입력된 검침값을 현재 범위로 저장하고 편집 상태를 유지한다.
- `저장`은 부과기준일 저장 성공 후 검침값을 저장하며 성공 시 조회 상태로 복귀한다.
- 시작일이 종료일보다 늦거나 값이 없으면 저장하지 않고 오류 토스트를 표시한다.

### 3.4 고객번호 요약
- 고객번호로 행을 그룹핑해 합계 정보를 표시한다.
- 컬럼: `L · 고객번호 · 월 · 량 · 수동입력 · 할인금액 · 전월금액 · 부과액 · 전단가 · 단가 · 금-전1 · 금-전2 · 금월량 · 전월량`.
- 행 선택 시 연결된 대표 호실을 선택하고 최근 6개월 이력과 호실 표 선택 상태를 동기화한다.
- 수정 상태에서는 고객번호와 부과액 셀을 입력 형태로 표시한다. 현재 고객번호·그룹 부과액 직접 저장 API가 없어 읽기 전용 입력으로 제공하며 **❓ 직접 수정 저장 정책 확정 필요**.

### 3.5 호실별 수도 지침
- 컬럼: `호수 · 입주일자 · 퇴실일자 · 퇴실예정일자 · 전월 · 금월 · 량 · 전.량 · 증감 · 수동입력 · 할인유형 · 할인금액 · 부과액 · 적요 · 처리일자 · 부과기준 · 이름 · 전화 · 라인 · 인원`.
- 조회 상태에서는 모든 값을 텍스트로 표시한다. 수정 상태에서 입력 가능한 항목은 `전월 · 금월 · 량 · 수동입력 · 적요` 5개로 제한한다.
- `전.량 · 증감 · 할인유형 · 할인금액 · 부과액 · 처리일자 · 부과기준 · 이름 · 전화 · 라인 · 인원`은 수정 상태에서도 읽기 전용이다.
- `량` 직접 입력값이 있으면 해당 값을 우선 저장·계산하고, 직접 입력값이 없으면 `금월 - 전월`로 계산한다. 고정 사용량이 설정된 세대는 기존 고정량 정책을 fallback으로 유지한다.
- 공실 행은 5개 입력을 모두 비활성화한다. 음수 사용량은 “확인 필요”와 빨간색으로 표시한다.
- 수동 입력 요금이 있으면 자동요금보다 우선해 부과액으로 표시한다.
- 편집 중에만 수도 할인 설정, 고정 사용량 설정, 단가 설정 진입점을 표시한다.
- 행 플래그: `퇴실 예정` 파랑 · `공실 사용량` 빨강 · `최근 입주` 초록.
- 할인 gross-up, 절사, 합계 검산의 계산 정본은 `부과액-계산-정책.md`를 따른다.

### 3.6 검침대장 출력 모달
- 헤더의 `검침대장 출력`으로 연다.
- 연도·월분 선택, 건물 코드·이름 검색, 건물 다중 선택을 제공한다.
- 우측에는 선택 대상과 인쇄 표의 미리보기를 표시한다.
- 한 곳 이상 선택해야 `출력`할 수 있다.
- 인쇄 시 선택 건물별 수도 검침 데이터를 A4 검침대장 문서로 구성해 브라우저 인쇄를 실행한다.
- 화면용 모달·선택 컨트롤은 인쇄물에서 제외하고, 인쇄 완료 후 모달을 닫은 뒤 “검침대장 출력 처리되었습니다.” 토스트를 표시한다.
- 출력 서식의 정본은 [_output-forms.md](../../_output-forms.md) 2절이다.

### 3.7 전체 이월
- 헤더의 `전체 이월` 클릭 시 `YYYY년 M월분 이월을 진행할까요?` 확인 대화상자를 표시한다.
- 설명은 모든 건물의 현재 월분이 다음 월분으로 이월됨을 안내한다.
- `취소`는 변경 없이 닫는다.
- `이월`은 다음 달 범위로 이동하고 활성 호실의 당월 지침을 다음 달 편집 초깃값으로 만든다.
- 현재 구현은 화면에 로드된 선택 건물의 로컬 초깃값을 생성하는 프로토타입이다. 모든 건물을 원자적으로 저장하는 **❓ 서버 일괄 이월 API 및 실패 복구 정책 확정 필요**.

## 5. 데이터와 연동

| 항목 | 출처 / 연동 | 트리거 |
|---|---|---|
| 건물 목록 | `useBuildings` / buildings | 화면 진입 |
| 호실별 지침 | `useUtilityRows(buildingId, water, period)` | 건물·유형·월 변경 |
| 고정 사용량 | `useFixedUsages` / unit_meters | 건물·유형 변경 |
| 최근 6개월 | `useMeterHistory(unitId, water, period)` | 호실/고객번호 선택 |
| 부과기준일 | `useBillingPeriod`, `useSaveBillingPeriod` | 건물·월 변경 / 저장 |
| 검침 저장 | `useSaveMeterReadings` / `save_meter_readings` (`previous_reading`, `current_reading`, `usage`, `manual_charge`, `note`) | 계산·저장 |
| 할인·단가·고정량 | 각 설정 mutation | 편집 상태의 설정 액션 |
| 검침대장 | 선택 건물별 `useUtilityRows` 조회 + A4 `window.print()` | 인쇄 |
| 전체 이월 | 로컬 프로토타입 | 확인 대화상자의 이월 |

발송 트리거는 없다. 저장된 공과금은 관리비 부과·고지 생성 화면에서 참조한다.

## 6. 접근성·반응형
- 모든 검색·연월·날짜·검침 입력에는 접근 가능한 이름을 제공한다.
- 모달은 `dialog`/ `alertdialog`, 제목 연결, 배경 클릭 닫기 규칙을 사용한다.
- 데스크톱은 322px 좌측 레일과 가변 우측 작업공간을 사용한다.
- 좁은 화면에서는 좌우 영역을 세로로 배치하고 넓은 표는 영역 내부에서 가로 스크롤한다.
- 색상 외에 텍스트와 상태명으로도 선택·오류·플래그를 구분한다.
