# 사무실 관리자_전체 이사조회

> **상태**: `confirmed` · 2026-09-23 확정

## 목적
사무실 관리자가 이사 정산 대상 전체 세대를 한 화면에서 조회하고, 전기·가스 납부일과 청소비를 인라인으로 수정·저장한다.

## 조회 정책
- 기본 기간: 당해 1월 1일~현재 월 말일
- 유형: 전체/수도/전기/가스
- 상태: 전체/완료/미결(incomplete)
- 정렬: 코드순/일자순
- 검색: 건물명·주소·동·호수·임차인명
- API 조회 상한은 500건이며 화면은 현재 100건 단위로 표시한다.

## 표 구성
- 전체 화면: 번호, 소재지, 건물명, 호실, 이사일, 입주일, 전기 전/현재 검침값·사용량·금액·납부일, 가스 전/현재 검침값·사용량·금액·납부일, 당월 관리비, 입력검침자, 청소비, 상태
- 건물별 소계 및 전체 합계를 표시한다.
- 납부일은 날짜 입력, 청소비는 숫자 입력(천 단위 표시)으로 편집한다.

## 저장/출력
- 변경 건수가 있을 때만 저장 버튼을 활성화한다.
- 저장은 `update_settlement_inquiry_rows(p_rows jsonb)` RPC를 사용하며 전기 납부일·가스 납부일·청소비를 일괄 반영한다.
- 청소비 원천은 `moving_settlements.cleaning_cost`, 입력검침자는 `checked_by`/profiles 조인으로 표시한다.
- 출력 버튼은 인쇄 전용 헤더와 회사 워터마크를 포함한 표를 출력한다.

## 권한/상태
- moving 모듈 권한이 없으면 접근 거부 안내를 표시한다.
- 조회 오류·빈 결과·기간 역전·로딩 상태를 별도 안내한다.
- 저장 성공 시 변경 건수 토스트, 실패 시 재시도 안내를 표시한다.
