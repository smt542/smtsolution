## 1. 목적

관리업체 직원이 **문자(SMS)·알림톡**을 예약/즉시 발송하고, 발송 내역을 조회하며, 재사용 템플릿을 관리하는 **발송 허브**. 관리비 고지·정기점검·건물주 정산·수도검침·청소일정 등 각종 안내를 여기서 일원화해 보낸다. 발송 1건마다 테넌트 포인트가 차감되므로 발송·과금 정책([_notification-policy.md](../../_notification-policy.md))과 직결된다.

## 2. 권한

| staff (일반) | LNB "문자·알림톡 관리" 권한 부여 시 O (계정별 설정형) |

- **포인트 잔액 0이면 발송 하드 스톱** — 발송 화면에서 잔액 상태를 안내([_service-policy.md](../../_service-policy.md) 4.1, [_notification-policy.md](../../_notification-policy.md) 2·7절).

## 3. UI

### 3.1 상단 헤더 · 공통 인프라
- **기능**: 화면 제목("문자·알림톡 관리"), 좌측 공통 LNB, 우측 공통 RNB.
- **규칙**: RNB "A/S 접수·퇴실 신청 현황" 패널을 공유(공통 인프라).

### 3.2 탭 구성
- **기능**: 화면은 4개 탭으로 구성. 각 탭에 건수 배지(관리비 고지서 탭은 건물·월 선택 후 카드에 표시).
- **규칙**: **예약 발송 · 발송 내역 · 템플릿 관리 · 관리비 고지서**.

### 3.3 예약 발송 탭
- **기능**: 예약된 발송 목록 조회·관리.
- **규칙**:
  - 컬럼: **채널 · 발신자 · 수신자 · 내용 · 유형 · 예약 일시 · (액션)**([_data-dictionary.md](../../_data-dictionary.md) J절).
  - **채널**: 문자 · 알림톡([_status-codes.md](../../_status-codes.md) 11절).
  - **발신자**: 알림톡=「관리비서 채널」, 문자=「042-632-8770」([_notification-policy.md](../../_notification-policy.md) 1절).
  - **수신자**: 세그먼트 × 범위 × 인원수 표기(예: "입주자 / 전체 / 128명"). 세그먼트=**입주자 · 건물주 · 청소 담당자**, 범위=전체 / 특정 건물([_notification-policy.md](../../_notification-policy.md) 4절). 입주자 세그먼트는 세대 **주번호·부번호 모두** 수신.
  - **유형(예약 유형)**: 예약 · 예약(매월) · 예약(매주)([_status-codes.md](../../_status-codes.md) 11절).
  - 필터(전체/예약(매월)/예약)·정렬(최신순/과거순).
  - 행 액션: **예약 취소**(확인 모달, 되돌릴 수 없음). 행 클릭 시 **예약 발송 상세**(요약 · 수신자 목록 · 전송 내용) 모달.
  - **반복 발송 설정**: 예약을 정기 발송으로 전환. 주기(매월/매주) · 발송일 · 발송 시각 · 종료(계속 반복/횟수 지정). 대상 규칙·내용은 유지. 발송 시각을 바꾸면 이 예약과 이후 회차가 모두 그 시각(KST)에 발송되며, 이미 지난 시각으로는 바꿀 수 없다(2026-10-10).

### 3.4 발송 내역 탭
- **기능**: 지난 발송 결과 조회.
- **규칙**: 컬럼=채널 · 발신자 · 수신자 · 내용 · 유형 · **상태** · 발송 일시. **상태**=완료 · 실패 · 예약([_status-codes.md](../../_status-codes.md) 11절). 필터(전체/완료/실패/예약)·정렬(최신순/과거순). 발송 실패 시 실패 사유·재시도 안내([_notification-policy.md](../../_notification-policy.md) 7절).

### 3.5 템플릿 관리 탭
- **기능**: 재사용 발송 템플릿 등록·수정·삭제.
- **규칙**:
  - 컬럼: **템플릿(문자/알림톡) · 구분 · 템플릿명 · 템플릿 내용 · 링크 · (액션)**([_data-dictionary.md](../../_data-dictionary.md) J절).
  - 필터(전체/문자/알림톡). **「템플릿 등록」** 버튼 → 등록 모달.
  - 템플릿 등록/수정 모달 필드:
    - **템플릿 유형**: 문자 / 알림톡.
    - **구분**: 정기 / 공지.
    - **템플릿명**.
    - **템플릿 내용** + **변수 삽입**(건물명·공지제목·호실·입주자명·관리비기간·납기일·출금예정일·고객번호·당월관리비·미납관리비·총납부금액·관리실연락처 등). 변수는 발송 시 치환([_notification-policy.md](../../_notification-policy.md) 5절).
    - **링크(알림톡 버튼)**: 버튼명 + 연결 URL. **알림톡 유형에서만** 노출. URL에도 변수(링크토큰·공지ID) 사용 가능.
  - **팝빌 승인 템플릿(템플릿 코드 보유)은 잠금**(2026-10-12): 템플릿명·유형·내용·링크·강조표기·템플릿 코드는 수정할 수 없고 「팝빌 승인 템플릿은 팝빌에서 수정 후 동기화해 주세요」를 안내한다. 구분만 수정 가능(저장 경로도 DB에서 거부). 「팝빌 동기화」는 코드가 같은 템플릿의 이름을 바꾸지 않고 내용·버튼(팝빌 원문 형식)·강조표기만 갱신한다.

### 3.6 발송 작성(공용 발송 모듈)
- **기능**: 신규 문자·알림톡 작성·발송(즉시/예약).
- **규칙**: 채널·발신자·수신자 세그먼트·범위·템플릿/내용·예약 유형을 지정해 발송하는 **공용 발송 모듈**을 통해 처리한다. 타 화면(예: partner 정산문자)도 이 모듈을 호출한다. 발송 시 포인트 차감·잔액 하드 스톱 규칙 적용([_notification-policy.md](../../_notification-policy.md) 2·7절). 신규 발송은 **문자·알림톡 플로팅 버튼(FAB)** 으로 작성 개시한다(공용 Messenger 모듈).

- **플로팅 버튼 문자 템플릿**(2026-10-14): 메시지 내용 우측 「템플릿」 메뉴에 기본 문자 템플릿 10종(입주 환영·관리비 납부·관리비 미납(문자)·정기 점검·건물주 정산·청소 일정·단수·정전·택배 도착·이사 정산 안내, previous_lhw 원본)을 org별로 기본 제공한다(0311, 신규 org 자동 생성). 변수 `#{건물명}·#{호실}·#{입주자명}·#{건물주명}·#{청소담당자명}`은 수신자별로 자동 치환한다 — 건물명=수신자 건물, 호실·입주자명=수신 세대, 건물주명=건물주 수신자는 본인 이름·그 외는 건물의 건물주명, 청소담당자명=청소 담당 수신자는 본인·그 외는 건물 청소 담당자. 휴대폰 미리보기는 첫 수신자 값으로 치환하고, 값이 없으면 예시 값(그린빌라·101호·김민준 등)으로 보여 준다.

- **플로팅 버튼 알림톡 승인 템플릿 자동 채움**(2026-10-14): 알림톡 「템플릿」 메뉴의 팝빌 승인 4종을 수신자별 값으로 채워 보낸다.
  - **관리비 고지(일반·자동이체·장기미납)**: 「부과월」(기본 이번 달)을 고르면 그 달 부과 확정 내역으로 세대별 건물명·호수·관리비 기간·납부 마감일(자동이체는 출금예정일)·고객번호·당월/미납/총 납부금액·관리실 연락처를 채우고, 발송 직전에 고지서 상세 링크를 발급한다(변수 규칙은 3.7 관리비 고지서 탭과 같음). **고지 유형이 고른 템플릿과 다른 세대(예: 자동이체 세대에 일반 템플릿)가 있으면 발송하지 않고, 토스트로 해당 세대와 맞는 템플릿(예: 「관리비 고지(자동이체)」)을 안내한다(2026-10-19).** 부과 확정이 없거나 납부자번호·금액·마감일이 없는 세대는 그 값을 빈 값으로 보내고 사유별 인원을 안내한다(2026-10-15). 발송하면 세대별 카카오 고지 발송 기록을 남긴다(예약 발송 제외).
  - **신규 공지**: 「공지」를 고르면 공지 제목을 넣고, 발송 직전 공유 토큰으로 「공지 확인하기」 링크를 만든다. 발송 로그는 그 공지에 귀속한다.
  - 자동 채움 변수는 입력칸을 띄우지 않는다. 값을 모두 채우지 못하면 발송하지 않는다.

### 3.7 관리비 고지서 탭 (카카오 고지서 알림톡 발송, 결정 2026-10-12)
- **기능**: 건물·월분의 부과 확정 세대에 관리비 고지서 알림톡을 즉시 발송.
- **규칙**:
  - 건물 선택 → 월분 선택(기본 이번 달, 최근 12개월) → 대상 세대 표. 대상 = 그 달 **부과 확정** 세대 중 **입주 중**.
  - 컬럼: (선택) · 호수 · 입주자 · 고지 유형(일반/자동이체/장기미납) · 당월 관리비 · 미납 관리비 · 총 납부금액 · 상태(발송 가능 / 제외 사유). 기본 전부 체크.
  - 제외(체크 불가): 알림톡 수신 동의 없음 · 전화번호 없음 · 납부자번호 없음.
  - 금액: 당월 관리비·미납 관리비·총 납부금액은 지로 고지서의 당월계·미납액·납기내금액과 같은 값이다(총 납부금액 = 당월 + 이월 미납, 연체료 합산 설정이면 연체료 포함).
  - 유형별 템플릿·변수 규칙은 [알림·발송 정책](../01_공통%20정책/알림·발송%20정책%20_%20템플릿.md) 5절(고객번호=납부자번호 뒤 6자리, 출금예정일=그 달 납부 마감일).
  - 발송 전 확인 모달에 유형별 인원 요약(예: "일반 12 · 자동이체 3 · 장기미납 1 — 총 16명"). 유형별로 묶어 접수하며, 주번호·부번호 모두 수신. 일부 묶음만 접수되면 접수·실패를 각각 안내.
  - 템플릿(또는 템플릿 코드)이 없거나 회사 대표 전화가 없으면 안내하고 발송 버튼 비활성.
  - 접수된 세대는 고지서 카카오 발송 기록(접수, 발송 로그 연결)으로 남긴다.
