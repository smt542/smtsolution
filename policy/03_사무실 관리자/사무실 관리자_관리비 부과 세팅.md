## 1. 목적

관리업체 직원이 건물·월분별 부과기준일과 세대별 관리비를 조회·편집·저장하고, 전월 이월 항목 또는 확정된 공과금 부과액을 반영하는 화면이다. 건물별 참조사항과 중요 건물 표시로 반복 부과 작업의 실수를 줄인다.

- 관리비 항목의 등록·수정·삭제는 `항목등록 관리` 화면에서 처리한다.
- 이 화면의 `저장`은 입력값 저장과 당월 부과 확정을 함께 수행한다.
- 공과금 원천 금액은 수도·전기·가스 공과금 화면에 입력된 해당 월 부과액을 사용한다(별도 확정 절차 없음).

## 2. 권한

| 사용자 | 접근 | 조회 | 편집·저장 |
|---|---:|---:|---:|
| 조직 관리자 | O | O | O |
| 일반 직원 | `billing` 권한 보유 시 O | O | O |
| 권한 미보유 사용자 | X | X | X |

권한이 없으면 화면 대신 접근 불가 안내를 표시한다.

## 3. UI 및 동작 규칙

### 3.0 조회조건 / 전체 건물 (좌측 상단)

- 연도와 월분을 선택하면 같은 건물의 해당 월 데이터를 다시 조회하고 편집 중 변경값은 초기화한다.
- `건물명·주소 검색`은 코드·건물명·주소를 즉시 필터링한다.
- `그룹 전체`/1~5 필터는 건물의 고지서 부과 그룹(건물 폼에서 지정, 미지정 시 1그룹)을 기준으로 거른다.
- 건물 표는 `코드 · 건물명 · 주소`를 표시하며 선택 행을 강조한다.
- 건물 미선택 상태에서는 우측 세대 표에 `건물을 선택해 주세요` 안내를 표시한다.

### 3.1 부과시 참조사항 / 중요 건물 (좌측 하단)

- 선택 건물의 `부과시 참조사항`을 조회 모드에서 읽기 전용으로 표시하고, 수정 모드에서 편집한다.
- 참조사항 변경은 상단 `저장` 시 건물 메모로 저장한다.
- `중요 건물` 체크는 즉시 저장한다.
- 중요 건물에서 `빌라자료추가`를 누르면 `중요 건물로 지정된 건물이에요` 경고를 먼저 표시하고, 확인 후 전월 자료 반영 확인으로 이어진다.

### 3.2 편집 바 (우측 상단)

- 건물 미선택 시 비활성 상태와 `건물을 선택해 주세요`를 표시한다.
- 조회 모드에는 건물명·부과기준일과 `수정` 버튼을 표시한다.
- `수정`을 누르면 부과기준일, 건물 참조사항, 세대별 부과 여부·금액 입력을 활성화하고 `저장`·닫기 버튼을 표시한다.
- 부과기준일 기본값은 전월 16일~당월 15일이다.
- `저장`은 다음 순서로 처리한다: 부과기준일 저장 → 세대별 변경값·메모 저장 → 건물 참조사항 저장 → 당월 부과 확정. 실패하면 수정 모드를 유지하고 오류를 안내한다.
- 화면에 노출되지 않는 납기일은 기존 저장값을 유지한다. 전월 자료 반영 때는 3.5의 납부일 이월 규칙을 따른다.
- 닫기 버튼은 저장하지 않은 변경을 폐기하고 조회 모드로 돌아간다.

### 3.3 공과금 정보 (우측 중단)

- 탭은 `수도 · 전기 · 공용전기 · 가스` 순서다.
- 선택 탭의 고객번호, 사용량, 수동입력, 할인금액, 부과액, 단가, 검침량 요약을 읽기 전용으로 표시한다.
- 확정 데이터는 `산정 완료`로 표시한다.
- 현재 데이터 모델에는 공용전기 전용 구분이 없어 공용전기는 전기 산정 내역에 포함해 표시한다. ❓ 공용전기를 독립 데이터로 분리할지 확정이 필요하다.

### 3.4 세대별 관리비 (우측 하단)

- 툴바는 `빌라자료추가 · 전체자료추가 · 공과금 계산`과 `공실 사용량 · 최근 입주` 범례를 표시한다.
- 표 고정 정보는 `호수 · 총 관리비 · 성명/평수/룸타입/입주일 · 부과시 참조사항 · 부과시 공지사항 · 처리일자`다.
- 가변 관리비 항목은 항목명에 따라 `관리비 · 공과금 · 수리비` 그룹으로 묶고 각 항목의 Y/N 및 금액을 표시한다.
- 조회 모드에서는 값과 상태를 읽기 전용으로 표시하고, 수정 모드에서는 Y/N과 금액을 편집한다.
- 공실 세대는 금액 입력을 비활성화하고 합계를 0으로 표시한다. 당월 입주 세대는 `최근 입주` 배경으로 강조한다.
- 일자계산 항목은 기존 계산 규칙에 따라 입주일 기준 일할 계산해 총 관리비에 반영한다.
- 확정 후 변경된 행은 `재확정 필요`, 변경되지 않은 행은 확정 스냅샷 합계를 표시한다.
- 호수를 누르면 최근 관리비 이력을, 참조·공지 셀을 누르면 수정 모드에서 세대 메모 편집 창을 연다.

### 3.5 전월 자료 반영

- `빌라자료추가`는 선택 건물, `전체자료추가`는 조회 가능한 전체 건물을 대상으로 한다.
- 확인 모달에는 전월·현재 월분과 기존 입력값 덮어쓰기 안내를 표시한다.
- 현재 월에 존재하는 동일 세대·동일 항목 중 `이월` 설정된 항목(필수 공과금 전기·수도료·가스 제외)만, **세대·항목별로 저장된 값이 있는 가장 최근 달**의 Y/N·금액으로 덮어쓴다(2026-10-14, 전월에 없으면 그 이전 달). 비이월 항목과 세대 메모는 유지한다.
- 가져올 값이 없는 칸은 **덮어쓰지 않고** 현재 월 값을 유지한다(0으로 채우지 않음). 하나도 가져오지 못하면 「가져올 지난 자료가 없어요」로 안내하고, 전체 반영 완료 안내의 반영 건물 수에서도 뺀다.
- 부과기준일은 납기일과 같은 방식으로, 설정해 둔 가장 최근 달(이번 달 이전, 없으면 이후 포함)의 날짜를 이번 달로 옮긴다(같은 날짜, 말일이면 말일). 기준 달이 없으면 현재 월 값을 유지한다.
- **납부일 이월** (2026-10-14): 전월 **건물·월 납기일**(이 화면에서 정한 값)과 **같은 날짜**로 현재 월 납기일을 정한다(전월 15일 → 이번 달 15일, 30일 → 30일). 이번 달에 그 날짜가 없으면 말일로 맞춘다(1/30 → 2/28).
  - 전월 납기일이 비어 있으면 **납기일을 정해 둔 가장 최근 달**(이번 달 이전)의 날짜를 기준으로 가져온다. 이전 달에 하나도 없으면 **납기일을 정해 둔 가장 최신 달**(이번 달 이후 포함)을 기준으로 한다. 어느 달에도 없으면 현재 월 값을 그대로 둔다.
  - 기준 달과 같은 날짜로 옮기고(6/25 → 9/25), 기준 납부일이 그 달 말일이면 이번 달도 말일로 정한다.
  - 시스템 기본값인 그 달 말일·발행 고지서 납기일은 이월 기준으로 쓰지 않는다.
  - **말일 특수 조건**: 전월 납부일이 그 달 **말일**이었으면 이번 달도 **말일**로 정한다(2/28 → 3/31, 9/30 → 10/31).
  - 별도 회사 기본 납부일 설정은 두지 않는다(셋업 납부기한 설정 폐지).
- 전체 반영은 건물별로 병렬 처리한다. ❓ 일부 건물 실패 시 전체 롤백이 필요한지 확정이 필요하다.

### 3.6 공과금 계산

- 별도 확정 절차 없이, 공과금 관리(수도·전기·가스)에 해당 월 부과액이 입력된 공과금만 세대별 관리비에 반영한다.
- 대상 공과금(고객번호가 등록됐거나 부과액이 하나라도 입력된 수도·전기·가스, 하나도 없으면 셋 다) 중 입주 세대의 부과액이 하나라도 비어 있으면 반영하지 않고 `공과금 부과액이 아직 없어요` 모달에 누락된 공과금(예: `수도 · 가스`)을 표시해 공과금 관리에서 먼저 입력하도록 안내한다(2026-10-14).
- 반영 시 수도·전기·가스 항목에 세대별 수동 부과액을 우선 사용하고, 없으면 자동 계산 부과액을 반영한 뒤 수정 모드로 전환한다. 부과액이 없는 세대는 기존 입력값을 유지한다.
- 저장(부과 확정)은 공과금 확정 여부와 관계없이 진행하며, 0원 부과 항목 확인 모달 없이 바로 저장한다(2026-10-14).
- 관리비 항목에 해당 공과금 이름의 항목이 없으면 그 유틸 값은 반영하지 않는다.
- 저장(부과 확정) 시 수도·전기·가스는 공과금 관리의 해당 월 세대 부과액을 우선 사용하고, 부과액이 없을 때만 세대별 관리비에 입력된 값을 쓴다(`공과금 계산`을 누르지 않아도 반영, 2026-10-18).
- 수도·전기·가스(필수 공과금 항목)는 전월 이월하지 않는다. 공과금 부과액이 없는 달은 0원이다(2026-10-18).
- 부과 확정 후 공과금 관리의 세대 부과액이 확정 금액과 달라지면 그 세대에 `재확정 필요`를 표시한다. `공과금 계산` → 저장으로 다시 확정해야 고지서·세입자 앱에 반영된다(확정된 고지서 금액은 자동으로 바꾸지 않음, 2026-10-18).

### 3.7 신규 입주자 당월 부과

- 당월 부과 확정 이후 미부과 신규 입주 세대가 감지되면 `이번 달 관리비를 부과하시겠습니까?` 창을 자동 표시한다.
- 확인한 세대만 당월 부과하고, 취소한 세대는 다음 달부터 부과한다.

## 4. 화면 상태

| 상태 | 조건 | 노출 / 동작 |
|---|---|---|
| 건물 미선택 | 최초 진입 또는 선택 해제 | 건물 선택 안내, 편집·개별 반영·공과금 계산 비활성 |
| 조회 중 | 건물·월분 데이터 요청 중 | 각 패널에 로딩 안내 |
| 조회 모드 | 건물 조회 성공 | 모든 금액 읽기 전용, `수정` 노출 |
| 수정 모드 | `수정` 또는 공과금·전월자료 반영 | 입력 활성, 상단 테두리 강조, `저장`·닫기 노출 |
| 공과금 미산정 | `공과금 계산` 시 입주 세대 부과액 누락 | 오류 아이콘 안내 모달, `확인`으로 닫기 |
| 전월 반영 확인 | 자료 추가 클릭 | 대상별 확인 모달, 취소/반영 |
| 중요 건물 경고 | 중요 건물의 개별 전월 반영 | 경고 확인 후 개별 반영 확인으로 이동 |
| 저장 완료 | 일정·변경값·확정 성공 | 조회 모드 전환, 성공 토스트, 처리일자 갱신 |
| 빈 상태 | 선택 건물에 세대 없음 | `등록된 세대가 없습니다.` |
| 오류 | 조회·저장 실패 | 오류 안내와 가능한 경우 재시도 |
