## 1. 목적

퇴실(이사정산) 세대의 **전기 공과금 정산 내역**만 모아 조회·출력하는 화면. 여러 건물의 이사정산분 중 전기 부분(계기번호·고객번호·검침·정산요금·한전입금일)을 한눈에 확인하고, **한전입금일**을 입력·저장하며, 검침대장 형태로 출력한다. 이사정산 입력·계산 자체는 `moving-settlement`에서 수행하며 이 화면은 **조회·출력·입금일 관리** 전용이다.

## 2. 권한  ([_permission-matrix.md](../../_permission-matrix.md) 2절)

| 사용자 | 접근 |
|---|---|
| staff (마스터) | O |
| staff (일반) | LNB "이사정산" 권한 부여 시 O (계정별 설정형 ◐) |

- 마스터가 `staff-management`에서 계정별로 이사정산 메뉴 접근을 부여/제한한다.
- 이 화면은 조회·출력이 주기능이며, 편집 가능한 값은 **한전입금일**뿐이다.

## 3. UI

### 3.0 공통 프레임
- **기능**: 좌측 공통 LNB, 우측 공통 RNB("A/S 접수·퇴실 신청 현황") 패널 공유. 상단 브레드크럼 "이사정산" + 제목 "전기 이사조회".
- **규칙**: LNB/RNB는 공통 인프라. 본문은 조회 툴바 + 결과 표.

### 3.1 조회 툴바
- **기능**: 조회 조건 설정 + 출력·저장 액션.
- **규칙**:
  - **조회일 기간**: 시작(년·월) ~ 종료(년·월) 드롭다운. 이사정산 발생 기간 기준.
  - **신청일**: 년·월·일 드롭다운(정산 신청일 기준 필터).
  - **상태 세그**: `전체 · 완결 · 미결` — 이사정산 조회 상태([_status-codes.md](../../_status-codes.md) 2절). 기본 `전체`.
  - **정렬 세그**: `코드순 · 일자순`. 기본 코드순.
  - **검색**: "건물명·소재지" 텍스트 즉시 필터.
  - 날짜 입력은 전 화면 공통으로 **드롭다운/달력 방식**(직접 타이핑 금지, [_service-policy.md](../../_service-policy.md) 5절).
  - 드롭다운은 커스텀(`.uc-dd`) 사용, 네이티브 `<select>` 금지(`CLAUDE.md`).
  - **출력** 버튼: 현재 조회 결과를 검침대장 서식으로 인쇄(3.3).
  - **저장** 버튼: 편집한 한전입금일 반영(3.2).

### 3.2 결과 표
- **기능**: 조건에 맞는 전기 이사정산 내역 목록.
- **규칙**:
  - 컬럼: **NO · 소재지 · 건물명 · 건물 주소 · 호실 · 해약일자 · 계기번호 · 고객번호 · 최종검침 · 이주검침 · 사용량 · 정산요금 · 한전입금일** ([_data-dictionary.md](../../_data-dictionary.md) G2 이사조회, 전기 추가필드=계기번호·고객번호·한전입금일).
  - **사용량 = 최종검침 − 이주검침**(이사 검침 기준, [_calculation-rules.md](../../_calculation-rules.md) 6절 ②).
  - **정산요금**은 이사정산(`moving-settlement`)에서 산출된 값을 조회 표시(이 화면에서 재계산하지 않음).
  - **한전입금일**은 셀 인라인 편집 가능(달력 방식). 편집 시 「저장」 활성, 저장 시 "한전입금일 N건을 저장했어요" 토스트.
  - 하단 합계(tfoot): 조회 건수·정산요금 합계 등 요약.
  - 음수 값은 빨간색 표기(`CLAUDE.md`).

### 3.3 출력(검침대장 서식)
- **기능**: 조회 결과를 인쇄물로 출력.
- **규칙**:
  - 표 컬럼 = 화면 표와 동일(NO·소재지·건물명·건물 주소·호실·해약일자·계기번호·고객번호·최종검침·이주검침·사용량·정산요금·한전입금일).
  - 하단에 관리업체 정보 블록(관리업체·주소·대표자·전화 등) 포함. **회사명 워터마크** 출력([_output-forms.md](../../_output-forms.md) 0절).
  - 조회 결과 없으면 "출력할 내역이 없어요" 안내 후 미출력.
  - 출력물 상세는 [_output-forms.md](../../_output-forms.md) 참조.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 결과 없음 | 조건에 맞는 내역 없음 | "조회 결과가 없어요 · 조회 기간이나 검색어를 바꿔 보세요" |
| 성공 | 내역 있음 | 표 + 합계 |
| 저장 비활성 | 편집 없음 | 「저장」 비활성(disabled) |
| 성공(저장) | 한전입금일 저장 | "한전입금일 N건을 저장했어요" 토스트 |
| 제한(권한) | 이사정산 메뉴 미부여 | LNB 숨김 |
| 에러 | 저장 실패 | 실패 안내·재시도([_service-policy.md](../../_service-policy.md) 6절) |
