## 1. 목적

관리업체 직원이 한 건물에 **신규 호실(세대)과 입주민 정보를 등록**하는 화면. 등록 후 이 세대의 부과·공과금·수납 관리가 시작된다.

## 2. 권한

|---|---|

| staff (일반) | LNB "건물·입주자 관리" 권한 부여 시 O ([_permission-matrix.md](../../_permission-matrix.md) 2절) |

## 3. UI (섹션 순서)

### 3.0 상단 헤더
- **기능**: "호수·입주민 등록" 제목 + 뒤로가기 / 등록 저장.
- **규칙**: **등록 저장**=8섹션 통합 저장 → **저장 시 부과 모달(3.9)** 개입. **뒤로가기**=입력 중이면 확인 모달 후 목록 이동. 공통 LNB/RNB 공유.

### 3.1 기본 정보
- **규칙**: `호실* · 입주자명 · 입금자명 · 룸(원룸·1.5룸·투룸·쓰리룸·기타) · 인원 · 평형 · 입주일 · 입주예정일 · 할인 유형(일반·수급자할인·다자녀할인·기타할인) · 할인 금액 · 기타적요 · 이사정산시적요`.
  - **할인 금액**: 할인 유형이 "일반"이면 미입력(비활성).
  - **입주일**은 달력 방식([_service-policy.md](../../_service-policy.md) 5절). 미래일(입주예정일) 입력 가능.

### 3.2 연락처·차량
- **규칙**: 전화번호(주/부, 다중) · 차량번호(다중) · 문자 수신(동의/거부) · 알림톡 수신(동의/거부) · 홈피 비밀번호. **주번호·부번호 모두 발송 수신 대상** 신규 등록(공실 세대 포함) 기본값: 문자 수신·알림톡 수신 **동의**(2026-10-18).([_notification-policy.md](../../_notification-policy.md) 4절).

### 3.3 관리비·부과
- **규칙**: 관리비 · 이사청소 · 인상액 · 부과금 여부(Y/N) · 부과일 · 이체 방식(지로·이체·자동이체·입금·없음) · 효성 회원번호(8자리) · 계약번호(3자리) · 연체료 부과 여부(O/X) · 단수 출력 여부(O/X) · 부과시 참조사항([_data-dictionary.md](../../_data-dictionary.md) C3).

### 3.4 공과금 고객번호
- **규칙**: 수도·전기·공용전기·가스 고객번호·계량기 번호, 한전고객번호·한전계기번호([_data-dictionary.md](../../_data-dictionary.md) C4).

### 3.5 고지서
- **규칙**: 출력 여부 · 이름 출력 유형(미출력·이름 출력·코드번호 출력) · 발송(우편 / 알림톡 고지서) · 인증([_status-codes.md](../../_status-codes.md) 4절). **알림톡 수신 동의 세대는 이체 방식과 무관하게 알림톡 고지서로 발송**된다.

### 3.6 전출정보
- **규칙**: 퇴실 이력 표(이사일·이름·집전화·전화(주/부)·입주일), **읽기 전용**. 신규 등록 시 비어 있음(퇴실 처리로 누적).

### 3.7 임대 정보
- **규칙**: 임대구분·개시/만료일·보증금·보증금일·임대료·전세금·은행·계좌.

### 3.8 부동산 정보
- **규칙**: 매물(물건명·구분·거래형태·면적·보증금·전세금·월세·입주가능일 등)·시설정보·이사정산체크(최대 24).

### 3.9 저장 시 "이번달 부과?" 모달
- **기능**: 등록 저장 시, 해당 건물의 **당월분 부과가 이미 확정된 경우** 신규 세대를 이번 달에 부과할지 물음.
- **규칙**: 문구·버튼은 [tenant-detail.md](../tenant-detail/tenant-detail.md) 3.9와 동일 — **[다음달부터] / [이번 달 부과]**, 이번 달 선택 시 **입주일 기준 일할 계산**([_calculation-rules.md](../../_calculation-rules.md) 1.1). 중간 입주자 당월 부과 확인 취지(기능정의서 C-2).

### 3.10 하단 액션
- **규칙**: "등록 저장" 시 검증 통과하면 저장 후 목록 이동. **필수값 미입력 시 저장 차단**.
  - **필수값**: 호실(숫자 3자리, 예: 101). 전화번호·입주자명 등은 선택 — 공실 세대 선등록·연락처 미확보 세대 대응(2026-10-18).

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 입력(기본) | 신규 진입 | 빈 폼 |
| 검증 실패 | 호실 미입력·숫자 3자리 아님 | 안내, 저장 차단 |
| 부과 확인 | 저장 시 당월 부과 확정 건물 | 이번달 부과 모달(3.9) |
| 성공 | 저장 완료 | 토스트 후 목록 이동 |
| 이탈 확인 | 입력 중 뒤로가기 | 확인 모달 |
| 에러 | 저장 실패 | 실패 안내·재시도([_service-policy.md](../../_service-policy.md) 6절) |
