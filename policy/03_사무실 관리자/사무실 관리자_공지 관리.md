## 1. 목적

세입자(resident) 앱에 노출되는 **공지를 등록·수정·삭제**하고, 대상 건물 세대에 **알림톡으로 전송**하는 화면. 공지는 세입자 앱 홈·공지 목록에 나타나며(유형별 노출 차등), 삭제 시 앱에서도 즉시 사라진다.

## 3. UI

### 3.0 상단 / 목록 헤더
- **기능**: 공지 등록 진입 + 유형 필터.
- **규칙**: "＋ 공지 등록" 버튼. 목록 상단에 건수 배지 + 유형 필터 세그(`전체 / 신규 / 중요 / 긴급`). (검색·건물 선택 없음.)

### 3.1 공지 목록
- **기능**: 등록된 공지 표시.
- **규칙**: 컬럼 `유형 · 제목 · 대상 · 게시일 · 알림톡 · 작성자`.
  - **알림톡** 셀: `발송 완료 · {N}명` 또는 `발송 대기`(수신자 수를 이 셀에 병합; 별도 수신자수·전송일시 컬럼 없음).
  - 행 클릭 → 상세/수정 모달.
  - 빈 상태 "등록된 공지가 없어요".

### 3.2 공지 등록/수정 모달
- **기능**: 공지 작성·수정.
- **규칙**: 필드 `유형(신규/중요/긴급) · 제목(최대 40자) · 내용(일시·대상·내용 순) · 대상 건물(전체 건물/개별, 다중 선택)`.
  - **대상 건물은 실제 건물 마스터 연동**(프로토타입 4개 하드코딩은 임시).
  - **수신자 수 미리보기**: 대상 건물 선택 시 "연결된 세대 N명에게 발송"을 등록/수정 화면에서도 노출.
  - 유형별 노출: **신규**=앱 공지 목록 표시 / **중요**=앱 홈 상단 강조 / **긴급**=앱에서 긴급 공지로 강조 표시. ([_status-codes.md](../../_status-codes.md) 8절)
  - **알림톡 발송은 유형과 무관하게 상세 모달에서 수동 전송**(긴급도 자동 발송하지 않음).
  - 검증: 제목·내용 필수. 저장 시 확인 모달.
  - 등록 모달에는 알림톡 발송 컨트롤 없음(발송은 상세 모달에서).
  - 삭제(상세 모달) 시 "세입자 앱에서도 즉시 사라집니다" 경고.

### 3.3 알림톡 전송 (상세 모달)
- **기능**: 공지를 대상 세대에 알림톡 발송.
- **규칙**:
  - 미발송 시 "알림톡 전송", 발송 후 "재전송" 버튼. 발송 전 "연결된 세대 N명에게 보낼 수 있어요", 후 "알림톡 N명 발송 완료".
  - 확인 모달 후 발송 상태 갱신(alim=true, recv=N) + 공용 알림톡 작성창에 공지 반영(공유 URL 포함).
  - 수신자 범위는 **대상 건물 단위만**(건물별 연결 세대 전체; 세대 개별 지정 없음). 채널·과금은 [_notification-policy.md](../../_notification-policy.md).
