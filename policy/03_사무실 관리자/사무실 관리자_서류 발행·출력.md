## 1. 목적

부과 확정된 관리비 **지로 고지서와 부속 서류를 출력**하고, 자동이체 청구 자료를 내려받거나 건물주·관계처에 **팩스로 발송**하는 문서 허브다. 문서 종류를 카드로 선택한 뒤 각 모달에서 기간과 대상을 지정하고 미리보기·인쇄·다운로드·발송을 수행한다.

## 3. UI 및 동작 규칙

### 3.0 문서 카드(랜딩)

- **고지서 출력**: `지로 고지서`
- **부속 서류**: `조정명세서`, `자동이체 세대 출력`
- **발송**: `팩스 발송`
- 카드를 누르면 해당 문서 모달을 연다.
- A4 관리비 고지서와 카카오 고지서 발송 진입점은 이 화면에서 노출하지 않는다.

### 3.1 출력 모달(공통)

- 모달은 데스크톱 기준 **1020×660px**, 헤더 61px, 본문 530px, 푸터 69px 구조다.
- 지로·조정명세서·팩스는 좌측 **340px 선택 패널**과 우측 미리보기로 나뉜다.
- 좌측 상단에서 출력 연도(2019~2026), 월분(1~12), 건물 검색(코드·건물명·주소)을 제공한다.
- 건물 표의 선택 상태와 하단 선택 카운트는 동일한 상태를 사용한다.
- 미리보기는 50~140% 범위에서 10% 단위로 확대·축소하며 100%로 초기화할 수 있다.
- 모달 닫기, 선택 행, 체크 상태, 주요 실행 버튼은 키보드와 스크린리더로 조작할 수 있어야 한다.

### 3.2 지로 고지서

- 건물 선택 후 호수·세대주·핸드폰·이체 유형을 확인하고 출력할 세대 하나를 선택한다.
- 미리보기에는 재발행·단수·자동이체 표식 영역과 지로 용지 축소판을 표시한다.
- 실제 인쇄 시 화면 축소판이 아니라 인쇄 전용 `GiroPrintView`를 사용한다.
- 인쇄 전에 `issue_bills`로 지로 발행 이력을 기록한다.
- 납기일은 해당 건물·월분의 관리비 부과 설정값을 사용한다.
- 이름/코드 표시는 세대별 고지서 출력 설정을 따른다.

### 3.3 조정명세서

- 좌측 건물 표에서 하나 이상의 건물을 선택한다.
- 선택 월과 전월의 확정 부과 자료를 함께 조회해 건물별 조정명세서를 구성한다.
- 미리보기는 고밀도 표 형태의 축소판이며, 실제 인쇄는 인쇄 전용 `AdjustmentPrintView`를 사용한다.
- 하단에는 선택 건물 수와 인쇄 버튼을 표시한다.

### 3.4 자동이체 세대 출력

- 상단에 출력 연도·월분과 부과 그룹 `전체 / 1 / 2 / 3 / 4 / 5` 세그먼트를 표시한다.
- 자동이체가 등록된 확정 부과 세대만 표에 노출한다.
- 표에는 청구타입, 회원번호, 계약번호, 회원명, 청구월, 약정일, 결제일, 상품, 기본금액, 수량, 회원구분을 표시한다.
- `다운로드`는 건물별 기존 CMS 엑셀 API를 사용하며 파일 형식은 `.xlsx`다.
- `인쇄`는 현재 자동이체 목록을 인쇄용 표로 출력한다.
- ❓ 부과 그룹 1~5의 영속 매핑 기준은 현재 조회 모델에 없으므로 확정이 필요하다.

### 3.5 팩스 발송

- 1단계 모달에서 팩스번호가 등록된 세대를 선택하고 `발송`을 누른다.
- 2단계 확인 모달에서 발신 팩스번호, 수신 팩스번호, 건물명, 선택 세대 수, 호수, 대상 월분과 장수를 확인한다.
- 수신번호가 유효한 형식일 때만 최종 발송할 수 있다.
- 최종 발송은 건물별 선택 세대를 `resolve_fax_bill_issues`로 확정한 뒤 `/api/bill/fax/send`로 접수한다.
- 접수 성공은 전송 완료가 아니라 **결과 확인 중(queued)** 으로 취급한다.
- 일부 실패 또는 접수 실패 시 확인 모달을 유지하고 재시도 안내를 노출한다.
- ❓ 클라이언트에서 선택할 발신 팩스번호 목록을 제공하는 프로필 API 연결이 필요하다.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 로딩 | 기간·건물별 확정 자료 조회 중 | 우측 미리보기 영역 로딩 표시 |
| 성공 | 유효한 대상 선택 | 미리보기와 실행 버튼 활성 |
| 제한 | 건물·세대 미선택 또는 팩스번호 없음 | 인쇄·발송 버튼 비활성 |
| 결과 없음 | 선택 월에 확정 자료 없음 | 대상 없음 안내, 실행 버튼 비활성 |
| 조회 오류 | 확정 자료 조회 실패 | 우측 오류 안내 |
| 팩스 접수 성공 | 제공자 접수 완료 | "발송을 접수했습니다. 결과 확인 중입니다." |
| 팩스 일부/전체 실패 | 제공자 접수 실패 | 실패 안내, 확인 모달 유지 |
