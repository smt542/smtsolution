## 1. 목적

관리자가 건물·월분별 도시가스 검침값과 고객번호별 부과 요약을 한 화면에서 조회·수정·저장하고, 여러 건물의 검침대장을 선택해 인쇄하는 화면이다. 성공 기준은 선택 건물의 호실 지침을 저장 가능한 형태로 편집하고 검침대장 미리보기를 출력하는 것이다.

## 2. 권한

| 사용자 | 접근 |
|---|---|
| 마스터/조직 소유자 | O |
| 일반 관리자·직원 | `utilities` 모듈 권한 보유 시 O |
| 권한 없음 | LNB 메뉴를 숨기고 직접 접근 시 권한 없음 빈 상태 노출 |

## 3. UI

### 3.0 좌측 LNB와 화면 헤더

- **기능**: 현재 화면 위치와 전역 액션을 제공한다.
- **규칙**:
  - LNB의 `공과금 관리` 그룹을 펼치고 `고객번호 조회 · 전기 · 수도 · 가스` 하위 메뉴를 노출한다. 현재 `가스` 항목은 브랜드 틴트로 활성 표시한다.
  - 화면 헤더는 상위명 `공과금 관리`, 화면명 `가스`를 2줄로 표시한다.
  - 우측에 `검침대장 출력`과 `전체 이월`을 항상 노출한다.
  - `검침대장 출력`은 3.6 모달, `전체 이월`은 3.7 확인 모달을 연다.

### 3.1 조회 월분·건물 패널

- **기능**: 조회할 연도·월분과 건물을 선택한다.
- **규칙**:
  - 최초 월분은 현재 날짜 기준 직전 달로 설정한다.
  - 연도·월분 변경 시 조회 키를 `YYYY-MM-01` 형식으로 바꾸고 선택 건물의 가스 데이터를 다시 조회한다.
  - 검색은 건물명 또는 주소에 포함되는 문자열을 즉시 필터한다.
  - 표 컬럼은 `코드 · 건물명 · 주소 · 가스`이다. `가스`는 건물별 등록된 가스 고객번호 수를 표시한다.
  - 건물 선택 행은 브랜드 틴트 배경을 유지한다.
  - 수정 모드에서는 월분·검색·건물 선택을 비활성화하고 패널 전체를 약화 표시한다.
  - 검색 결과가 0건이면 `검색 결과가 없습니다.`를 표시한다.

### 3.2 건물 미선택 초기 상태

- **기능**: 첫 진입 시 다음 행동을 안내한다.
- **규칙**:
  - 우측 편집 바는 빈 카드로 유지한다.
  - 고객번호 영역과 호실별 지침 영역에 각각 `건물을 선택해 주세요`, `선택한 건물의 고객번호가 여기에 표시돼요`를 노출한다.
  - 호실별 지침 헤더와 범례는 건물 미선택 상태에서도 유지한다.
  - Figma 기준 상태는 `673:119113`이다.

### 3.3 건물·부과기간 편집 바

- **기능**: 현재 선택 건물·월분·부과기간을 확인하고 조회/수정 모드를 전환한다.
- **규칙**:
  - 좌측에 `건물명`과 `YYYY년 M월분 가스 지침`을 표시한다.
  - 부과기간은 건물·월별 부과기간 설정(billing_period_settings)을 조회해 표시하고, 설정이 없으면 기본값 전월 16일~당월 15일을 표시한다(수도·전기와 같은 경로).
  - 조회 모드는 `수정` 버튼만 노출하고 기간 필드는 비활성 스타일이다(`673:117774`).
  - `수정` 클릭 시 테두리를 브랜드 색으로 바꾸고 `계산 · 저장 · 취소(X)`를 노출한다(`673:116091`).
  - `계산`은 현재 초안으로 요금을 재계산하고 완료 토스트를 표시한다.
  - `저장`은 당월 지침이 있거나 고정 사용량이 설정된 호실의 당월 지침·수동입력·적요를 저장한다. 공실도 저장 대상이며, 저장 성공 시 조회 모드로 돌아가고 저장 건수를 토스트로 알린다.
  - `취소(X)`는 현재 건물·월분의 로컬 초안을 폐기하고 조회 모드로 돌아간다.

### 3.4 고객번호 요약 표

- **기능**: 고객번호별 지침·사용량·요금을 집계해 보여준다.
- **규칙**:
  - 컬럼 순서는 `L · 고객번호 · 월 · 량 · 수동입력 · 할인금액 · 전월금액 · 부과액 · 전단가 · 단가 · 금-전1 · 금-전2 · 금월량 · 전월량`이다.
  - 고객번호가 없는 행은 `미지정` 그룹으로 집계한다.
  - `량`은 호실별 고정 사용량 또는 `max(0, 금월-전월)`의 합이다.
  - `부과액`은 호실 수동입력 우선, 없으면 자동부과액, 그것도 없으면 `량×해석 단가`를 합산한다.
  - 할인금액은 음수 표기로 보여준다.
  - 조회 모드는 선택 행을 브랜드 틴트로 표시한다.
  - 수정 모드에서 등록 고객번호의 `부과액`(고객번호×월 청구총액)을 직접 입력한다. 저장하면 수도·전기와 같은 규칙으로 호실 사용량 비율 배분(할인 반영·잔액 흡수, 수동입력 호실 고정)하고, 수정 중에는 초안으로 즉시 다시 배분해 보여준다. 비우고 저장하면 총액을 지우고 `량×단가`로 되돌린다(2026-10-18).
  - 배분 대상은 계량기 고객번호가 그 번호인 호실이고, 등록 번호가 하나뿐이면 계량기 고객번호가 빈 호실도 포함한다(공과금 고객번호 집계와 같은 묶음).
  - 전월금액·전단가·금-전1·금-전2처럼 현재 조회 RPC가 제공하지 않는 값은 `-`로 표시한다.

### 3.5 호실별 가스 지침 표

- **기능**: 호실별 지침과 부과 결과를 조회·수정한다.
- **규칙**:
  - 컬럼 순서는 `호수 · 입주일자 · 퇴실일자 · 퇴실예정일자 · 전월 · 금월 · 량 · 전.량 · 증감 · 수동입력 · 할인유형 · 할인금액 · 부과액 · 적요 · 처리일자 · 부과기준 · 이름 · 전화 · 라인 · 인원`이다.
  - 표는 가로·세로 스크롤을 허용하고 헤더를 상단에 고정한다.
  - 수정 모드에서는 `전월 · 금월 · 량 · 수동입력 · 적요`를 각각 입력 외형으로 표시한다. `전월`은 전월 이월값, `량`은 금월-전월 또는 고정 사용량 계산값이므로 읽기 전용이고, `금월 · 수동입력 · 적요`는 편집한다.
  - 공실 행도 검침과 공실 사용량 정산을 위해 `금월 · 수동입력 · 적요`를 편집·저장할 수 있다.
  - 고정 사용량이 있는 호실은 당월 지침을 비활성화하고, 자물쇠 버튼으로 고정 사용량 설정 모달을 연다. 저장 payload에서는 해당 행의 `current_reading`을 생략한다.
  - 사용량은 고정 사용량 우선, 없으면 `max(0, 금월-전월)`로 계산한다.
  - 수동입력 요금이 있으면 자동부과액보다 우선한다.
  - 범례는 `퇴실 예정(파랑) · 공실 사용량(빨강) · 최근 입주(초록)`이고 해당 행의 왼쪽 3px 마커로 표시한다.
  - 현재 데이터 소스에 없는 퇴실일·퇴실예정일·전화·인원은 `-`로 표시한다. 라인은 현재 행 순번을 표시한다.
  - 조회 데이터가 0건이면 `등록된 호실이 없습니다.`, 조회 중이면 로딩, 실패하면 `가스 지침을 불러오지 못했습니다.`를 표시한다.
  - `❓` 퇴실일·퇴실예정일·전화·라인·인원의 정식 API 필드 매핑이 필요하다.

### 3.6 검침대장 출력 모달

- **기능**: 여러 건물의 검침대장을 선택해 미리보고 인쇄한다.
- **규칙**:
  - 건물 선택 영역과 인쇄 미리보기 영역을 나란히 제공한다(`673:113443`).
  - 좌측에서 출력 연도·월분을 바꾸고 건물명·주소로 검색한다. 목록은 `코드 · 건물명 · 주소 · 가스 고객번호 수` 순서로 표시한다.
  - 건물을 복수 선택할 수 있으며 현재 화면에서 선택한 건물을 기본 체크한다.
  - 선택 건물마다 같은 월분의 전기·수도·가스 검침 행을 조회하고 호실 기준으로 병합해 A4 세로 통합 검침대장을 만든다.
  - 문서 제목은 `[ YYYY 년 MM 월분 검침대장 ]`이며, 상단에 주소/빌라명·키번호·수도정보·전기정보·청소정보·전화번호를 표시한다.
  - 본문은 `호수`와 `전기검침 · 수도검침 · 가스검침` 그룹을 두고 각 그룹에 `전월 · 금월 · 량 · 전량 · 평균`을 표시한 뒤 `NO · 미납액`을 배치한다.
  - 호실별로 검침값 행과 적요 행을 한 쌍으로 표시하고 한 페이지에는 최대 12개 호실을 배치한다. 하단에는 전기·수도·가스 소계와 `건물명 · 현재 / 전체` 페이지 번호를 표시한다.
  - Figma 출력물에는 회사명 워터마크와 영문 `GAS METER LEDGER` 제목을 넣지 않는다.
  - 하단에 `N곳 선택`을 표시하고 선택 0건·로딩·오류 중에는 인쇄 버튼을 비활성화한다.
  - `인쇄` 클릭 시 검침대장 영역만 브라우저 인쇄 대상으로 노출한다.

### 3.7 전체 이월 확인 모달

- **기능**: 다음 월분 이월 전에 사용자 확인을 받는다.
- **규칙**:
  - 400×157 확인 모달이며 제목은 `YYYY년 M월분 이월을 진행할까요?`, 설명은 `모든 건물의 M월분이 다음 월분으로 이월됩니다.`이다(`673:111749`).
  - `취소`는 변경 없이 닫는다.
  - 현재 구현의 `이월`은 선택 건물의 활성·비고정 호실 중 당월 지침이 비어 있고 전월 지침이 있는 행만 로컬 초안에 채운 뒤 수정 모드로 전환한다.
  - `❓` 디자인 문구의 "모든 건물" 범위와 현재 선택 건물 단위 로컬 이월의 차이를 해소할 서버 일괄 이월 정책/API가 필요하다.

## 4. 화면 상태

| 로딩 | 선택 건물·월분 조회 중 | 중앙 스피너와 로딩 문구 |

| 출력(print) | `검침대장 출력` 클릭 | 건물 다중 선택·미리보기 모달(`673:113443`) |
| 이월 확인(confirm) | `전체 이월` 클릭 | 취소·이월 확인 모달(`673:111749`) |
| 에러 | 조회·저장 실패 | 블록 오류 문구 또는 실패 토스트 |
| 권한 없음 | `utilities` 권한 없음 | 화면 접근 차단 빈 상태 |

| 지침 저장 | `save_meter_readings` RPC via `useSaveMeterReadings` | 수정 모드 저장 |
| 고정 사용량 저장·해제 | `unit_meters` upsert/update | 자물쇠 모달 |
| 검침대장 | 선택 건물별 `list_utility_rows` × 전기·수도·가스 | 출력 모달 선택·월분 변경, 호실 기준 병합 |
| 인쇄 | 브라우저 `window.print()` | 인쇄 버튼 |

- 발송 트리거는 없다.
- 공실도 표시하며 지침·수동요금·적요 입력 및 저장 대상에 포함한다.
- 계량기 고정 사용량 행은 지침값 대신 고정 사용량을 계산 분모에 사용한다.
