## 1. 목적

선택한 기준 년·월과 조회 범위로 미납 원장을 확인하고, 장기 미납 기준을 충족한 세대에 독촉 문자를 발송하며, 현재 필터 결과를 미납대장으로 출력한다.

## 2. 권한

| 권한 | 동작 |
|---|---|
| `overdue` | 화면 진입 및 조회·출력 |
| `messaging` | 「독촉 문자 발송」 사용 |
| 권한 없음 | 「권한이 없습니다」 상태를 표시하고 원장을 노출하지 않음 |

## 3. UI 및 동작 정책

### 3.0 공통 화면 구조

- 사무실 관리자 공통 LNB(240px)와 헤더(62px)를 사용한다.
- 본문은 회색 배경 위 흰색 원장 카드로 구성한다.
- 카드의 조회 툴바와 표 헤더·하단 합계는 스크롤 중에도 기준 위치를 유지한다.
- 우측의 사이드 탭과 채팅 플로팅 버튼은 공통 인프라이며 미납 관리 고유 기능이 아니다.

### 3.1 상단 조회 툴바

- 좌→우 순서: `년도 · 월 · 까지 · 전체/독촉 대상 · 전체/당계 · 건물명 검색 · 독촉 문자 발송 · 출력`.
- 년도는 현재 연도부터 최근 8개 연도, 월은 1~12월을 제공한다.
- 진입 시 기본 선택값은 올해·당월(KST)이다(2026-10-10).
- 기간과 건물은 각각 선택한다. 기간과 건물이 모두 확정되면 조회 훅을 실행한다.
- 건물명 입력은 건물 목록을 검색·선택하는 콤보박스다.
- 조회 범위:
  - `전체`: 선택 월까지 누적된 미납 월분.
  - `당계`: 선택한 년·월에 해당하는 월분.
- 독촉 대상 세그먼트는 별도의 개월·금액 드롭다운을 두지 않고 확정 기준을 만족한 세대만 필터한다.
- 독촉·출력 버튼은 빈 상태에서도 위치와 강조를 유지한다. 실행할 대상이 없으면 각각 안내 토스트를 표시한다.
- `messaging` 권한이 없으면 독촉 문자 발송 버튼만 비활성화한다.

### 3.2 빈 상태와 조회 상태

| 상태 | 조건 | 노출/동작 |
|---|---|---|
| 기간 미선택 | 년도 또는 월 미선택 | 「년도와 월을 선택해 주세요」 / 「조회 기간을 고르면 미납 내역이 표시돼요」 |
| 건물 미선택 | 기간 선택, 건물 미선택 | 「건물명을 검색해 선택해 주세요」 |
| 조회 중 | 기간·건물 선택, API 응답 전 | 중앙 로딩 표시 |
| 결과 없음 | 조회 성공, 0건 | 「조회 결과가 없어요」 |
| 독촉 대상 없음 | 독촉 대상 필터 결과 0건 | 「독촉 대상이 없어요」 |
| 조회 실패 | 조회 API 오류 | 실패 안내와 「다시 조회」 |
| 조회 성공 | 1건 이상 | 원장 표와 호합·전체 합계 |

### 3.3 미납 원장 표

- 컬럼 순서: `동호 · 거래처명 · 년월 · 연체 · 미납액 · 납.연체료 · 납.후연체 · 연체료계 · 합계 · 비고 · 전화 · 이름`.
- 세대별 월분 행을 최신 월부터 표시하고 마지막에 `[호합]` 행을 둔다.
- 하단 sticky 합계행은 `항목 N / M건`과 금액 열 전체 합계를 표시한다.
  - `N`: 월분 행 수.
  - `M`: 세대 수.
- `연체료계 = 납.연체료 + 납.후연체`, `합계 = 미납액 + 연체료계`.
- 현재 조회 API·요율표로 계산한 연체료는 `납.연체료`와 `연체료계`에 표시한다.
- `납.후연체` 원천값이 없는 경우 0으로 표시한다. 원천/산식 확정은 6절 미정 사항을 따른다.
- 원장 행을 선택하면 세대·입주자·입주·미납·연체료 상세를 모달로 표시한다.

### 3.4 독촉 대상과 문자 발송

- 독촉 대상 기준은 세대 단위로 다음 두 조건을 모두 만족해야 한다.
  1. 연체 개월수 2개월 이상.
  2. `합계(미납액 + 연체료계)` 100,000원 이상.
- 「독촉 문자 발송」은 화면의 수동 체크박스 선택이 아니라 위 기준을 만족한 세대를 자동 수신자로 담는다.
- 세대 연락처의 주번호와 부번호를 각각 수신자로 포함하되, 빈 번호와 동일한 중복 번호는 제외한다.
- 세대별 가장 최근 미납 월분으로 고지서 토큰을 발급하고 상세 링크를 만든다.
- 발송 작업창은 페이지를 가리지 않는 우측 고정 작업창으로 열린다.
  - 제목: 「문자·알림톡 발송」
  - 탭: 문자(SMS) / 알림톡
  - 발신 번호, 자동 수신자 칩, 수신자 목록, 예약 전송, 템플릿, 본문, 첫 수신자 미리보기, 하단 고정 발송 버튼을 제공한다.
  - 최소화와 닫기를 지원한다.
- 미납 관리 진입 기본값은 `SMS`, 템플릿은 「관리비 미납 안내」다.
- 치환 변수: `건물명 · 세대 · 미납금액 · 미납월 · 납기일 · 관리사무소연락처 · 상세링크`.
- 대상 세대를 담으면 「N세대를 수신자로 담았어요」, 대상이 없으면 「발송할 대상이 없어요」를 표시한다.
- 토큰 발급 또는 발송 실패 시 작업창을 열거나 성공 처리하지 않고 오류를 표시한다.
- 발송 채널·예약·과금·멱등성은 [_notification-policy.md](../../_notification-policy.md)를 따른다.

### 3.5 출력

- 「출력」은 현재 조회 범위와 독촉 대상 필터가 적용된 결과만 사용한다.
- 대상이 없으면 「출력할 미납 세대가 없습니다.」를 표시한다.
- 정책상 최종 산출물은 A4 세로 미납관리 현황이며, 제목은 `[ 미납관리 현황 {년}년 {월}월 ]`, 표는 비고를 제외한 11개 열과 호합·전체 합계를 포함한다.
- ❓ 현재 프론트엔드 구현은 임시 CSV 저장 방식이다. 공용 A4 출력 API/서식 연결 시점은 6절에서 확정한다.

## 5. 수용 기준

1. 1920px 데스크톱에서 Figma의 빈 상태·조회 결과·우측 발송 작업창 배치와 크기가 일치한다.
2. 기간 또는 건물을 변경하면 독촉 필터·상세·발송 작업창 상태가 초기화된다.
3. 전체/당계 변경이 조회 요청의 `scope`에 반영된다.
4. 독촉 대상은 `2개월 이상 AND 합계 10만원 이상`으로만 산출된다.
5. 독촉 발송은 주·부번호를 중복 없이 포함하고, 세대별 상세 링크를 치환한다.
6. 표는 12개 열, 세대별 `[호합]`, 하단 `항목 N / M건`을 유지한다.
7. 패널을 연 상태에서도 배경 원장을 확인할 수 있고 최소화·닫기가 가능하다.
8. 권한·빈 결과·조회 실패·토큰 실패가 각각 정의된 상태와 토스트를 표시한다.
