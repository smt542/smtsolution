## 1. 목적

관리업체(테넌트) 단위의 **전역 기준값**을 탭별로 설정하는 화면. 회사 대표 정보, 고지서 출력·연체 요율, 이사정산 기준, A/S 유형, 알림 조건, 그리고 기존 전산 → 신규 시스템 **데이터 이관**을 한곳에서 관리한다. 여기서 정한 값은 고지서·정산·부과·알림 등 여러 화면이 참조한다.

## 2. 권한  ([_permission-matrix.md](../../_permission-matrix.md) 2절)

| 사용자 | 접근 |
|---|---|
| staff (마스터) | O |
| staff (일반) | LNB "셋업 설정" 권한 부여 시 O (계정별 설정형) |

- 권한 모델은 [_permission-matrix.md](../../_permission-matrix.md) 2절을 따른다. 마스터가 `staff-management`에서 계정별로 이 메뉴 접근을 부여/제한(권한 칩 그룹 "설정").
- 여기서 정한 값은 테넌트 전역에 적용되므로 실질 운영은 주로 마스터가 담당한다.

## 3. UI

상단 공통 헤더에 우측 **「저장」 버튼**(전역), 그 아래 탭 바가 있다. 탭 구성: **회사 정보 · 고지서 설정 · 이사정산 설정 · A/S 설정 · 알림 설정 · 데이터 이관**. 좌측 공통 LNB, 우측 공통 RNB("A/S 접수·퇴실 신청 현황")를 공유한다(공통 인프라).

### 3.1 회사 정보 (탭)
- **기능**: 세입자 앱·고지서·알림톡에 표기되는 관리업체 대표 정보.
- **규칙**:
  - 필드: **상호 · 대표 전화 · 팩스 · 사업자등록번호 · 대표자 · 주소 · 운영 시간** ([_data-dictionary.md](../../_data-dictionary.md) A1 관리업체).
  - **대표 전화**는 건물별 담당 연락처가 없을 때 세입자 문의 안내에 노출되는 기본값. **운영 시간**은 세입자 안내 문구에 함께 표기.

### 3.2 고지서 설정 (탭)
- **기능**: 고지서 출력·발송에 쓰이는 계좌·안내문·출력옵션·연체 요율.
- **규칙**:
  - **관리비 입금 계좌**: 은행·계좌번호·예금주로 **최대 2개** 등록, 그중 **고지서에 인쇄할 1개를 선택**(라디오, 단일 선택).
  - **고객 안내사항**: 고지서 하단에 인쇄되는 자유 문구, **최대 250자** ([_output-forms.md](../../_output-forms.md) 1절).
  - **출력 옵션** (각 출력/미출력 토글):
    - **단전·단수 출력**: 연속 미납이 지정 개월 수(예: 3개월)에 도달한 세대에 예정 문구 표기. **임계 개월 수는 이 화면에서 입력**([_calculation-rules.md](../../_calculation-rules.md) 4절). ⚠️ 여기의 "단수(斷水)"는 수도 끊음 예고이며, 금액 끝자리 "단수(端數)"와 다른 개념([_calculation-rules.md](../../_calculation-rules.md) 5절).
    - **수도 단가 출력** · **관리비 기간 출력** · **증감량 표시**(전월 대비 사용량 증감).
  - **납부기한(기본 납부일)**: 관리회사별 1개. **기준 월(당월/익월) + 납부일(1~28일·말일)** 또는 「설정 안 함」. 건물·월 납기일(관리비 부과 세팅)을 따로 정하지 않은 달의 납부기한으로 쓰여 **미납 관리·연체료·이월 미납·이사정산 미납·현장 앱 기한**에 반영된다. 우선순위: 발행 고지서 납기일 → 건물·월 납기일 → **기본 납부일** → 그 달 말일. 짧은 달은 말일로 맞춘다(예: 익월 31일 → 2월 28일). 저장소 `org_billing_due_settings`(2026-10-10).
  - **관리비 연체 설정**: 전체 on/off 토글(**단리**). on일 때 **1~12개월차(12개월차 이후 포함) 경과 개월수별 요율(%)** 을 건물 정책값으로 입력. 계산식은 [_calculation-rules.md](../../_calculation-rules.md) 3절. 세대별 연체료 부과 대상 여부(O/X)는 `tenant-detail`에서 제어.

### 3.3 이사정산 설정 (탭)
- **기능**: 이사정산 내역서 계좌·정산 체크 항목·정산 기준.
- **규칙**:
  - **이사정산 입금 계좌**: 은행·계좌번호·예금주 1개. 이사정산 내역서에 인쇄([_output-forms.md](../../_output-forms.md) 4절).
  - **정산 체크 항목**: 이사정산 입력의 정산 체크에 노출되는 점검 항목명 목록, **최대 24개**. 추가·삭제·이름 편집 가능(카운터 표시).
  - **정산 기준**(계산 규칙, 모두 **읽기 전용·변경 불가**): 수도 단가 반영=반영 · 전기 단가 반영=반영 · 공실 수납 처리=수동. 계산식은 [_calculation-rules.md](../../_calculation-rules.md) 6절.

### 3.4 A/S 설정 (탭)
- **기능**: A/S 접수 화면의 유형 선택지 관리.
- **규칙**: **A/S 접수 유형**을 **최대 6개** 등록·삭제·편집(카운터 표시). 기본값=A/S신청·건물주수납·이사정산·건물주요청·안내문공지·기타 ([_status-codes.md](../../_status-codes.md) 1절 A/S 유형).

### 3.5 알림 설정 (탭)
- **기능**: 담당자 대상 자동 알림 on/off 및 선행 일수.
- **규칙**:
  - **입주 예정 세대 알림**: on/off. 입주 예정일에 대상 세대를 담당자에게 알림.
  - **임대 만료일 알림**: on/off + **만료 N일 전** 선택(1·3·5·7·14·30일). 설정 일수만큼 앞서 만료 예정 세대를 알림.

### 3.6 데이터 이관 (탭)
- **기능**: 기존 전산 데이터를 엑셀로 신규 시스템에 이전. 참조 무결성을 위해 **3그룹 순차** 진행.
- **규칙** ([_data-exchange.md](../../_data-exchange.md) 4절, 대상 8종 [_status-codes.md](../../_status-codes.md) 9·10절 data-kind):
  - **그룹 1 마스터**(서로 비의존, 먼저): `vendorMaster`(거래처) · `building`(건물 기본).
  - **그룹 2 건물 하위**(건물 코드 선행): `vendor`(건물 협력업체·선행 거래처·건물) · `util`(건물 공과금 정보·선행 건물) · `feeitem`(관리비 항목 단가·선행 건물·입주자) · `tenant`(입주자·선행 건물).
  - **그룹 3 이력**(건물·세대 등록 후): `meter`(검침 시작지침·선행 입주자) · `unpaid`(미납 잔액·선행 입주자).
  - 각 대상 행: **「양식」 다운로드 → 「업로드」**(업로드는 **엑셀 일괄등록 모달**로 진행). 상태 뱃지 **미실행 / 완료**([_status-codes.md](../../_status-codes.md) 10절). **진행 기록 초기화** 버튼(확인 모달) 제공.
  - **엑셀 일괄등록 모달 흐름**: 양식 다운로드 → **CSV(UTF-8)로 저장** → 업로드 → **「등록 전에 오류를 먼저 확인」(오류 사전검증)** → (오류 시) **오류 내역 다운로드**로 확인·수정 → **등록**. **중복 기준=코드**(동일 코드는 중복 처리). 등록 성공 시 해당 행 상태를 "완료"로 갱신.
  - 선행 대상 미완료 시 후행 업로드는 참조가 어긋날 수 있어 순서 준수를 안내(각 행에 "선행: …" 표기).

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 화면 진입 | 저장된 설정값 로드, 탭 전환 시 해당 탭 표시 |
| 성공 | 「저장」 클릭 | "저장되었습니다" 토스트([_service-policy.md](../../_service-policy.md) 6절) |
| 제한 | 정산 체크 24개 / A/S 유형 6개 도달 | 추가 버튼 비활성 + 안내 |
| 제한(읽기) | 정산 기준 3항목 | 변경 불가(읽기 전용 세그먼트) |
| 이관 완료 | 이관 항목 업로드 성공 | 해당 행 상태 "완료" 갱신 |
| 에러 | 저장·업로드 실패 | 실패 안내·재시도, 원본 데이터 훼손 없음([_service-policy.md](../../_service-policy.md) 6절) |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 회사 정보 | 관리업체(테넌트) 마스터 ([_data-dictionary.md](../../_data-dictionary.md) A1) | 고지서·알림톡·세입자 앱 표기에 참조 |
| 고지서 계좌·안내문·출력옵션 | 로컬(프로토타입) → 정식 API | `bill-publish` 고지서 출력에 반영 |
| 연체 요율(1~12개월) | 설정값(건물 정책) | 연체료 계산([_calculation-rules.md](../../_calculation-rules.md) 3절)·미납 관리 참조 |
| 단전·단수 임계 개월 | 설정값 | 고지서 예고 문구·`overdue-management`([_calculation-rules.md](../../_calculation-rules.md) 4절) |
| 이사정산 계좌·체크·기준 | 설정값 | `moving-settlement`·이사정산 내역서에 반영 |
| A/S 유형 | 설정값 | `receipt-management`·`mobile-as` 유형 선택지 |
| 알림 조건 | 설정값 | 입주 예정·임대 만료 알림 트리거 |
| 데이터 이관 | 엑셀 업로드([_data-exchange.md](../../_data-exchange.md) 4절) | 양식 다운/업로드, 상태·건수 기록 |

- 발송(문자·알림톡) **자체 트리거 없음**. 설정값이 타 화면 발송·출력·계산에 참조된다.
