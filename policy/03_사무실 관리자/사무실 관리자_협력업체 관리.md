## 1. 목적

관리업체 직원이 건물 관리에 쓰이는 **협력업체(청소·정화조·승강기·소방·CCTV 등)를 구분(카테고리)별로 등록·관리**하는 **마스터 화면**. 여기 등록한 업체는 건물 상세(`building-detail`)에서 각 건물에 배정·계약 상세를 기록하는 데 쓰인다.

## 3. UI

### 3.0 상단 헤더 / 검색
- **기능**: 화면 제목과 업체 검색.
- **규칙**: 공통 LNB·RNB 공유. **업체명·담당자·연락처**로 검색. "업체 추가" 버튼(우측).

### 3.1 구분(카테고리) 목록
- **기능**: 협력업체를 구분 단위로 묶어 보여주고, 구분별 업체 수 표시.
- **규칙**:
  - **기본 구분(9종)**: 청소 업체 · 정화조 업체 · 인터넷 업체 · 전기안전업체 · 유선방송정보업체 · 승강기보수업체 · 승강기정기검사업체 · 소방검사업체 · CCTV 업체. ("전체" 포함)
  - 구분별 업체 수(count) 표시, "전체" 선택 시 모든 업체.
  - **기본 구분(9종)**: 시스템 기본값으로 **고정**(이름 변경·삭제 불가).
  - **사용자 추가 구분**: 기본 9종 외에 새 구분 추가·이름 인라인 편집·삭제 가능.

### 3.2 업체 목록
- **기능**: 선택 구분에 속한 업체 목록.
- **규칙**: 컬럼 `구분 · 업체명 · 연락처`. 행 클릭 시 수정 모달.

### 3.3 업체 등록/수정 모달
- **기능**: 업체 정보 입력·수정.
- **규칙**: 입력 필드는 **구분 종류에 따라 다르다**.
  - **기본 구분(9종)**: `업체명* · 전화번호 · 계좌번호 · 계약서 사진(최대 10장) · 비고`
  - **사용자 추가 구분**: `업체명* · 담당자* · 연락처 · 계약서 사진(최대 10장) · 비고`
  - 필수 검증: 구분 선택 + 업체명(추가 구분은 담당자도 필수). 미충족 시 저장 차단.
  - 삭제: 확인 모달 후 실행.
  - 계약서 사진은 이미지 업로드(최대 10장)·미리보기·삭제.

### 3.4 저장
- **기능**: 등록·수정·삭제 반영.
- **규칙**: **명시적 「저장」 버튼**으로 반영(fee-item과 통일, 실수 방지), 결과 토스트로 알림([_service-policy.md](../../_service-policy.md) 6절).

## 4. 화면 상태

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 협력업체 마스터(구분·업체명·연락처·계좌·계약서사진·비고·담당자) | 로컬(프로토타입) → 정식 API | 조회/저장 |
| 건물별 협력업체 배정·계약 상세 | `building-detail` 2절 | **이 마스터에서 업체를 선택 배정**, 건물별 계약 상세는 building-detail에 기록 |

- 발송 트리거 **없음**.
- vendor-management = **전사 협력업체 마스터(풀)**. `building-detail`은 이 마스터에서 업체를 골라 각 건물에 배정한다.
