## 1. 목적

퇴실(이사정산) 세대의 **수도 공과금 정산 내역**만 모아 조회·출력하는 화면. 여러 건물의 이사정산분 중 수도 부분(고객번호·검침·정산요금·수도입금일)을 확인하고, **수도입금일**을 입력·저장하며, 검침대장 형태로 출력한다. 이사정산 입력·계산은 `moving-settlement`에서 수행하며 이 화면은 **조회·출력·입금일 관리** 전용이다.

## 2. 권한  ([_permission-matrix.md](../../_permission-matrix.md) 2절)

| 사용자 | 접근 |
|---|---|
| staff (마스터) | O |
| staff (일반) | LNB "이사정산" 권한 부여 시 O (계정별 설정형 ◐) |

- 마스터가 `staff-management`에서 계정별로 이사정산 메뉴 접근을 부여/제한한다.
- 편집 가능한 값은 **수도입금일**뿐이다.

## 3. UI

### 3.0 공통 프레임
- **기능**: 공통 LNB·RNB 공유. 브레드크럼 "이사정산" + 제목 "수도 이사조회".
- **규칙**: LNB/RNB는 공통 인프라. 본문은 조회 툴바 + 결과 표.

### 3.1 조회 툴바
- **기능**: 조회 조건 설정 + 출력·저장 액션.
- **규칙**:
  - **조회일 기간**: 시작(년·월) ~ 종료(년·월) 드롭다운.
  - **신청일**: 년·월·일 드롭다운(정산 신청일 필터).
  - **상태 세그**: `전체 · 완결 · 미결`([_status-codes.md](../../_status-codes.md) 2절). 기본 `전체`.
  - **정렬 세그**: `코드순 · 일자순`.
  - **검색**: "건물명·소재지" 즉시 필터.
  - 날짜는 드롭다운/달력 방식(직접 타이핑 금지). 드롭다운은 커스텀(`.uc-dd`), 네이티브 `<select>` 금지(`CLAUDE.md`).
  - **출력** 버튼: 검침대장 서식 인쇄(3.3). **저장** 버튼: 수도입금일 반영(3.2).

### 3.2 결과 표
- **기능**: 조건에 맞는 수도 이사정산 내역 목록.
- **규칙**:
  - 컬럼: **NO · 소재지 · 건물명 · 건물 주소 · 호실 · 해약일자 · 고객번호 · 최종검침 · 이주검침 · 사용량 · 정산요금 · 수도입금일** ([_data-dictionary.md](../../_data-dictionary.md) G2). 전기와 달리 **계기번호·한전입금일 없음**, 입금일 컬럼은 「수도입금일」.
  - 컬럼 라벨 **"건물 주소"** 사용(주소 컬럼 표기 표준).
  - **사용량 = 최종검침 − 이주검침**([_calculation-rules.md](../../_calculation-rules.md) 6절 ②). 계량기 없는 호실은 고정 사용량(예: N톤 고정) 규칙 적용([_calculation-rules.md](../../_calculation-rules.md) 2.1).
  - **정산요금**은 `moving-settlement` 산출값을 조회 표시(재계산 안 함).
  - **수도입금일** 셀 인라인 편집(달력 방식) → 「저장」 활성 → "변경사항 N건을 저장했어요" 토스트.
  - 하단 합계(tfoot) 요약. 음수는 빨간색(`CLAUDE.md`).

### 3.3 출력(검침대장 서식)
- **기능**: 조회 결과 인쇄.
- **규칙**: 표 컬럼 동일(수도입금일 포함) + 관리업체 정보 블록 + **회사명 워터마크**([_output-forms.md](../../_output-forms.md) 0절). 결과 없으면 "출력할 내역이 없어요". 상세는 [_output-forms.md](../../_output-forms.md).

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 결과 없음 | 조건 매칭 내역 없음 | "조회 결과가 없어요 · 조회 기간이나 검색어를 바꿔 보세요" |
| 성공 | 내역 있음 | 표 + 합계 |
| 저장 비활성 | 편집 없음 | 「저장」 비활성 |
| 성공(저장) | 수도입금일 저장 | "변경사항 N건을 저장했어요" 토스트 |
| 제한(권한) | 이사정산 메뉴 미부여 | LNB 숨김 |
| 에러 | 저장 실패 | 실패 안내·재시도([_service-policy.md](../../_service-policy.md) 6절) |
