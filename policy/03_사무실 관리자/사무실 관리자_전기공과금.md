## 1. 목적

한전이 고객번호(라인) 단위 총액으로 청구한 전기요금을, 해당 고객번호에 속한 호실별 사용량 비례로 안분·부과한다. 사용자는 건물·연월을 선택하고 부과기간, 고객번호별 단가와 호실별 검침값을 검토·편집·저장하며 검침대장을 인쇄할 수 있다.

- 배분 계산의 정본은 `staff/utility-electric/부과액-계산-정책.md`이며 이 문서는 화면 동작만 정의한다.
- 수도·가스는 같은 화면 골격을 사용하되, 전기 화면 진입 시 전기 데이터가 기본 조회된다.

## 3. UI

### 3.0 공통 헤더와 공과금 하위 메뉴

- **기능**: 현재 공과금 종류와 화면 전역 액션을 제공한다.
- **규칙**:
  - LNB의 공과금 관리 아래에 고객번호 조회·전기·수도·가스를 노출한다. 전기 진입 시 전기를 활성화한다.
  - `검침대장 출력`은 3.5의 출력 모달을 연다.
  - `전체 이월`은 즉시 처리하지 않고 3.6의 확인 대화상자를 연다.

### 3.1 전체 건물 패널

- **기능**: 조회 월과 대상 건물을 선택한다.
- **규칙**:
  - 연도와 월분 변경 시 선택한 공과금 종류의 해당 월 데이터를 다시 조회한다.
  - 건물명·주소 검색은 입력 즉시 코드·건물명·주소를 대상으로 목록을 필터한다.
  - 표는 `코드 · 건물명 · 주소 · 전기 고객번호 수`를 표시한다. 선택한 건물 행은 선택 상태를 유지한다.
  - 건물 선택 시 우측 고객번호 집계·호실 지침·부과기간을 조회한다.
  - 수정 모드에서는 조회 조건과 건물 변경을 막는다.

### 3.2 부과 편집 바

- **기능**: 선택 건물·대상 월·부과 시작일/종료일과 편집 상태를 제어한다.
- **규칙**:
  - 건물 미선택 시 `건물 미선택`과 대상 월을 표시하고 날짜·수정 액션은 비활성화한다. (Figma 673-79321)
  - 기본 부과기간은 전월 16일~당월 15일이며, 건물·월별 저장값이 있으면 저장값을 우선한다.
  - 조회 모드의 `수정`을 누르면 날짜·고객번호 단가·호실 입력이 활성화되고 좌측 건물 패널은 비활성화된다. (Figma 673-76879)
  - 수정 모드 액션은 `계산 · 저장 · 취소(X)`다.
    - 계산: 현재 입력값으로 사용량과 부과액을 다시 계산한다.
    - 저장: 부과기간, 전기 지침/수동요금/적요, 고객번호별 단가를 저장한 뒤 조회 모드로 복귀한다.
    - 취소: 저장하지 않고 조회 모드로 복귀한다.
  - 시작일·종료일은 필수이며 시작일이 종료일보다 늦을 수 없다.

### 3.3 고객번호 집계표

- **기능**: 선택 건물의 고객번호(라인)별 청구·부과 집계를 확인하고 편집한다.
- **규칙**:
  - 컬럼은 `L · 고객번호 · 고지금액 · 부과액 · 량 · 단가 · 금월량 · 전월량 · 검면 · 이사`다.
  - 고객번호별 호실을 묶어 사용량·금월/전월 지침·부과액을 합산한다.
  - 편집 가능한 값은 고객번호별 단가이며 저장 시 해당 건물·공과금 종류의 단가 설정으로 반영한다.
  - 고지금액은 기존 확정 정책에 따라 `부과액 × 1.11`로 계산한다. 검면·이사의 원천/산식은 현재 `list_utility_rows` 응답만으로 확정할 수 없어 6번 미정에 남긴다.
  - 건물 미선택 시 선택 안내를 표시한다.
  - 집계표는 정보 표시용이다. 행 클릭 동작·선택 강조 없음(호실표 필터 없음).

### 3.4 호실별 전기 지침표

- **기능**: 호실별 검침과 부과 결과를 조회·편집한다.
- **규칙**:
  - 컬럼은 `호수 · 입주일자 · 퇴실일자 · 퇴실예정일자 · 전월 · 금월 · 량 · 전.량 · 증감 · 수동입력 · 할인유형 · 할인금액 · 부과액 · 적요 · 처리일자 · 부과기준 · 이름 · 전화 · 라인 · 인원`이다.
  - `량 = 금월 지침 − 전월 지침`. 고정 사용량이 설정된 호실은 고정값을 사용하고 검침 입력을 저장 payload에서 제외한다.
  - 호실 부과액은 정본 배분 계산을 따른다. 수동입력 금액이 있으면 자동 계산보다 우선한다.
  - 할인유형·할인금액은 입주민/할인 설정 값을 읽어 계산에 반영한다.
  - 행 플래그는 `퇴실 예정 · 공실 사용량 · 최근 입주`다. 최근 입주는 기준일과 입주일 차이가 31일 이내인 경우다.
  - 편집 모드에서 당월 지침·수동입력 금액·적요를 입력한다. 공실은 당월 지침 입력을 비활성화한다.
  - 금월 지침이 전월보다 작아 사용량이 음수인 경우 확인이 필요하며 음수 계열 값은 경고 표기한다.
  - 월중 입·퇴실 호실은 일수 안분하지 않고 검침 사용량 기준 월 단위로 배분한다.
  - `❓` 퇴실일자·퇴실예정일자·전월 사용량·전화·인원 필드는 현재 검침 조회 응답에 없으므로 연동 원천 확정 필요.

### 3.5 검침대장 출력 모달

- **기능**: 조회 월과 출력 건물을 선택하고 검침대장을 미리 본 뒤 인쇄한다. (Figma 673-64561)
- **규칙**:
  - 연도·월분을 변경할 수 있고 코드·건물명·주소로 건물을 검색한다.
  - 건물 체크박스는 다중 선택을 허용하며 하단에 선택 수를 표시한다.
  - 선택한 첫 건물을 우측 미리보기로 보여준다. 인쇄 시 선택한 모든 건물을 각각 출력한다.
  - 선택 건물이 없거나 조회 중/오류이면 인쇄 버튼을 비활성화한다.
  - 출력물은 주소/빌라명·키번호·연락 정보와 전기/수도/가스 검침 열을 가진 검침대장 서식을 사용한다.

### 3.6 전체 이월 확인

- **기능**: 대상 월을 다음 월로 이월하기 전에 영향 범위를 재확인한다. (Figma 673-68534)
- **규칙**:
  - 문구는 `YYYY년 M월분 이월을 진행할까요?`와 `모든 건물의 M월분이 다음 월분으로 이월됩니다.`를 표시한다.
  - 취소는 변경 없이 닫는다.
  - 이월은 대상 호실의 비어 있는 금월 지침을 전월 지침으로 준비하고 수정 모드로 전환한다.
  - `❓` Figma 문구는 모든 건물 일괄 처리를 뜻하지만 현재 구현은 선택 건물의 로컬 편집값만 준비한다. 전체 건물용 서버 트랜잭션/API와 실패 복구 정책 확정이 필요하다.

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 건물 목록 | `buildings` | 화면 진입 |
| 건물별 전기 고객번호 수 | `building_customer_numbers` (`elec`, `common_elec`) | 화면 진입·종류 변경 |
| 호실별 지침/부과 | `list_utility_rows(building, elec, period)` | 건물·월·종류 변경 |
| 고정 사용량 | `unit_meters.fixed_usage` | 건물·종류 변경 |
| 부과기간 | `billing_period_settings` | 건물·월 변경, 저장 |
| 고객번호별 단가 | `list_utility_prices` / `save_utility_unit_prices` | 건물·종류 변경, 저장 |
| 지침·수동요금·적요 | `save_meter_readings` | 수정 저장 |
| 검침대장 | 선택 건물별 `list_utility_rows` + 브라우저 인쇄 | 모달 열기·선택 변경·인쇄 |

- 발송 트리거는 없다. 산출 부과액은 서류 발행·관리비 부과 화면에서 참조한다.
