## 1. 목적

특정 월 관리비 **고지서 상세**(납부 계좌·개별 사용료·공용/기타 항목·정산)를 조회하고, **계좌를 복사해 은행 이체**하도록 돕는 화면. 앱 로그인 없이 **공유 링크로도 열람** 가능.

---

## 2. 권한

| 사용자 | 접근 |
|---|---|
| resident (매칭 세대) | **R (조회 전용)** |
| 공유 링크 수신자 | **R (비로그인 열람)** — 해당 월 고지서만 |

- 앱 내 납부·수정 없음(계좌 복사 후 이체). 데이터는 관리주체(staff) 등록 자료 표시.

## 3. UI

### 3.0 헤더
- **기능**: 대상 월 표시 + 뒤로가기.
- **규칙**: "{연}년 {월} 관리비"(예: 2026년 7월 관리비).

### 3.1 납부 계좌 카드
- **기능**: 납부 계좌·총액 표시 + 복사.
- **규칙**:
  - **관리주체 납부 계좌**: 은행 · 계좌번호 · 예금주(예: 농협 352-2224-0507-03 · 스마일관리(최서윤)).
  - **상태 뱃지**(`미납`/`부분납부`/`완납`) + **총 관리비 금액**. 낼 금액(당월 미납 + 이월 미납 + 연체료)이 남았는데 이 달 수납이 있으면 `부분납부`. 연체료만 남아도(수.연 미수금) 완납이 아니며 `계좌·금액 복사`는 남은 연체료를 포함한 금액(2026-10-10).
  - 버튼 2개: **「계좌 복사」**(계좌번호만) · **「계좌·금액 복사」**(계좌번호 + 납부 금액 함께).

### 3.2 개별 사용료
- **기능**: 검침 기반 개별 사용료.
- **규칙**: **수도·전기·가스** 각 **당월 사용량 · 전월 사용량 · 금액**(예: 수도 8.2톤·전월 7.6톤·14,030원). **개별 사용료 소계**.
  - 개별 사용료 = 필수 공과금 항목(전기·수도료·가스). 그 달 부과가 없어도 **0원으로 표시**하고 섹션을 숨기지 않는다(2026-10-10).

### 3.3 공용 · 기타 관리비
- **기능**: 항목별 관리비.
- **규칙**: **실제 관리비 항목명(`fee-item` 유형별)** · 금액 목록(프로토타입의 "항목 1~17"은 더미). **공용·기타 소계**.
  - 건물 유형의 관리비 항목을 **모두** 표시하고, 그 달 부과가 없는 항목은 **0원**. 부과 후 삭제된 항목도 금액이 있으면 표시(2026-10-10).

### 3.4 정산
- **기능**: 최종 정산 집계.
- **규칙**:
  - **당월 부과액 = 개별 사용료 소계 + 공용·기타 소계**(예: 66,590 + 55,010 = 121,600원).
  - **미납액**(전월 이월 미납) · **연체료** 표시.
  - **총 관리비 = 당월 부과액 + 미납액(이월) + 연체료**(예: 121,600 + 0 + 6,800 = 128,400원). 계산 근거 [_calculation-rules.md](../../_calculation-rules.md).
  - 정산 행은 `당월 부과액 · 당월 연체료 · 이월 미납액(전월까지) · 이월 연체료(전월까지) → 총 관리비 → 납부한 금액 · 남은 금액` 순서로 나눠 표기한다. 당월 연체료 = 이 달 미납 원금 연체료 + 수.연 연체료 미수금, 이월 연체료 = 전월까지 미납분의 연체료(이 고지서 달 기준). 납부한 금액 = 이 달 부과액에 낸 금액(연체료 수납 제외), 남은 금액 = 총 관리비 − 납부한 금액(2026-10-10).

### 3.5 공유 링크 비로그인 열람 (서명 URL)
- **기능**: 로그인 없이 해당 월 고지서 열람.
- **규칙**: 공유 링크는 **건물·호수·월 + HMAC 서명 URL**(`/rb/{건물}/{호수}/{월}?s={서명}`) 형식. 파라미터는 보이되 **서명 없이는 위조·열거 불가**, 수신자는 비밀번호 없이 링크만으로 **해당 월 고지서만** 연다.
  - **유효기간 = 고지월 + 12개월.** 유효기간 내에는 마스킹 없이 전체 공개(세대·이름·금액·항목), **만료 후에는 금액 마스킹**.
  - 링크는 **서버가 무상태로 자동 발급**한다(세입자 공유 · 미납 문자/알림톡 봉투). 무상태 서명이라 개별 폐기는 없음.
  - 서명은 **건물(building) 바인딩**으로 교차 건물·조직 접근을 차단한다.
  - (기존 공유 토큰 `/r/[token]` 경로를 **대체**함.)
