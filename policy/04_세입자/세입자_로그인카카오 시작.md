## 1. 목적

세입자가 **카카오톡으로 앱을 시작(로그인)** 하는 진입 랜딩. "고지서 없이 관리비를 앱에서 바로 확인"이라는 가치 제안을 보여주고, **카카오 단일 로그인**으로 온보딩(본인인증·세대 연결) 또는 (기존 매칭) 홈으로 보낸다.

---

## 2. 권한

| 사용자 | 접근 |
|---|---|
| resident (세입자) | O — 랜딩 열람은 누구나, 시작은 카카오 인증 필요 |
| staff / partner | — (별도 표면) |

- 세입자 앱은 **카카오 기반**. 계정 발급 개념 없이 카카오 인증 + 세대 매칭으로 이용 자격이 정해진다([_service-policy.md](../../_service-policy.md), [_permission-matrix.md](../../_permission-matrix.md)).
- 이 화면은 **인증 전** 진입점. 관리비 등 실데이터는 인증·매칭 이후에만 노출된다.

---

## 3. UI

### 3.0 히어로 (가치 제안)
- **기능**: 브랜드 + 앱 소개 카피.
- **규칙**: "이번 달 관리비, 앱에서 바로 확인하세요" + 부제("고지서 없이도 항목별 금액과 납부일까지 한눈에. 납부 계좌도 바로 복사해요"). **정적 문구**(동작 없음).

### 3.1 프리뷰 카드
- **기능**: 앱에서 보게 될 관리비 화면 미리보기.
- **규칙**: "2026년 8월 관리비 · 납부 완료 · 128,400원 · 8월 21일 납부 · 그린빌라 201호"와 항목(일반관리비·전기·수도·가스) 표시. **마케팅용 고정 예시** — 실제 사용자 데이터가 아니며 조작·링크 없음.

### 3.2 카카오 시작 버튼
- **기능**: 카카오 로그인 개시.
- **규칙**:
  - "카카오톡으로 3초 만에 시작" **단일 버튼**(다른 로그인 수단 없음).
  - 탭 → 카카오 로그인(OAuth) 진행. 성공 시 분기:
    - **신규/미매칭**: 본인인증·세대 연결 온보딩(`resident-auth` 등)으로 이동.
    - **기존 매칭·세션 유효**: 홈(`resident-home`)으로(이 화면은 자동 건너뜀).
  - **실 OAuth 프로덕션 개시**: `NEXT_PUBLIC_KAKAO_LOGIN_ENABLED=true` 환경에서는 스텁이 아닌 **실제 카카오 로그인**으로 진입하고, 인증 콜백은 **공개 도메인 기준**으로 생성해 로그인 후 목적지로 복귀한다.
  - **카카오 동의 항목**: 전화번호·이름·닉네임(세대 자동 매칭·표시용) + **프로필 사진(선택 동의)**. 프로필 사진은 동의 시 아바타로 표시(→ `resident-me`·`resident-verify`), **미동의여도 로그인은 정상 진행**(글자 아바타).
  - 실패·취소: 랜딩 유지, 재시도 안내(공통 표준).

### 3.3 약관·개인정보 동의 안내
- **기능**: 시작 전 동의 고지.
- **규칙**: "이용약관 · 개인정보 처리방침에 동의하고 시작합니다" 문구. **시작 버튼을 누르면 묵시적 동의**로 간주(별도 체크박스 없음). "이용약관"·"개인정보 처리방침"은 **전문 열람 링크**로, 탭 시 각 `resident-terms`·`resident-privacy` 화면(조회 전용)으로 이동.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 기본 | 미인증 진입 | 랜딩(히어로·프리뷰·시작 버튼) |
| 자동 로그인 | 세션 유효·매칭 완료 | 이 화면 건너뛰고 홈 |
| 인증 중 | 카카오 로그인 진행 | 카카오 화면/로딩 |
| 성공 | 인증 통과 | 온보딩 또는 홈으로 분기 |
| 에러 | 인증 실패·취소 | 랜딩 유지 + 재시도(공통 표준) |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 카카오 로그인 | 카카오 OAuth/SDK (실 OAuth, `NEXT_PUBLIC_KAKAO_LOGIN_ENABLED`) | 시작 버튼 |
| 카카오 동의 항목(전화·이름·닉네임·**프로필 사진**) | 카카오 OAuth scope | 인증 시 수집(프로필 사진=선택 동의) |
| 세션·세대 매칭 상태 | 계정·매칭 데이터 | 인증 성공 후 분기 판단 |
| 프리뷰 카드 | 없음(정적 예시) | — |

- 발송 트리거 **없음**.
