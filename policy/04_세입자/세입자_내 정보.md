## 1. 목적

본인 **계정·세대 정보를 조회**하고, **퇴실 신청 · 알림 설정 · 약관 열람 · 로그아웃 · 회원탈퇴**를 하는 설정 화면.

## 2. 권한

| 사용자 | 접근 |
|---|---|
| resident (매칭 세대) | 계정·세대 **조회** + 알림 설정 · 퇴실 신청 · 세션 관리 |

- 프로필·세대 정보는 **조회 전용**(수정은 관리주체/카카오 소관).

## 3. UI

### 3.0 헤더
- **기능**: 제목.
- **규칙**: "내 정보".

### 3.1 프로필 카드 (조회 전용)
- **기능**: 계정 표시.
- **규칙**: 아바타 + **"카카오 간편 로그인"** 표기 + **이름 · 전화번호**(예: 박정호 010-3921-4482). 수정 불가.
  - **아바타 = 카카오 프로필 사진**(카카오 로그인 **선택 동의** 항목). 카카오에서 사진을 받으면 **사진으로 표시**하고, **없으면(미동의) 이름 첫 글자 아바타로 폴백**한다. 카카오 **기본(회색) 이미지도 그대로 표시**한다(직접 등록 사진과 구분하는 분기 없음).

### 3.2 세대 정보 (조회 전용)
- **기능**: 연결 세대 표시.
- **규칙**: **건물·호수 · 입주일 · 관리주체**. 변경은 관리사무소 소관(앱 수정 없음).

### 3.3 퇴실 신청
- **기능**: 퇴실 신청 시작/현황.
- **규칙**: "희망 퇴실일을 알려주세요" → **퇴실 신청 시트**(`resident-home` 3.4와 동일 기능: 달력 3일 이상 여유·진행 3단계·신청/변경/취소). **신청이 없을 때의 시작 진입점**이 여기다.

### 3.4 알림 설정
- **기능**: 알림톡 수신 상시 제어.
- **규칙**: **알림톡 토글** — "관리비 확정 안내와 서비스 공지를 카카오톡으로 받아요"(끄면 "관리비가 확정돼도 알려드리지 않아요"). **토글 즉시 반영(저장)**. `resident-notify`(온보딩) 설정과 동일 대상.

### 3.5 이용 정보
- **기능**: 약관·처리방침 열람.
- **규칙**: **이용약관** → `resident-terms`, **개인정보 처리방침** → `resident-privacy`(둘 다 조회 전용).

### 3.6 로그아웃
- **기능**: 세션 종료.
- **규칙**: **확인 모달** 후 로그아웃 → `resident-login`.

### 3.7 회원탈퇴
- **기능**: 계정 탈퇴.
- **규칙**: **확인 모달** 후 탈퇴 → **세대 연결 해제 · 개인정보 파기**(법정 보존 필요분 예외, [_service-policy.md](../../_service-policy.md) 8절 · `resident-privacy` 3절). 재이용 시 **재가입·재매칭** 필요.
- `❓` 프로토타입 "테스트: 정산 처리 완료로 전환" 버튼은 실제 앱 제외.

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 계정(카카오·이름·전화) | 계정 데이터 | 진입 시(조회) |
| 카카오 프로필 사진 | 카카오 로그인 시 수집(**선택 동의**) | 아바타 표시. 미동의 시 없음 → 글자 아바타 |
| 세대 정보 | 세대·입주자 데이터([_data-dictionary.md](../../_data-dictionary.md) C) | 진입 시(조회) |
| 알림 설정 | 사용자 설정 | 토글 시 즉시 저장 |
| 퇴실 신청 | 퇴실 신청 데이터(→ staff 퇴실 신청 현황) | 신청/변경/취소 |
| 회원탈퇴 | 계정·매칭·개인정보 | 탈퇴 확인 시(연결 해제·파기) |

- 발송 트리거 없음(알림 발송 주체는 staff).
