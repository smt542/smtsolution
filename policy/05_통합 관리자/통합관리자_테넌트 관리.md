## 1. 목적

본사가 계약 **테넌트(관리업체)를 조회·등록·수정·상태변경·삭제**하는 화면. 별도 상세 페이지 없이 **목록 + 모달**에서 모든 관리를 수행한다.

---

## 2. 권한

| 사용자 | 접근 |
|---|---|
| admin (본사 관리자) | O — 테넌트 조회·신규 등록·수정·상태변경·삭제 |

- 입주자 개인정보는 다루지 않고 **테넌트 계약·집계 정보**만 관리한다.

## 3. UI

### 3.0 헤더
- **기능**: 제목 + 신규 등록.
- **규칙**: "테넌트 관리" + **「＋ 신규 테넌트」** → 등록 모달(3.4, 신규 모드).

### 3.1 요약 카드 (4)
- **기능**: 계약 상태 요약(표시 전용).
- **규칙**:
  - **운영 중**(전체 N곳).
  - **90일 내 만료** — 연장 확인 필요(만료 90일 이내).
  - **정지** — 계약 확인 필요.
  - **해지** — **최근 12개월** 내 해지 건수.

### 3.2 상태 필터
- **기능**: 목록 필터.
- **규칙**: `전체` / `운영` / `정지` / `해지`([_status-codes.md](../../_status-codes.md) 테넌트 상태).

### 3.3 테넌트 목록 표
- **기능**: 목록 조회 + 수정 진입.
- **규칙**:
  - 컬럼: **업체명(+지역) · 건물 · 세대 · 직원 · 세입자 · 상태 · 계약 시작 · 계약 만료**. 페이지네이션.
  - **행 클릭 → 수정 모달(3.4, 수정 모드)** — 별도 상세 페이지는 없다.

### 3.4 테넌트 등록/수정 모달 (동일 폼)
- **기능**: 신규 등록 · 기존 수정 · 상태 변경 · 삭제.
- **규칙**:
  - 입력 필드(모두 필수): **상호 · 대표자 · 사업자등록번호 · 대표 전화 · 팩스 번호 · 이메일 · 주소 · 관리자 아이디 · 초기 비밀번호 · 초기 비밀번호 확인 · 계약 시작일\*(달력) · 계약 만료일\*(달력) · 상태(운영/정지/해지)**.
  - **신규 생성**: 확인 모달 "테넌트가 생성되고 **관리자 계정이 발급**됩니다".
  - **수정 저장**: 확인 모달. 상태를 **정지/해지로 변경 시 경고** — "해당 업체의 **사무·현장 관리자와 세입자 앱 접속이 제한**됩니다".
  - **계약 연장 시 운영 전환 확인**: 계약 만료로 정지된 테넌트(상태 정지 + 기존 만료일 < 오늘 KST)의 계약 만료일을 오늘 이후로 바꿔 저장하면 "운영 상태로 변경할까요?" 모달을 한 번 더 띄운다. `운영으로 변경` → 운영으로 저장(접속 재개), `정지 유지` → 정지 그대로 저장. 만료일 당일까지는 유효.
  - **삭제**(수정 모드): 빨강 확인 모달 "**삭제하면 되돌릴 수 없습니다.** 건물·세대·수납 데이터와 관리자 계정이 모두 제거됩니다".
  - 비밀번호: **신규 생성** 시 초기 비밀번호·초기 비밀번호 확인(숫자 4자리 — 사무실 관리자 계정 규칙, 2026-10-13, 일치 필수, 첫 로그인 때 변경 강제). **수정** 시 비밀번호 변경·비밀번호 변경 확인(입력할 때만 재설정, 비우면 유지).
  - 필수 미입력·비밀번호 규칙 위반·확인 불일치 → 인라인 에러.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 성공 | 테넌트 있음 | 요약 + 목록 |
| 결과 없음 | 필터 결과 0곳 | 없음 안내 |
| 확인 | 생성·저장·삭제 시도 | 확인 모달(정지/해지·삭제는 경고) |
| 로딩/에러 | 조회 중·실패 | 공통 표준 준용 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 테넌트 목록·집계(건물·세대·직원·세입자) | 테넌트 데이터 | 진입 시 |
| 계약 기간·상태 | 테넌트 계약 데이터 | 진입/저장 시 |
| 테넌트 등록·수정·삭제 | 테넌트 데이터 | 모달 저장/삭제 |
| 관리자 계정 발급 | 계정 데이터(staff 관리자 계정) | 신규 생성 시 |

- **정지/해지 → 해당 테넌트의 staff·partner·resident 접속 제한**. 삭제 → 관련 데이터·계정 전체 제거(복구 불가). 발송 트리거 없음.
