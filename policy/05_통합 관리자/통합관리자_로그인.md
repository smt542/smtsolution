## 1. 목적

**본사 관리자**가 HQ 콘솔(관리비서 본사 전용)에 로그인하는 화면. 아이디·비밀번호 단일 인증이며, 모든 로그인은 감사 로그에 기록된다.

---

## 2. 권한

| 사용자 | 접근 |
|---|---|
| admin (본사 관리자) | O — 계정 인증 후 콘솔 진입 |
| staff / partner / resident | — (별도 표면) |

- 본사 관리자 **전용 콘솔**. **입주자 개인정보는 조회되지 않는다**(데이터 경계, [_service-policy.md](../../_service-policy.md)). 본사 계정은 내부 관리(회원가입 없음).
- **크로스-persona 격리**: staff·partner·resident와 단일 인증 풀을 공유하되, 이 로그인·콘솔은 **platform_admin persona만** 통과·접근한다(서버 인가 게이트, API·페이지). 아이디는 서버에서 계정으로 해석·인증(회사코드/슬러그 불필요)([_permission-matrix.md](../../_permission-matrix.md) 7절).

---

## 3. UI

### 3.0 좌측 브랜드 패널 (안내)
- **기능**: 콘솔 소개·데이터 경계 고지.
- **규칙**: "HQ CONSOLE · 모든 관리업체를 한 콘솔에서" 소개. **"입주자 개인정보는 조회되지 않으며 모든 접근은 기록됩니다"** 경계 안내. 정적.

### 3.1 로그인 폼
- **기능**: 자격 증명 입력.
- **규칙**:
  - **아이디** 입력.
  - **비밀번호** 입력(마스킹).
  - **자동 로그인** 체크 시 아이디를 로컬 저장해 재방문 시 프리필(해제 시 삭제).
  - **로그인** 버튼 → 인증. **2단계 인증(2FA) 없음**.

### 3.2 하단 안내
- **기능**: 접근 제한·감사 고지.
- **규칙**: "본사 관리자만 접근할 수 있는 콘솔", "모든 로그인과 대리 접속은 감사 로그에 기록됩니다"(페이지 배너 문구). **대리 접속 기능은 제거됨**(구 `tenant-detail` 삭제) — 이 배너의 "대리 접속" 표현은 페이지 측 잔재로, 페이지 문구 정리 대상. 회원가입·비밀번호 찾기·소셜 링크 없음.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 기본 | 진입 | 로그인 폼(자동 로그인 시 아이디 프리필) |
| 검증 실패 | 필수값 미입력 | 인라인 에러 + 필드 포커스 |
| 인증 중 | 로그인 클릭 | 진행 안내 |
| 성공 | 인증 통과 | 대시보드(`admin/overview`) 이동 |
| 에러 | 인증 실패 | 실패 안내·재시도(공통 표준) |
