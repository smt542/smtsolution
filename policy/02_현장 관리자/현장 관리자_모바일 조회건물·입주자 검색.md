## 1. 목적

현장관리자가 **담당 건물**과 **입주자**를 검색해 건물 상세(`mobile-building`)로 진입하거나 입주자 연락처를 바로 확인하는 조회 진입 화면. partner의 조회 계열 시작점이다.

---

## 2. 권한

| 사용자 | 접근 |
|---|---|
| partner (현장관리자) | **R (읽기 전용)** — 건물·입주자 열람 |
| staff / resident | — (별도 표면) |

- 건물·세입자 정보는 partner **읽기 전용**([_permission-matrix.md](../../_permission-matrix.md) 3절, [_service-policy.md](../../_service-policy.md) 2.3). 입력 컨트롤 없음.
- **발송 없음**. 연락처는 전화 걸기(`tel:`) 링크만 제공.

---

## 3. UI

### 3.0 상단 헤더
- **기능**: 제목("조회").

### 3.1 검색
- **기능**: 텍스트 검색.
- **규칙**: 탭에 따라 placeholder·대상 전환 — 건물 탭="건물명 검색", 입주자 탭="입주자명 또는 전화번호 검색". 입력 즉시 필터.

### 3.2 탭 (건물 / 입주자)
- **기능**: 조회 대상 전환.
- **규칙**: `건물`(기본) · `입주자` 단일 선택. 탭 전환 시 검색 대상·목록 렌더 변경.

### 3.3 건물 목록
- **기능**: 건물 검색 결과 표시 + 상세 진입.
- **규칙**:
  - 카드 표시: **건물명 · 주소**.
  - 카드 탭 → 선택 건물 전달 후 `mobile-building`으로 이동.

### 3.4 입주자 목록
- **기능**: 입주자 검색 결과 표시 + 연락 확인.
- **규칙**:
  - 카드 표시: **입주자명 · 건물/호실 · 연락처(다중)**. 이름 가나다 정렬.
  - 연락처는 **전화 걸기 링크**만(주번호·부번호 등 다중 표시, [_data-dictionary.md](../../_data-dictionary.md) C2). 상세 이동 없음(읽기 목적).

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 성공 | 결과 있음 | 카드 목록 |
| 결과없음 | 검색 결과 0건 | "검색 결과가 없어요" 안내 |
| 로딩 | 조회 중 | 공통 표준 준용 |
| 에러 | 조회 실패 | 실패 안내·재시도(공통 표준) |
