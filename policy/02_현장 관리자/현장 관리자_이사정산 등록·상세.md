## 1. 목적

현장관리자가 퇴실 세대의 **이사정산 항목을 상세 입력·계산·저장**하고, 정산내역서를 PNG 이미지로 생성하는 화면(상세판). 신규 등록과 기존 정산 상세 열람·수정·삭제를 같은 화면에서 처리한다. 계산식은 [_calculation-rules.md](../../_calculation-rules.md) 6절(이사정산 계산)을 따른다. **partner의 유일한 이사정산 화면**이다(간이 화면 `mobile-moving-settlement`는 삭제·미사용).

## 2. 권한

| 사용자 | 접근 | 쓰기 |
|---|---|---|
| partner (현장관리자) | O | **O — 이사정산 입력·계산·저장** |
| staff | — | PC `moving-settlement`에서 처리 |

- partner 고정 기능 세트의 "이사정산 입력"([_permission-matrix.md](../../_permission-matrix.md) 3절). **문자·알림톡·정산문자 발송 없음** — 출력물은 내역서 **PNG 생성뿐**(partner는 발송 없음; 문자는 staff `messaging` 소관).

## 3. UI

> 상단 헤더(제목·대상 세대·내역서 버튼) + 접이식 섹션 스크롤 + 하단 고정 버튼(취소/저장). 대상 세대는 앞 화면(`mobile-tenant`)에서 전달.

### 3.1 기본
- **기능**: 정산 기준 일자·일수 입력.
- **규칙**: **퇴실일자**(달력 입력, [_service-policy.md](../../_service-policy.md) 5절 날짜=달력 통일) · **계산일수 기준** · **계산일수 부과**. 일수는 관리비 일할 계산의 분자/분모로 쓰인다([_calculation-rules.md](../../_calculation-rules.md) 1.1·6절).
  - 계산일수 · 기준 기본값 30(고정 분모), 계산일수 · 부과 기본값 = 퇴실일의 '일'(퇴실 달 실거주 일수). 퇴실일을 고르면 부과 일수를 다시 채우며, 두 값 모두 직접 수정할 수 있다. 저장된 부과 일수가 0이면 열 때 퇴실일 기준 값으로 채운다(2026-10-10).

### 3.2 공과금 정산 (전기·수도·가스)
- **기능**: 종별 지침·단가로 공과금 산출.
- **규칙**:
  - 입력: **전월 지침 · 이사 지침 · 단가 · 입금계좌 · 입금일**([_data-dictionary.md](../../_data-dictionary.md) G3).
  - **사용량 = max(0, 이사 지침 − 전월 지침)**, **금액 = round(사용량 × 단가)** 자동 계산([_calculation-rules.md](../../_calculation-rules.md) 6절 ②).
  - 이사 지침 < 전월 지침이면 카드에 경고(「전월 지침보다 작아 사용량을 0으로 계산했어요…」), 저장은 막지 않는다. 계량기 교체·한 바퀴는 전월 지침을 고쳐 반영(2026-10-10).
  - 기본값(사무실 이사정산과 동일, 2026-10-10):
    - **전월 지침**: 퇴실월 검침이면 그 달 전월 지침, 이전 달 검침이면 그 달 금월 지침. 기준 검침은 **값이 있는 가장 최근 검침**이다 — 지침이 모두 빈 행은 건너뛰고, 퇴실월 검침의 전월 지침이 비어 있으면 그 이전 달 중 금월 지침이 있는 가장 최근 달 값을 쓴다(바로 전 달에 한정하지 않음, 2026-10-11, 0307). 검침이 하나도 없으면 빈 칸.
    - **이사 지침**: 현장에서 읽은 값을 입력(빈 값으로 시작).
    - **단가**: 수도·전기는 그 달 검침 단가(셋업 3.3 「단가 반영=반영」 고정), 검침 단가가 없거나 가스는 직접 입력.
    - **입금계좌**: 셋업 「이사정산 입금 계좌」를 「은행 계좌번호 · 예금주」로 채우고, 칸 오른쪽 「복사」로 클립보드에 복사한다. **입금일**: 실제 입금한 날이라 직접 입력(자동값 없음).
    - 저장된 정산은 저장값을 쓰고, 비어 있는 단가·입금계좌만 위 기본값으로 채운다.
  - 종별 금액 합 = **① 공과금 소계**.

### 3.3 관리비 항목
- **기능**: 관리비 항목별 부과액 입력 → 정산액 산출.
- **규칙**:
  - 항목: 건물 유형에 등록된 관리비 항목(필수 공과금 항목 제외 — 공과금은 3.2 이사 검침으로 정산). 부과액 기본값 = 그 세대의 **퇴실월 부과액**, 일할·반올림은 항목 설정을 따른다(사무실 이사정산과 같은 원천). 사람이 입력하지 않은 상태(전부 0 또는 자동값 그대로)일 때만 채우고, 직접 입력한 값은 유지한다. 퇴실월이 아직 부과되지 않았으면 0(2026-10-10).
  - 일할 대상은 **정산액 = 반올림규칙(부과액 × 부과일수 ÷ 기준일수)**, 정액은 부과액 그대로([_calculation-rules.md](../../_calculation-rules.md) 1.1·1.2).
  - **가수금 · 연락처** 입력(가수금은 관리비 소계에 합산).
  - 정산액 합 + 가수금 = **② 관리비 소계**.

### 3.4 기타
- **기능**: 자유 항목(항목명·금액) 추가.
- **규칙**: 항목 **최대 15개**([_data-dictionary.md](../../_data-dictionary.md) G3). 추가/삭제 가능(최소 1행 유지). 합 = **③ 기타 소계**.

### 3.5 청소
- **기능**: 청소 담당·처리·금액 입력.
- **규칙**: 청소담당(업체) · **청소처리(미결·완료**, [_status-codes.md](../../_status-codes.md) 2절) · 청소완료일 · 청소금액 · 청소계좌 · 청소 적요. 청소금액 = **④ 청소**.

### 3.6 정산
- **기능**: 수납액·최종 수납일 입력.
- **규칙**: **수납액 · 최종 수납일**(달력). 수납액이 합계 계산의 차감분.

### 3.7 정산 체크 · 비고
- **기능**: 정산 체크리스트(최대 24항목) 및 비고.
- **규칙**: 체크 항목별 입력([_data-dictionary.md](../../_data-dictionary.md) G3 정산체크 24) · 비고 자유 입력.

### 3.8 합계
- **기능**: 소계 집계와 미수금 표시.
- **규칙**:
  - 표시: ① 공과금 · ② 관리비 · ③ 기타 · ④ 청소 · 미납 소계(①+②+③+④) · 수납액.
  - **미수금 = ① + ② + ③ + ④ − 수납액**([_calculation-rules.md](../../_calculation-rules.md) 6절). 미수금 **음수는 빨간색**(`CLAUDE.md`).

### 3.9 저장 / 내역서 / 삭제
- **기능**: 정산 저장, 내역서 PNG, (상세 모드) 삭제.
- **규칙**:
  - **저장 전제**: 퇴실일자 필수. **미수금 < 0이면 저장 차단**(확인만, 저장 안 됨) — [_calculation-rules.md](../../_calculation-rules.md) 6절 "미수금<0은 내역서 생성 차단"과 동일 기준.
  - **내역서(PNG)**: 정산 항목별 상세 + 합계, **회사명 워터마크** 포함([_output-forms.md](../../_output-forms.md) 0·4절). **미수금 < 0이면 생성 차단**. 이미지 저장(파일 다운로드)만 제공, **발송 없음**.
  - **상세 모드**(기존 정산 열람): 제목이 "이사정산 상세", 취소 버튼이 **삭제(빨강)** 로 바뀌며 확인 모달 후 목록에서 제거(복구 불가).

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 신규 입력 | 대상 세대 진입 | 빈 폼(기본값), 취소/저장 |
| 상세 | 저장된 정산 열람 | 값 프리필, 삭제/저장 + 내역서 |
| 저장 차단 | 미수금 < 0 | "입력값을 다시 확인해 주세요" 안내, 저장·내역서 불가 |
| 성공 | 저장 성공 | "이사정산을 저장했어요" 토스트, **화면 유지**(신규면 저장된 정산 상세로 전환). 삭제 성공만 입주자 화면 복귀(2026-10-10) |
| 이탈 확인 | 미저장 뒤로가기 | "작성을 취소할까요?" 확인 |
