## 1. 목적

현장관리자가 선택한 세대의 **입주자 정보·연락처**, **수납정보(조회)**, **이사정산 이력(조회)**을 확인하고, 새 이사정산 등록(`mobile-ms-new`)으로 진입하는 화면.

---

## 2. 권한

| 사용자 | 접근 |
|---|---|
| partner (현장관리자) | **R (읽기 전용)** — 입주자·수납·이사정산 이력 열람 / 이사정산 등록 진입은 O(쓰기) |
| staff / resident | — (별도 표면) |

- 입주자 정보·**수납**은 partner **읽기 전용(조회, 조작 불가)**([_permission-matrix.md](../../_permission-matrix.md) 3절, [_service-policy.md](../../_service-policy.md) 2.3).
- 이사정산 **이력은 조회**이나, **입력(계산+저장)은 partner 쓰기 가능** 기능이므로 등록 진입 버튼을 노출(입력은 `mobile-ms-new`에서 수행).
- **발송 없음** — partner는 정산문자 등 발송이 없다(문자는 staff `messaging` 소관, [_notification-policy.md](../../_notification-policy.md)).

## 3. UI

### 3.0 상단 헤더
- **기능**: 뒤로가기 + 호수·입주자명 제목 + 건물명 서브 + `이사정산 등록` 버튼.
- **규칙**: 뒤로가기 → `mobile-building`. `이사정산 등록` → `mobile-ms-new`(신규, 편집 컨텍스트 초기화).

### 3.1 탭 (입주자 정보 / 수납정보 / 이사정산)
- **기능**: 조회 영역 전환.
- **규칙**: `입주자 정보`(기본) · `수납정보` · `이사정산(N)`(건수 뱃지). 단일 선택.

### 3.2 입주자 정보 탭 (읽기)
- **기능**: 세대·연락처 조회.
- **규칙**:
  - **입주자 정보**: 건물명 · 호수 · 입주자명(없으면 `공실`) · 입주일. [_data-dictionary.md](../../_data-dictionary.md) C1.
  - **연락처**: 다중 전화(주/부, 전화 걸기 링크). 없으면 안내. [_data-dictionary.md](../../_data-dictionary.md) C2.

### 3.3 수납정보 탭 (읽기)
- **기능**: 월별 수납 이력 조회(조작 불가).
- **규칙**:
  - 월별 카드(접기/펼치기): **년월 · 기한 · 당월계**, 상세는 **연체 · 수납액 · 수수료 · 수납일자 · 은행 · 구분 · 비고**. [_data-dictionary.md](../../_data-dictionary.md) F1, 수납 구분·은행은 [_status-codes.md](../../_status-codes.md) 3절.
  - 연체 등 음수/미납 강조는 빨간색(`CLAUDE.md`). **조회 전용 — 수납 처리·수정 불가**.

### 3.4 이사정산 탭 (이력 조회)
- **기능**: 세대 이사정산 이력 조회 + 상세 진입.
- **규칙**:
  - 카드 표시: **No·이름 · 상태(`미결`(미수금>0)/`완료`) · 수납액 · 미수금 · 등록일자**. 상태값 [_status-codes.md](../../_status-codes.md) 2절(partner). 미수금 음수는 빨간색.
  - 카드 탭 → 해당 정산 레코드 전달 후 `mobile-ms-new`(상세)로 이동.
  - 계산식은 [_calculation-rules.md](../../_calculation-rules.md) 6절(정산요금·미수금).

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 성공 | 세대 로드 | 탭별 정보 표시 |
| 공실 | 입주자명 없음 | `공실` 표기 |
| 빈(수납) | 수납 이력 없음 | "수납 내역이 없어요" |
| 빈(이사정산) | 정산 이력 없음 | "이사정산 내역이 없어요" |
| 로딩/에러 | 조회 중·실패 | 공통 표준 준용 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 입주자·연락처 | 세대·입주자 데이터([_data-dictionary.md](../../_data-dictionary.md) C절) · 프로토타입 로컬 | 진입 시 로드(선택 세대) |
| 수납 이력 | 수납 데이터([_data-dictionary.md](../../_data-dictionary.md) F절) | 진입 시 로드, **읽기 전용** |
| 이사정산 이력 | 이사정산 데이터([_data-dictionary.md](../../_data-dictionary.md) G절) | 진입 시 로드 |
| 이사정산 등록/상세 이동 | `mobile-ms-new` | 버튼/카드 탭 |

- 발송 트리거 **없음**. 수납은 조회만(처리는 staff `receipt-management`).
