## 1. 목적

현장관리자가 현장에서 **새 A/S 접수를 직접 등록**하는 화면. 대상 세대·유형·접수내용·초기 처리상태를 입력해 등록하면 `mobile-home` 목록에 반영된다.

---

## 2. 권한

| 사용자 | 접근 |
|---|---|
| partner (현장관리자) | O — **A/S 등록**(쓰기) |
| staff / resident | — (별도 표면) |

- partner의 쓰기 가능 영역인 **본인 A/S 등록**에 해당([_permission-matrix.md](../../_permission-matrix.md) 3절, [_service-policy.md](../../_service-policy.md) 2.3).
- 접수자·담당자는 **로그인 현장관리자 본인**으로 고정(본인 할당 원칙).
- **발송 없음**([_notification-policy.md](../../_notification-policy.md) 3절).

## 3. UI

### 3.0 상단 헤더
- **기능**: 뒤로가기 + 제목("신규 접수").
- **규칙**: 뒤로가기 → `mobile-home`.

### 3.1 대상 세대
- **기능**: 건물·호수 선택.
- **규칙**:
  - **건물** 드롭다운 → 담당 건물 목록. 선택 시 **호수 목록 재구성**.
  - **호수** 드롭다운 → `건물 전체` + 호실 목록. 건물 변경 시 기본값 `건물 전체`.
  - 커스텀 드롭다운 규칙 준수(`CLAUDE.md`).

### 3.2 접수 정보
- **기능**: 접수 메타 + 유형·내용 입력.
- **규칙**:
  - 읽기: **접수자 · 담당자**(=본인 고정) · **접수일시**(오늘 자동) · **입주자 전화번호**.
  - 입력: **유형**(드롭다운, [_status-codes.md](../../_status-codes.md) 1절) · **접수 내용**(textarea, 등록 시 필수).

### 3.3 처리 (초기값)
- **기능**: 등록 시 초기 처리상태·시행일자·시간·처리내용 입력(선택).
- **규칙**:
  - **처리결과(상태)**: 기본 `미결`, 드롭다운 `미결·보류·완결·반복`.
  - **시행일자**: 달력 선택([_service-policy.md](../../_service-policy.md) 5절). **시간**: HH:MM 보정.
  - **처리결과 내용**: textarea(선택).

### 3.4 하단 액션
- **기능**: 취소 / 접수 등록.
- **규칙**:
  - **접수 등록**: 접수 내용 미입력 시 차단·안내. 확인 모달 후 등록, 완료 토스트 → `mobile-home` 복귀(신규 건 목록 상단 추가).
  - **취소**: 확인 모달(입력 내용 미저장 안내) 후 `mobile-home` 복귀.
