## 1. 목적

관리업체 소속 **현장관리자**가 모바일 웹에 로그인하는 화면. 아이디·비밀번호 인증만 제공하며, 회원가입·비밀번호 찾기·소셜 로그인은 두지 않는다(계정 발급·문의는 관리사무소). 성공 시 홈으로 이동한다. 하단 탭·인증 후 화면은 없다(로그인 전용).

## 2. 권한

| 사용자 | 접근 |
|---|---|
| partner (현장관리자) | O — 계정 인증 후 진입 |

- 계정 유형은 partner(현장 관리자) 고정([_permission-matrix.md](../../_permission-matrix.md) 1절). staff·resident는 각자 별도 로그인 화면.
- 계정 발급·권한은 테넌트 마스터가 staff `staff-management`에서 관리(이 화면은 인증만).
- **크로스-persona 격리·겸직**: 이 로그인은 **현장(field/partner) capability를 가진 계정만** 통과시킨다(서버 인가 게이트, `requirePersona`). staff·resident·HQ 계정으로는 진입 불가. 단 **겸직 계정**(사무실+현장)은 현장 capability를 보유하므로 이 앱에도 로그인할 수 있다([_permission-matrix.md](../../_permission-matrix.md) 7절).

---

## 3. UI

### 3.1 아이디 · 비밀번호 입력
- **기능**: 자격 증명 입력.
- **규칙**:
  - **아이디** 입력.
  - **비밀번호** 입력 + **표시/숨김 토글**(eye). 기본 마스킹.

### 3.2 자동 로그인
- **기능**: 다음 접속 시 아이디 유지.
- **규칙**: 체크 시 아이디를 로컬에 저장(프로토타입: localStorage)하여 재방문 시 프리필. 해제 시 삭제.

### 3.3 로그인 버튼 · 안내
- **기능**: 인증 실행.
- **규칙**:
  - 아이디/비밀번호 미입력 시 **인라인 에러**("아이디를 입력해 주세요" 등) 후 해당 필드 포커스.
  - 성공 시 "로그인 중이에요" 후 홈(`mobile-home`)으로 이동.
  - 하단 고정 안내: **계정 문의는 관리사무소**(문의 042-632-8770). 회원가입·비밀번호 찾기 링크 없음.

| 에러 | 인증 실패(서버) | 실패 사유 안내·재시도([_service-policy.md](../../_service-policy.md) 6절) |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 |
|---|---|---|
| 계정 인증 | 인증 API(프로토타입: 이동만) | 로그인 클릭 시 |
| 로그인 persona·capability 판정 | 서버 인가 게이트(field capability 확인, [_permission-matrix.md](../../_permission-matrix.md) 7절) | 인증 시 |
| 자동 로그인 아이디 | 로컬 저장(localStorage) | 체크/해제 시 |

- 발송 트리거 **없음**. 로그인·인증은 감사 로그의 사용자용 조회 화면 없음([_service-policy.md](../../_service-policy.md) 8절, 단순 로그인은 감사 기록 제외).
