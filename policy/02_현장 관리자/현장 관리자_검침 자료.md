## 1. 목적

현장관리자가 **선택한 건물의 전 세대**를 대상으로 수도·전기·가스 지침(전월·금월·량)을 현장에서 즉시 입력·저장하는 화면. 전월 대비 급증/급감을 경고하고, 최근 이력·신규 입주 세대를 표시해 검침값 오류를 현장에서 잡는다. 입력한 지침으로부터의 **호실별 부과 계산은 이 화면이 하지 않고**, 사무(staff) 부과 단계에서 [_calculation-rules.md](../../_calculation-rules.md) 2절(정본 `staff/utility-electric/부과액-계산-정책.md`)을 따른다.

## 2. 권한

| 사용자 | 접근 | 쓰기 |
|---|---|---|
| partner (현장관리자) | O | **O — 검침(지침) 입력·저장** |
| staff · resident | — | 해당 롤 화면에서 처리(모바일 아님) |

- partner는 [_permission-matrix.md](../../_permission-matrix.md) 3절의 **고정 기능 세트**. 검침 입력은 partner의 쓰기 허용 기능 중 하나다(그 외 쓰기는 이사정산·본인 A/S뿐).
- **발송(문자·알림톡) 없음**. 이 화면은 지침 입력·저장 전용.

## 3. UI

> partner 공통: 모바일 단일 컬럼, 하단 탭(홈/조회/프로필). 이 화면은 상단 헤더 + 하단 고정 저장 바 구조.

### 3.0 상단 헤더 · 건물 표시
- **기능**: 화면 제목("검침 자료") + 현재 대상 건물명 표시, 뒤로가기(건물 화면).
- **규칙**: 대상 건물은 앞 화면(`mobile-building`)에서 선택되어 전달된다(건물명 유지). 이 화면에서 건물을 바꾸지 않는다.

### 3.1 년월 바 (부과기간 이동)
- **기능**: 검침 대상 **년월**을 이전/다음 또는 피커로 선택. 우측에 "입력 완료 세대 수 / 전체 세대 수" 카운트.
- **규칙**:
  - 이전/다음 버튼과 년월 피커로 이동. **자료가 생성된 월만 선택 가능**하고, 아직 생성되지 않은 미래 월(회색)은 선택 시 "자료는 아직 생성되지 않았어요" 안내로 막는다.
  - 카운트 = 3종(수도·전기·가스) 금월 지침이 모두 입력된 세대 기준.

### 3.2 세대 카드(아코디언) 목록
- **기능**: 건물 내 전 세대를 호실 오름차순 카드로 나열, 탭하면 펼쳐 지침 입력.
- **규칙**:
  - 카드 헤더: **호실 · 입주자명(없으면 "공실") · 상태 뱃지**.
  - 뱃지: **신규**(입주 60일 이내, [_status-codes.md](../../_status-codes.md) 4절) / **입력완료·미입력**(3종 금월 입력 여부).

### 3.3 지침 입력 (수도·전기·가스 각 블록)
- **기능**: 종별로 전월·금월·전.량·량 입력, 최근 이력 표시.
- **규칙**:
  - 종별 단위 표기: 수도 ㎥ · 전기 kWh · 가스 ㎥([_status-codes.md](../../_status-codes.md) 6절 검침 항목).
  - 입력 필드: **전월(지침) · 금월(지침) · 전.량 · 량**([_data-dictionary.md](../../_data-dictionary.md) D2). **량 = max(0, 금월 − 전월)** 로 자동 계산되며, 량을 직접 고치면 금월이 역산된다(전월+량).
  - **최근 이력**: 직전 몇 개월의 월별 사용량(N월량)을 함께 노출해 계량기 고장·누수·오검침 판단을 돕는다([_data-dictionary.md](../../_data-dictionary.md) D3 최근 이력).
  - 전월 지침·전.량은 직전 월 저장값에서 자동 상속(수정 가능).

### 3.4 급증/급감 경고
- **기능**: 검침값 이상을 현장에서 즉시 인지.
- **규칙**:
  - **급증**: 금월 지침이 전월의 **120% 초과**면 "전월 지침 대비 N% 상승" 경고 배지 + 최초 1회 확인 팝업("검침값을 다시 확인해 주세요").
  - **급감/역전**: 금월 지침이 전월보다 **작으면** "금월 지침이 전월보다 작아요 · 검침값을 확인해 주세요" 경고.
  - **경고는 저장을 막지 않는다**(확인 후 그대로 진행 가능). 육안 확인 원칙([_calculation-rules.md](../../_calculation-rules.md) 8절, 자동 감지 없이 증감 확인).

### 3.5 세대 부가정보 (읽기 전용)
- **기능**: 입주민 전화번호·입주일·미납 현황 참고 표시 + 적요 입력.
- **규칙**:
  - **입주민 전화번호**: 등록된 주/부번호를 `tel:` 링크(누르면 통화). 없으면 "등록된 번호가 없어요".
  - **입주일** 표시(공실→최근 입주 확인용, 신규 뱃지와 연동).
  - **미납월 · 미납총 · 연체총 · 총합액**: 읽기 전용 참고값(수납은 partner 조회 전용, [_permission-matrix.md](../../_permission-matrix.md) 3절).
  - **적요**: 자유 입력(비고).

### 3.6 저장
- **기능**: 현재 년월·건물의 전 세대 지침을 일괄 저장.
- **규칙**: 하단 고정 「저장」 → 확인 모달 → 저장, 성공 토스트 후 건물 화면으로 복귀. 저장값(전월·금월·전.량·적요)은 다음 달 열람 시 전월값으로 상속된다([_calculation-rules.md](../../_calculation-rules.md) 7절 이월).

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 기본 | 건물 선택됨 | 세대 카드 목록 + 년월 바 |
| 미래 월 | 미생성 월 이동 시도 | 이동 차단 + "자료는 아직 생성되지 않았어요" |
| 경고 | 급증(>120%)·급감(역전) | 배지 + (급증) 최초 1회 확인 팝업. **저장은 계속 가능** |
| 성공 | 저장 성공 | "검침 자료를 저장했어요" 토스트 → 건물 화면 복귀 |
| 빈/에러 | 세대 없음·저장 실패 | 공통 표준 준용([_service-policy.md](../../_service-policy.md) 6절) |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 대상 건물 | 앞 화면(`mobile-building`) 선택값 | 진입 시 |
| 세대·전월지침·최근 이력 | 검침 이력(공통, 프로토타입 localStorage) | 건물·년월 선택 시 조회 |
| 금월 지침·전.량·적요 저장 | 검침 이력 테이블 | 「저장」 시 일괄 반영 |
| 입주민 연락처(주/부) | 세대 데이터([_data-dictionary.md](../../_data-dictionary.md) C2) | 읽기·`tel:` 링크 |
| 부과 계산 | **이 화면 아님** — staff 부과 단계 | [_calculation-rules.md](../../_calculation-rules.md) 2절·정본 참조 |

- 발송 트리거 **없음**. 저장된 지침이 staff 공과금 부과·검침대장([_output-forms.md](../../_output-forms.md) 2절)의 입력원이 된다.
