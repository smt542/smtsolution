### 로그인

#### OM2-001 IP 기준 로그인 실패 일시 잠금
- **화면/기능**: 로그인(`/staff/login`) / 실패 횟수 제한
- **유형**: 예외
- **우선순위**: P1
- **사전조건**: 동일 IP에서 접속한다. 존재하는 office 계정 아이디와 다른 계정 아이디를 섞어 사용한다.
- **절차**: 1. 10분 안에 잘못된 비밀번호로 9회 로그인한다. 2. 10번째 실패를 발생시킨다. 3. 같은 IP에서 올바른 비밀번호로 로그인한다. 4. 15분 경과 후 다시 올바른 비밀번호로 로그인한다.
- **기대결과**: 1까지는 폼 상단 오류 영역에 사유만 표시되고 재시도할 수 있다. 2 이후 해당 IP의 로그인은 15분간 차단되고 응답은 HTTP 429이며 `Retry-After`가 제공된다. 3은 올바른 비밀번호여도 차단된다. 4에서는 자동 해제되어 로그인에 성공한다. 계정 자체는 영구 잠금되지 않는다.
- **근거**: `policy/03_사무실 관리자/사무실 관리자_로그인.md` > 6. 결정됨 [2026-10-11] IP·아이디별 일시 잠금

#### OM2-002 아이디 기준 실패 20회 경계
- **화면/기능**: 로그인(`/staff/login`) / 실패 횟수 제한
- **유형**: 경계값
- **우선순위**: P1
- **사전조건**: office 계정 A가 있다. IP 기준 잠금(10분 내 10회)에 걸리지 않도록 여러 IP에서 분산해 시도한다.
- **절차**: 1. 15분 안에 계정 A로 19회 로그인 실패를 발생시킨다. 2. 계정 A로 올바른 비밀번호 로그인을 시도한다. 3. 다시 실패를 누적해 15분 안에 20회 실패를 만든다. 4. 다른 IP에서 계정 A로 올바른 비밀번호 로그인을 시도한다. 5. 15분 경과 후 다시 로그인한다.
- **기대결과**: 2는 19회 실패 상태이므로 로그인에 성공한다. 20회 실패에 도달하면 4는 IP와 무관하게 계정 A 기준으로 15분간 차단되고 HTTP 429와 `Retry-After`가 제공된다. 5에서 자동 해제되어 로그인할 수 있고, 계정이 영구 잠금 상태로 남지 않는다.
- **근거**: `policy/03_사무실 관리자/사무실 관리자_로그인.md` > 6. 결정됨 [2026-10-11] IP·아이디별 일시 잠금

- **사전조건**: office 계정이 있고 브라우저 로컬 저장값이 비어 있다.

- **기대결과**: 1에서 기본 마스킹(●) 상태와 평문 표시가 토글된다. 2에서 아이디가 자동으로 채워진다(비밀번호는 아님). 3에서 저장값이 제거되어 빈 폼으로 표시된다.
- **근거**: `policy/03_사무실 관리자/사무실 관리자_로그인.md` > 3.2 비밀번호, 3.3 자동 로그인, 4. 화면 상태

#### OM2-004 임시 비밀번호 계정의 첫 로그인 강제 변경
- **화면/기능**: 로그인(`/staff/login`) → 비밀번호 변경(`/staff/change-password`) / 최초 로그인
- **유형**: 상태전이
- **우선순위**: P1
- **사전조건**: 마스터가 계정·직원 관리에서 사무실 관리자 계정 B를 발급했다(임시 비밀번호).
- **절차**: 1. B의 임시 비밀번호로 로그인한다. 2. 변경 화면에서 주소창으로 `/staff/buildings`에 직접 접근한다. 3. 변경 화면에서 로그아웃을 누른다. 4. 다시 로그인해 새 비밀번호·확인을 입력하고 변경한다. 5. 새 비밀번호로 재로그인한다.
- **기대결과**: 1에서 업무 화면이 아니라 비밀번호 변경 화면으로 진입한다. 2에서 업무 화면에 들어갈 수 없다(건너뛰기 없음). 3은 허용되며 로그인 화면으로 돌아간다. 4 완료 후에야 업무 화면에 진입한다. 5에서 변경 화면을 거치지 않고 바로 업무 화면으로 진입한다.
- **근거**: `policy/01_공통 정책/서비스 전체 정책서 (4개 롤 통합).md` > 8. 보안·감사(비밀번호); `policy/03_사무실 관리자/사무실 관리자_계정·직원 관리.md` > 3.2 계정 등록·수정 모달

#### OM2-006 담당자 필터·검색 재조회와 결과 없음
- **화면/기능**: 건물·입주자 관리(`/staff/buildings`) / 검색 바·담당자 필터
- **유형**: 정상
- **우선순위**: P2
- **사전조건**: 사무 담당자 S1이 지정된 건물 2개, S2가 지정된 건물 1개가 있다.
- **절차**: 1. 검색 입력에 건물명 일부를 입력만 하고 기다린다. 2. `검색` 버튼(또는 Enter)을 누른다. 3. 검색어를 지우고 필터 패널에서 사무 담당자 S1을 선택한다. 4. 존재하지 않는 건물명으로 검색한다.
- **기대결과**: 1에서는 목록이 바뀌지 않는다(실시간 필터 아님). 2에서 목록이 재조회된다. 3에서 서버 재조회로 S1 담당 건물 2개만 표시되고 건수 배지가 `2곳`이 된다. 담당자 필터는 역할별 단일 선택이다. 4에서 "조건에 맞는 건물이 없습니다" 안내가 표시된다.

#### OM2-007 건물 목록 정렬·페이지당 건수 경계
- **화면/기능**: 건물·입주자 관리(`/staff/buildings`) / 건물 목록 페이지네이션
- **유형**: 경계값
- **우선순위**: P3
- **사전조건**: 건물이 21개 등록돼 있고 등록일이 서로 다르다.
- **절차**: 1. 진입 후 1페이지 행 수와 정렬을 확인한다. 2. 2페이지로 이동한다. 3. 페이지당 건수를 10건, 50건으로 바꾼다.
- **기대결과**: 1에서 기본 20건이 등록일 최신순으로 표시되고 헤더 건수 배지는 `21곳`이다. 2에서 가장 오래된 1건이 표시된다. 3에서 드롭다운 선택지는 10/20/50건이며 10건이면 3페이지, 50건이면 1페이지로 분할된다. 목록 영역은 고정 높이에서 헤더가 고정된 채 세로 스크롤된다.
- **근거**: `policy/03_사무실 관리자/사무실 관리자_건물·입주자 관리.md` > 3.2 건물 목록(마스터) 카드, 6. 결정됨 [2026-07-03]

#### OM2-008 입주민 관리카드 키보드 진입과 미저장 닫기 확인
- **화면/기능**: 건물·입주자 관리(`/staff/buildings`) / 입주민 관리카드 모달
- **유형**: 상태전이
- **우선순위**: P2
- **사전조건**: 입주 세대가 있는 건물을 선택했다.
- **절차**: 1. 입주민 행에 키보드 포커스를 두고 Enter를 누른다. 2. 모달을 닫고 다른 행에서 Space를 누른다. 3. 입주자명을 수정한 뒤 `Esc`를 누른다. 4. 확인을 취소하고 `저장`한다. 5. 행을 클릭했을 때 출력 모달이 열리는지 확인한다.
- **기대결과**: 1·2에서 해당 `buildingId`·`unitId` 세대의 관리카드 모달이 열린다(기본정보·연락처·부과 설정·계량기/고객번호·고지서 설정·퇴실 이력·임대차·매물 정보). 3에서 미저장 변경 확인이 표시된다. 4에서 선택 세대 정보가 저장되고 하단 세대 표의 입주자명이 갱신된다. 5에서 출력 모달은 열리지 않는다.
- **근거**: `policy/03_사무실 관리자/사무실 관리자_건물·입주자 관리.md` > 3.3 호수·입주민 목록 및 관리카드 모달, 4. 화면 상태

#### OM2-010 출력 모달 초기 선택·미선택 상태·전량 인쇄
- **화면/기능**: 건물·입주자 관리(`/staff/buildings`) / 입주자카드 및 부과내역 출력 모달
- **유형**: 정상
- **우선순위**: P2

#### OM2-051 수동입력·할인 호실이 섞인 고객번호 배분 검산
- **화면/기능**: 전기공과금(`/staff/utilities?type=electricity`) / 호실별 전기 지침표·부과액 배분
- **유형**: 계산
- **우선순위**: P1
- **사전조건**: 선택 건물 고객번호 L1의 총부과액은 100,000원, 총량은 200이다. 201호는 량 50, 수동입력 30,000원이다. 301호는 량 20, 입주민 할인금액 4,000원이다. 나머지 호실의 량 합계는 130이다.
- **절차**: 1. 건물·월을 선택하고 `수정`을 누른다. 2. 201호 수동입력에 30,000을 입력한다. 3. `계산`을 누른다. 4. 각 호실 부과액과 고객번호 집계표의 부과액을 비교한다.
- **기대결과**: 수동입력 호실은 분자와 분모에서 모두 빠진다. 잔여부과액은 100,000 − 30,000 = 70,000원, 잔여량은 200 − 50 = 150이다. 단가는 (70,000 + 4,000) ÷ 150 ≒ 493.3원이다. 201호 부과액은 30,000원으로 고정된다. 301호 부과액은 20 × 493.3 − 4,000 ≒ 5,867원이다. 나머지 호실 부과액 합계는 130 × 493.3 ≒ 64,133원이다. 30,000 + 5,867 + 64,133 = 100,000원이므로 Σ(호실 부과액)이 고객번호 부과액과 같다. 할인유형·할인금액 열에는 입주민·할인 설정값이 읽기 전용으로 표시된다.
- **근거**: `policy/03_사무실 관리자/사무실 관리자_전기공과금.md` > 3.4 호실별 전기 지침표; `policy/01_공통 정책/부과·정산 계산 규칙 (Calculation Rules).md` > 2.1 호실별 배분

- **기대결과**: 1에서는 A·B가 모두 보인다. 2에서는 B만 보인다(미지정 = 1그룹). 3에서는 A만 보인다. 건물 유형은 필터 기준이 아니다.
- **근거**: `policy/03_사무실 관리자/사무실 관리자_관리비 부과 세팅.md` > 3.0 조회조건/전체 건물, 6. 결정됨(2026-09-23)

#### OM2-080 일자계산 항목의 일할 금액과 반올림

- **우선순위**: P1

#### OM2-105 수.연(연체료 이전) 분리와 미납 원금 계산

- **유형**: 계산
- **우선순위**: P1
- **사전조건**: 선택 호실의 2026-07분 당월계 100,000원, 자동 연체료 6,000원, 수납 100,000원(원금 완납)이다.

- **근거**: `policy/03_사무실 관리자/사무실 관리자_수납관리·민원접수.md` > 3.2 수납 이력; `policy/01_공통 정책/부과·정산 계산 규칙 (Calculation Rules).md` > 3. 연체료(수.연)
