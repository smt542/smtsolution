# P7b 유형별·전체 이사조회 구현 계획

1. 조회 유형·필터·페이지 결과 타입과 React Query 키를 추가하고 RPC 매핑 테스트를 작성한다.
2. 조직·`moving` 권한, 날짜·상태·유형 검증, 검색·페이지네이션을 담당하는 `list_settlement_inquiries` RPC를 추가한다.
3. 공통 조회 컴포넌트에 4개 유형 내비게이션, 필터, 동적 요금 열, 로딩·오류·빈 상태, 페이지네이션을 구현한다.
4. Next.js 16의 비동기 `params` 규약에 맞춘 `[type]` 경로와 `generateStaticParams`를 추가한다.
5. 단위 테스트, 타입 검사, 린트, 프로덕션 빌드, 실제 DB 마이그레이션·검증을 실행한다.
6. 네 WBS 항목과 Orca 워크트리 상태를 실제 검증 결과에 맞춰 최신화한다.
