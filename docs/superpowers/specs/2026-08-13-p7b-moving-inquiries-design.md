# P7b 유형별·전체 이사조회 설계

## 목표

P7a에서 저장한 이사정산을 사무실 관리자가 수도·전기·가스·전체 기준으로 조회한다. 네 화면은 URL과 제목은 분리하되 필터·테이블·페이지네이션 구현을 공유한다.

## 화면과 경로

- `/staff/moving-settlement/inquiries/water`: 수도요금이 입력된 정산
- `/staff/moving-settlement/inquiries/electric`: 전기요금이 입력된 정산
- `/staff/moving-settlement/inquiries/gas`: 가스요금이 입력된 정산
- `/staff/moving-settlement/inquiries/all`: 날짜 범위 내 모든 정산

이사정산 입력 화면에는 네 조회 화면 바로가기를 제공하고, 조회 화면끼리는 유형 내비게이션으로 전환한다.

## 조회 계약

- 기본 기간: 사용자 로컬 시간 기준 현재 월
- 필터: 건물(전체 가능), 퇴실일 시작/종료, 건물·동·호실·입주자 검색어, 정산 상태
- 정렬: 퇴실일 최신순, 생성일 최신순, ID 최신순
- 페이지: 20건, RPC 최대 100건
- 유형별 화면은 해당 요금이 `null`이 아닌 행만 포함한다. 따라서 입력된 0원은 조회 결과에 포함한다.
- 전체 화면은 수도·전기·가스 요금을 함께 표시하고, 개별 화면은 해당 요금만 표시한다.

## 권한과 격리

클라이언트에서 `moving` 모듈 접근을 확인하고, `security definer` RPC에서도 현재 조직과 `moving` 권한을 재검증한다. RPC 실행 권한은 `authenticated`만 보유하며 `public`·`anon`은 제외한다.

## 범위 밖

엑셀 내보내기, 조회 행에서 정산 수정 화면으로 상태를 복원하는 딥링크, 수납 데이터와의 대사는 후속 작업으로 둔다.
