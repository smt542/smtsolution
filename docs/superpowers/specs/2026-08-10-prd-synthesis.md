## B. 화면별 요약 (Staff 전 화면)

### B.1 대시보드 (`/`)
- **목적**: 로그인 직후 첫 진입. 오늘 처리해야 할 업무 요약 및 각 기능 진입점.
- **UI 블록**:
  - 입주예정일 팝업: 오늘 입주예정일 세대 목록, 닫기/오늘 그만보기 버튼
  - 업무 요약 카드: 입주예정 세대 수 / 미처리 AS 건수 / 미납 세대 수 등 (표시 항목 미확정)
- **권한**: 관리자·직원 O; 현장직원 X (모바일 홈 사용)
- **데이터**: 입주자 테이블(입주예정일=오늘), AS·미납·수납 테이블

### B.2 건물 목록 (`/buildings`)
- **목적**: 등록 건물 전체 조회 + 신규 건물 등록 진입점
- **UI 블록**:
  - 상단: 건물 등록 버튼, 엑셀 다운 버튼(필터 결과 기준, `건물목록_YYYYMMDD.xlsx`)
  - 필터: 관리·검침·청소 담당자별 드롭다운 (검침담당 필터 시 엑셀 검침일자 오름차순)
  - 테이블: 건물명/주소/담당자3종/총세대수/입주세대수, 더블클릭 → 건물 상세
- **권한**: 관리자·직원 O (건물 등록·엑셀 포함); 현장직원 X
- **데이터**: buildings 테이블(RLS), 직원 테이블(필터 드롭다운)

### B.3 건물 상세·등록 (`/buildings/new`, `/buildings/:id`)
- **목적**: 건물 기본정보·시설·고객번호·협력업체·참고사항 등록·수정 (등록/수정 모드 분기)
- **UI 블록**:
  - 섹션1 기본정보: 건물명(필수)/주소(필수)/관리·검침·청소 담당자(직원 드롭다운)
  - 섹션2 시설정보: CCTV/승강기/청소/검침/관리/정화조/인터넷/전기안전/소방안전 (체크박스+메모)
  - 섹션3 고객번호: 수도/공용전기/전기/가스, 복수 등록, 검침일/부과기간/고지서출력/명의자
  - 섹션4 협력업체: 승강기/소방안전/전기안전/정화조/기타, 계약서 파일 업로드(수 제한 없음)
  - 섹션5 참고사항: 자유 텍스트 최대 1,000자
  - 입주자 목록 섹션 상단에 입주자카드·관리비부과내역서 출력 버튼
- **권한**: 관리자·직원 O; 현장직원 X
- **데이터**: buildings 테이블(RLS), 직원 테이블, 파일 스토리지(S3)

### B.4 입주자 목록 (`/buildings/:id` 탭)
- **목적**: 건물 내 전체 세대(호실) 목록 조회, 입주자 관리 진입점
- **UI 블록**:
  - 상단: 입주자 등록 버튼, 입주자카드 출력 버튼, 관리비부과내역서 출력 버튼 (회사명 워터마크)
  - 테이블: 호실명/입주자명/룸타입/인원/입주일/공실여부/연체여부; 더블클릭 → 입주자 상세
- **권한**: 관리자·직원 O; 현장직원 X
- **데이터**: units/occupancies 테이블(RLS)

### B.5 입주자 상세·등록 (`/buildings/:id/tenants/new`, `/buildings/:id/tenants/:tenantId`)
- **목적**: 세대별 입주자 정보 등록·수정 (모드 분기)
- **UI 블록**:
  - 섹션1 기본정보: 호실명/이름/입금자명/룸타입/인원/연락처3개/차량번호/입주일(미래 날짜=입주예정일 허용)
  - 섹션2 부과·출력 설정: 부과Y/N, 출력Y/N, 공실처리Y/N, 퇴실일자, 연체료부과Y/N, 단수출력Y/N, 적요, 이사정산시 적요
  - 섹션3 계량기·계좌: 수도·전기·가스 계량기번호/고객번호; 수도·전기·가스·관리비 각 계좌(은행명/계좌번호/예금주)
  - 섹션4 임대차: 보증금/월세/계약시작·종료일/만료알림Y/N; 이전 전출자 이력(읽기전용)
  - 섹션5 시설정보: 자유 텍스트
  - 입주예정일(미래 입주일) → 대시보드 팝업 트리거
- **권한**: 관리자·직원 O; 현장직원 X
- **데이터**: occupancies/units 테이블, 룸타입 설정, 입주 이력 테이블

### B.6 전기·수도·가스 지침·부과 (`/utilities`)
- **목적**: 건물별 수도·전기·가스 지침값 일괄 입력 + 세대별 요금 자동 계산·부과
- **UI 블록**:
  - 상단: 건물 선택, 수도/전기/가스 탭, 부과계산 버튼, 검침대장 다운(xlsx, `[건물명]_[유형]_검침대장_YYYYMM.xlsx`), 6개월 이력 버튼
  - 테이블: 호실명/입주자명/전월지침(자동)/당월지침(입력)/사용량(자동)/자동계산요금/수동입력요금/적요/수도부과처리일자
  - 특이 처리: 공실 비활성, 수도 할인(수급자·다자녀), 상가 고정사용량, 층별 단가 분리, 신규입주 파란색 강조
  - 6개월 이력 팝업: 월/부과액/전월대비 증감/단가/단가증감
- **권한**: 관리자·직원 O (검침대장 다운 포함); 현장직원 X (모바일에서 지침 입력)
- **데이터**: 지침 이력 테이블, 입주자 설정(할인·고정량), 부과 이력 테이블

### B.7 관리비 부과 셋팅 (`/management-fee`)
- **목적**: 건물별·세대별 관리비 항목 설정 + 당월 금액 입력 + 부과 확정
- **UI 블록**:
  - 상단: 건물 선택, 관리비 항목 관리 버튼(모달), 부과 확정 버튼(확인 팝업)
  - 관리비 항목 모달: 항목명/이월Y/N (이월Y=다음달 자동이월; 이월N=매월초기화)
  - 테이블: 호실명/룸타입/입주일/합계관리비 + 항목별(부과Y/N + 금액), 일할계산(중간입주), 최근 1개월 전후 색상 강조
  - 신규 입주자 당월 부과 팝업: 부과 확정 후 신규 입주자 등록 시 자동 팝업
  - 건물별 셋팅 확인 체크박스: 특정 건물 진입 시 확인 팝업
- **권한**: 관리자·직원 O (항목등록·수정·부과확정 포함); 현장직원 X
- **데이터**: 관리비 항목 테이블, 부과 이력 테이블, 부과 확정 테이블

### B.8 고지서 발행·출력 (`/bill`)
- **목적**: 부과 확정된 관리비를 지로·A4·카톡·팩스로 발행·발송 (건물별 일괄 + 세대별 개별)
- **UI 블록**:
  - 상단: 건물 선택, 발행유형(지로/A4/카톡/팩스, 복수선택), 그룹 선택, 세대표기(코드/이름출력), 조정명세서 출력(그룹별 분리), 자동이체 세대 출력(그룹별 분리)
  - 테이블: 호실명/입주자명/고지서유형/그룹/자동이체여부/발송상태; 전체·개별 체크박스
  - 지로·A4: QR코드 자동포함, 자동이체 표시, 프로그램 회사명 하단 인쇄
  - 카톡: 공용 발송 모듈(`/messaging`) 호출, 즉시/예약 발송, 그룹·주부번호 선택 → NCP 알림톡 API
  - 팩스: 세대별 팩스번호 필요, 일괄 발송
  - 출력 옵션: 단수 표기·해지 설정, 납기일 자유 변경 (발행 시점에 개별 설정)
- **권한**: 관리자·직원 O; 현장직원 X
- **데이터**: 부과 확정 테이블, 공용 발송 모듈 → NCP API

### B.9 수납처리·자동이체 (`/payment`)
- **목적**: 세대별 관리비 수납 수동·자동 처리, 지로 수납, 자동이체 세대 관리
- **UI 블록**:
  - 상단: 건물 선택 + 이름·호실명 검색, 엑셀 업로드 버튼, 자동이체 세대 다운 버튼
  - 테이블: 호실명/입주자명/부과금액/수납금액/미납금액/납기일/비고/수납상태
  - 처리 유형: 수납(전액) / 원금(연체료 제외) / 취소 / 분할
  - 지로 수납 영역: 지로납부 세대 수납 처리 + 원장 조회
  - 엑셀 자동 매칭: 고객번호→이름→금액 순 3단계, 미매칭 수동 처리
  - 효성CMS 워크플로우: 회원번호 등록→엑셀 다운(회원번호 오름차순)→청구금액 붙여넣기 (API 직접 연동 제외)
- **권한**: 관리자·직원 O; 현장직원 X
- **데이터**: 수납 테이블, 지로 수납 테이블, 부과 확정 테이블

### B.10 수납관리·민원접수 (`/receipts`)
- **목적**: 세대별 수납현황 조회 + 민원·AS 접수·처리 통합 운영 화면
- **UI 블록**:
  - 상단: 금액/이름/건물명 검색, AS접수현황 팝업 버튼
  - 수납현황 테이블(상단): 건물명/호실명/입주자명/부과금액/수납금액/미납금액/납기일/수납상태; 고지서 문자 전송(공용 모듈 호출); 빌라별 요약, 수납명세서·영수증 출력
  - 민원접수 영역(하단): 미결/완결/보류/반복 필터; 목록(접수일/건물명/호실명/입주자명/접수내용/상태/처리결과); 신규 민원 접수; 담당 기사 문자 전송(공용 모듈 호출)
  - AS접수현황 팝업(새창): 건물별·날짜별 조회, 엑셀 다운, 호실 더블클릭 → 해당 세대 수납관리 이동
- **권한**: 관리자·직원 O; 현장직원 X
- **데이터**: 수납 테이블, 민원 테이블(RLS)

### B.11 미납관리 (`/overdue`)
- **목적**: 건물별 미납 세대 조회, 채권 관리 대상 필터, 독촉 문자 발송, 미납대장 출력
- **UI 블록**:
  - 상단: 건물 선택, 채권 관리 필터 버튼(연체 3개월↑ AND 10만원↑, 고정값), 미납대장 출력, 독촉 문자 발송(공용 모듈 호출)
  - 테이블: 호실명/입주자명/연락처/연체개월수/미납금액/최근납부일; 전체·개별 체크박스
  - 단전·단수 예고: 연체 2개월↑ 세대 → 3개월째 고지서 발송 시 자동 인쇄 (별도 설정 없음)
- **권한**: 관리자·직원 O; 현장직원 X
- **데이터**: 수납·부과 테이블(RLS), 공용 발송 모듈 → NCP SMS API

### B.12 이사정산 (`/moving-settlement`)
- **목적**: 퇴실 세대 이사정산 내역 작성·계산·출력, 중도퇴실/정산완료+공실 처리
- **UI 블록**:
  - 상단: 건물→호실 선택, 날짜 범위 이사정산 이력 조회, 수도·전기·가스 이사 조회
  - 좌측 검침정보 패널: 수도·전기·가스 전월·당월 지침·사용량 (상시 표시, 읽기전용)
  - 입력 영역: 퇴실일자/관리비(일할계산)/지침값/전기·가스 입금일(달력만)/수리비(귀속 선택)/정산금 입금계좌(자동)/하단비고/이사정산 시 적요
  - 내부 시설점검 체크리스트: 셋업에서 등록된 항목
  - 하단 버튼: 정산금 계산 / 계산+저장 / 중도퇴실 / 정산완료+공실 / 출력 / 빈양식
  - 정산완료+공실: 미납 수납 확인팝업, 수도 지침 자동이월, 적요 리셋, 입주 이력 누적 저장
  - 중도퇴실: 공실처리 없음, 종이고지서→카톡 자동 변경, 수납적요 "중도퇴실" 자동 기재
- **권한**: 관리자·직원 O (전 버튼); 현장직원 O (계산+저장만, 모바일)
- **데이터**: 세대·지침 이력·셋업 설정 테이블, 수납 테이블, 입주 이력 테이블

### B.13 문자·알림톡 발송 (`/messaging`) — 공용 모듈
- **목적**: 흩어진 개별 발송(고지서·독촉·정산·민원)을 단일 발송 엔진으로 통합. GNB 독립 진입 + 타 화면 컨텍스트 호출 병행.
- **UI 블록**:
  - 발송 채널: 문자(SMS) / 알림톡
  - 수신처 선택: 건물/그룹/개별세대/미납세대/자동이체세대; 입주자·건물주·담당기사·청소담당자·관리실직원; 주번호·부번호 각각 on/off
  - 내용: 템플릿(고지서/독촉/정산내역서/민원AS안내/공지3종/자주보내는문자) 또는 자유본문+치환변수
  - 발송 시점: 즉시 / 예약(기간·횟수 제한 없음, 취소 가능)
  - 결과: 성공N건/실패N건, 실패 건 재발송, 발송 이력 저장
- **컨텍스트 호출 프리셋**:

  | 호출 화면 | 진입점 버튼 | 프리셋 수신처 | 프리셋 템플릿 |
  |---|---|---|---|
  | 고지서 발행(`/bill`) | 카톡 고지서 발송 | 선택 세대(그룹/개별/주부번호) | 고지서(알림톡) |
  | 수납관리(`/receipts`) | 고지서 문자 전송 | 선택 세대 세입자 | 고지서 |
  | 수납관리(`/receipts`) | 담당 기사 문자 전송 | 해당 민원 담당 기사 | 민원/AS 안내 |
  | 미납관리(`/overdue`) | 독촉 문자 발송 | 선택/필터 연체 세대 | 독촉 |
  | 모바일 이사정산(`/m/moving-settlement`) | 정산내역서 문자 전송 | 퇴실자·건물주 | 정산내역서 |
  | 세입자 앱 공지(관리자) | 공지 알림톡 발송 | 건물/그룹 세대 | 공지(신규·중요·긴급) |

- **권한**: 관리자·직원 O; 현장직원 컨텍스트 진입만
- **데이터**: NCP SMS/알림톡 API, 발송 이력 테이블

### B.14 계정·직원 관리 (`/accounts`)

    - 스태프(청소담당자·관리실직원 등): 아이디/비밀번호/담당역할/소속(청소팀 등)

- **데이터**: 계정·직원·입주자 테이블(RLS), 건물 상세 담당자 드롭다운·발송 모듈 수신처와 참조 연동

  - 탭⑤-장기수선비: 건물별 공사 이력(공사명/공사일/금액/영수증·사진 파일, 수 제한 없음)
- **권한**: 관리자·직원 O; 현장직원 X
- **데이터**: 설정 테이블(RLS), 파일 스토리지(S3), 변경 즉시 전 화면 드롭다운 반영
