## 1. 목적

관리업체 직원이 퇴실 세대의 이사 정산 내역을 작성·계산·출력하고, 중도퇴실 또는 정산완료+공실 처리를 수행하는 화면. 세대 선택부터 정산 완료까지 단일 페이지에서 처리한다.

## 3. UI

### 3.0 상단 세대 선택 영역

- **기능**: 이사정산 대상 세대 선택 및 날짜별 이사정산 이력 조회
- **규칙**:
  - 건물 선택 드롭다운 → 호실 선택 드롭다운 순서로 세대 지정
  - 날짜 지정 이사정산 일괄 조회: 날짜 범위 선택 → 해당 기간 정산 이력 목록 표시
  - 수도·전기·가스 이사 조회 버튼: 각 유형별 이사 조회 결과 표시

### 3.1 검침정보 패널 (좌측 고정)

- **기능**: 이사정산 입력 중 검침 정보를 언제든 확인할 수 있는 참조 패널
- **규칙**:
  - 화면 왼쪽에 항상 표시 (작은 창 형태)
  - 표시 항목: 수도·전기·가스 전월·당월 지침값 / 사용량
  - 읽기 전용, 수정 불가

### 3.2 이사정산 입력 영역

- **기능**: 퇴실 세대의 정산 내역 입력
- **규칙**:
  - 입력 항목:
    - 퇴실일자 (달력 선택, 필수)
    - 관리비 계산: 퇴실일까지 일할 계산 자동 적용
    - 수도·전기·가스 지침값 (이사정산 시 수도 지침값 자동 이월)
    - 전기요금·가스요금 입금일 (달력 버튼으로만 조작, 마우스 전용)
    - 수리비 항목: 금액 입력 + 귀속 선택 (건물주에게 입금 / 관리자(이름)에게 입금 / 관리실 보관)
    - 정산금 입금 계좌: 자동 표시 (셋업 설정에서 등록된 계좌), 수정 가능
    - 하단 비고 입력란 (자유 텍스트)
    - 이사정산 시 적요 (입주자 정보의 이사정산 시 적요와 연동)

### 3.3 내부 시설점검 체크리스트

- **기능**: 퇴실 시 세대 내부 시설 점검 항목 체크
- **규칙**:
  - 체크 항목: 셋업 설정에서 등록된 시설점검 항목 표시
  - 체크박스로 점검 완료 여부 표시
  - 이사정산 내역서 출력 시 포함 가능

### 3.4 하단 액션 버튼 영역

- **기능**: 이사정산 관련 주요 처리 버튼 제공
- **규칙**:
  - `정산금 계산`: 입력된 항목 기준으로 정산금 자동 계산, 저장 없음
  - `계산+저장`: 정산금 계산 후 즉시 저장
  - `중도퇴실`:
    - 공실 처리 없음
    - 종이고지서 수령 세대 → 자동으로 카톡 고지서로 변경
    - 수납관리 페이지 해당 호실 적요에 "중도퇴실" 자동 기재
  - `정산완료+공실`:
    - 퇴실 처리 실행
    - 미납 관리비 전부 수납 처리 → "미납 관리비 N건을 수납 처리하시겠습니까?" 확인 팝업 후 실행
    - 전기·가스요금 입금일 달력 버튼으로 입력 (마우스 전용)
    - 수도 지침값 자동 이월
    - 입주자 정보 적요 리셋
    - 이전 전출자 정보 자동 누적 저장 (입주 이력 테이블)
  - `출력`: 이사정산 내역서 출력
  - `빈양식`: 빈 이사정산 내역서 양식 출력

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 세대 미선택 | "건물과 호실을 선택해 주세요" 안내 |
| 입력 대기 | 세대 선택 완료 | 기존 저장 데이터 불러와 표시, 입력 대기 |
| 계산 완료 | `정산금 계산` 클릭 후 | 정산금 자동 계산 결과 표시, 저장 미적용 |
| 저장 완료 | `계산+저장` 클릭 후 | "저장되었습니다" 토스트 메시지 |
| 중도퇴실 완료 | `중도퇴실` 클릭 후 | 고지서 유형 카톡으로 변경, 수납관리 적요 업데이트 |
| 정산완료 | `정산완료+공실` 확인 팝업 후 | 퇴실 처리·미납 수납·적요 리셋 일괄 처리 |
| 에러 | 처리 실패 | "오류가 발생했습니다. 다시 시도해 주세요." + 재시도 버튼 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 세대 정보 | 내부 DB (tenant 격리 RLS 적용) | 세대 선택 시 자동 조회 |
| 검침정보 | 내부 DB — 지침 이력 테이블 | 세대 선택 시 자동 조회, 좌측 패널 표시 |
| 정산금 입금 계좌 | 내부 DB — 셋업 설정 테이블 | 세대 선택 시 자동 표시 |
| 시설점검 항목 | 내부 DB — 셋업 설정 테이블 | 세대 선택 시 자동 조회 |
| 미납 관리비 수납 처리 | 내부 DB — 수납 테이블 | `정산완료+공실` 확인 팝업 후 트리거 |
| 이전 전출자 이력 저장 | 내부 DB — 입주 이력 테이블 | `정산완료+공실` 실행 시 자동 저장 |
| 이사정산 내역서 출력 | 서버사이드 생성 | `출력` 버튼 클릭 시 트리거 |
