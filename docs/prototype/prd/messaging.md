## 1. 목적

관리업체 직원이 세대·인물을 자유롭게 골라 문자(SMS)·알림톡을 발송하는 **공용 발송 모듈**. 흩어져 있던 각 화면의 개별 발송(고지서·독촉·정산·민원)을 하나의 발송 엔진으로 통합한다. 발송 UI·수신처·템플릿·발송 규칙은 이 문서에서 단일 정의하고, 다른 화면은 이 모듈을 **호출(프리셋 전달)**하여 사용한다.

## 3. 진입 방식

- **① 독립 진입 (GNB)**: 수신처·유형·내용을 처음부터 자유롭게 구성하여 발송. 특정 화면에 매이지 않는 공지·단체 발송 대상.
- **② 컨텍스트 진입 (각 화면의 전송 버튼)**: 호출한 화면이 **수신처·템플릿을 프리셋한 상태**로 이 모듈을 연다. 사용자는 대상·내용 확인 후 발송만 하면 된다. 프리셋 값은 진입 후에도 수정 가능.

| 호출 화면 | 진입점(버튼) | 프리셋 수신처 | 프리셋 템플릿 |
|---|---|---|---|
| 고지서 발행·출력 (`/bill`) | 카톡 고지서 발송 | 선택 세대(그룹/개별, 주·부번호) | 고지서(알림톡) |
| 수납관리·민원접수 (`/receipts`) | 고지서 문자 전송 | 선택 세대 세입자 | 고지서 |
| 수납관리·민원접수 (`/receipts`) | 담당 기사 문자 전송 | 해당 민원 담당 기사 | 민원/AS 안내 |
| 미납관리 (`/overdue`) | 독촉 문자 발송 | 선택/필터된 연체 세대 | 독촉 |
| 모바일 이사정산 (`/m/moving-settlement`) | 정산내역서 문자 전송 | 퇴실자·건물주 | 정산내역서 |
| 세입자 앱 공지 (관리자 발송) | 공지 알림톡 발송 | 건물/그룹 세대 | 공지(신규·중요·긴급) |

## 4. UI

### 4.0 상단 발송 유형 영역

- **기능**: 발송 채널 선택
- **규칙**:
  - 채널 선택: **문자(SMS) / 알림톡** 중 선택
  - 알림톡 선택 시 하단 템플릿 선택 활성화, 문자 선택 시 자유 본문 입력 활성화

### 4.1 수신처 선택 영역

- **기능**: 발송 대상을 조건·인물 기준으로 선택 (복수 조합 가능)
- **규칙**:
  - **세대 기준 필터**: 특정 건물 / 그룹 / 개별 세대 / 미납 세대(연체 필터) / 자동이체 세대
  - **인물 기준 필터**: 입주자 · 건물주 · 담당 기사 · 청소담당자 · 관리실 직원 (계정·직원 관리 페이지 `staff-management.md`의 인물·연락처 참조)
  - **입주자 번호 선택**: 주번호 / 부번호 각각 on·off (둘 다 선택 시 두 번호 모두 발송)
  - 조회 결과 목록을 전체 선택 체크박스 + 개별 체크박스로 최종 대상 확정
  - 선택 대상 수 실시간 카운트 표시 ("N명 / N건")
  - 컨텍스트 진입 시 이 영역은 프리셋 값으로 채워진 상태로 표시

### 4.2 내용 입력 영역

- **기능**: 발송 본문 작성 또는 템플릿 선택
- **규칙**:
  - **템플릿 선택**(알림톡): 고지서 / 독촉 / 정산내역서 / 민원·AS 안내 / 공지(신규·중요·긴급) / 자주 보내는 문자
  - **자유 본문**(문자): 텍스트 직접 입력, 치환 변수(세대명·금액·납기일 등) 삽입 지원
  - **공지 딥링크 삽입**: 공지 템플릿 발송 시 [공지확인하기] 버튼(세입자 웹 '우리건물 공지' 연결) 자동 포함
  - **자주 보내는 문자**: 반복 사용 문구를 템플릿으로 저장·재사용

### 4.3 발송 시점 영역

- **기능**: 즉시 또는 예약 발송
- **규칙**:
  - **즉시 발송**: 발송 버튼 클릭 즉시 전송
  - **예약 발송**: 달력 날짜 + 시간 설정 후 자동 발송, 등록 후 취소 가능 — 최대 예약 기간 제한 없음, 동시 예약 건수 사실상 무제한

### 4.4 발송 액션·결과

- **기능**: 발송 실행 및 결과 확인
- **규칙**:
  - `발송` 버튼 클릭 시 "선택한 N명/N건에 발송하시겠습니까?" 확인 팝업
  - 확인 시 NCP SMS/알림톡 API로 전송
  - 발송 완료 후 결과(성공 N건 / 실패 N건) 표시, 실패 건 재발송 버튼 제공
  - 발송 이력 저장 (발송자·일시·수신처·채널·내용·결과)

## 5. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기(독립 진입) | GNB 진입 | 수신처 미선택, 대상 0명 표시 |
| 프리셋(컨텍스트 진입) | 타 화면 버튼 호출 | 수신처·템플릿 프리셋 채워진 상태 |
| 대상 선택됨 | 수신처 확정 | 대상 수 카운트, 발송 버튼 활성화 |
| 확인 팝업 | 발송 버튼 클릭 | "N명/N건에 발송하시겠습니까?" |
| 발송 완료 | 발송 성공 | "발송되었습니다 (성공 N건 / 실패 N건)" 토스트 |
| 예약 등록 완료 | 예약 발송 설정 완료 | "예약이 등록되었습니다 (YYYY-MM-DD HH:MM)" 토스트 |
| 에러 | 조회·발송 실패 | "오류가 발생했습니다. 다시 시도해 주세요." + 재시도 버튼 |

## 6. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 수신처 목록(세대·인물) | 내부 DB (tenant 격리 RLS 적용) | 수신처 필터 적용 시 조회 |
| 문자·알림톡 발송 | NCP SMS/알림톡 API | 발송 버튼 클릭 후 확인 시 트리거 |
| 알림톡 템플릿 | NCP 알림톡 사전 등록 템플릿 | 템플릿 선택 시 참조 |
| 공지 딥링크 | 세입자 웹 '우리건물 공지' | 공지 템플릿 발송 시 삽입 |
| 발송 이력 | 내부 DB — 발송 이력 테이블 | 발송 완료 시 기록 |
