## 3. UI

### 3.1 수납 현황 조회 (`/m/receipts`)

- **기능**: 세대별 수납 현황 조회 (읽기 전용)
- **규칙**:
  - 건물 선택 → 세대별 수납 현황 목록 표시
  - 표시 컬럼: 호실명 / 입주자명 / 부과금액 / 수납금액 / 미납금액
  - 조작 불가, 조회만 가능 (PC와 동일한 데이터, 읽기 전용)

### 3.2 세입자 검색 (`/m/tenant-search`)

- **기능**: 이름 또는 전화번호로 세입자 조회
- **규칙**:
  - 검색 조건: 이름 / 전화번호 텍스트 입력
  - 검색 결과 표시: 건물명 / 호실명 / 입주자명 / 연락처 / 입주일
  - 검색 결과 탭 시 해당 입주자의 기본 정보 상세 표시
  - 입주자 정보 표시 항목: 주번호·부번호 포함

### 3.3 건물 기본 정보 조회 (`/m/building-info`)

- **기능**: 담당 건물의 기본 정보 조회
- **규칙**:
  - 건물 선택 드롭다운: 담당 건물 목록
  - 표시 항목:
    - 기본 정보 (건물명·주소·담당자)
    - 소방안전 업체
    - 전기안전관리 업체
    - 임대인 부번호
    - 기타 시설 정보
  - 읽기 전용, 수정 불가

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 건물·검색어 미입력 | 안내 문구 표시 |
| 결과 있음 | 조회 성공 | 목록 정상 표시 |
| 결과 없음 | 조건에 맞는 데이터 없음 | "검색 결과가 없습니다" 안내 |
| 에러 | 조회 실패 | "오류가 발생했습니다." + 재시도 버튼 |
