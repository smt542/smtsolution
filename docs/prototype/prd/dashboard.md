## 1. 목적

관리업체 직원이 로그인 직후 처음 마주하는 진입 화면. 오늘 처리해야 할 업무(입주 예정, AS 현황, 미납 등)를 요약해 보여주고, 각 기능 화면으로 이동하는 출발점 역할을 한다.

## 3. UI

### 3.0 입주예정일 팝업

- **기능**: 오늘이 입주예정일인 세대를 첫 진입 시 팝업으로 알림 (기능정의서 v2·A-3)
- **규칙**:
  - 입주자 상세에서 등록한 **입주예정일**이 오늘인 세대가 있으면 대시보드 진입 시 팝업 자동 노출
  - 팝업 내용: 해당 세대 목록 (건물명 / 호실명 / 입주자명 / 입주예정일)
  - 세대 행 클릭 시 해당 입주자 상세(`/tenants/:id`)로 이동
  - 하단 버튼 2개:
    - `닫기`: 팝업만 닫음, 당일 재진입 시 다시 노출
    - `오늘 그만보기`: 누르면 당일 자정까지 재노출 안 함 (익일 입주예정 세대 있으면 다시 노출)
  - 해당일 입주예정 세대가 없거나 '오늘 그만보기' 처리된 경우 팝업 미표시

### 3.1 업무 요약 영역

- **기능**: 오늘 기준 처리 대상 업무 요약 카드 표시
- **규칙**:
  - 요약 카드: 오늘 입주예정 세대 수 / 미처리 AS 건수 / 미납 세대 수 등 (표시 항목 확정 ❓)
  - 카드 클릭 시 해당 기능 화면으로 이동

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 로그인 후 진입 | 요약 영역 로드, 입주예정 세대 있으면 팝업 노출 |
| 팝업 없음 | 당일 입주예정 세대 없음 또는 '오늘 그만보기' 처리 | 팝업 미표시, 요약만 표시 |
| 로딩 | 요약 데이터 조회 중 | 요약 영역 로딩 인디케이터 |
| 에러 | 데이터 조회 실패 | "오류가 발생했습니다. 다시 시도해 주세요." + 재시도 버튼 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 입주예정 세대 | 내부 DB — 입주자 테이블 (입주예정일=오늘) | 화면 진입 시 자동 조회 |
| 업무 요약 데이터 | 내부 DB (AS·미납·수납 테이블, RLS 적용) | 화면 진입 시 자동 조회 |
