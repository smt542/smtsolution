## 3. UI

### 3.0 탭 네비게이션

- **기능**: 설정 카테고리 탭 전환
- **규칙**:
  - 탭 구성: **고지서 설정 / 계좌 설정 / 이사정산 설정 / 시스템 설정 / 장기수선비** 5개 탭
  - 탭 전환 시 해당 카테고리 설정 항목 표시
  - 탭별 하단에 `저장` 버튼 제공, 클릭 시 해당 탭 전체 저장

### 3.1 탭 ① — 고지서 설정

- **기능**: 고지서 출력 및 발송 관련 전역 설정
- **규칙**:
  - 설정 항목:
    - 고객 안내사항 (자유 텍스트, 고지서에 인쇄되는 안내문구)
    - 세대 표기 방식 기본값 (코드출력 / 이름출력 선택 — 고지서·출력물 전역 기본 적용, 발행 화면에서 건별 재지정 가능)
    - 연체료 합산 구분 (선택)
    - 고지서 출력 시 단전·단수 출력 여부 (Y / N)
    - 수도 단가 출력 여부 (Y / N)
    - 관리비 기간 출력 여부 (Y / N)
    - 고지서에 증감량 표시 여부 (Y / N)
    - AS현황 메인화면 표시 여부 (Y / N)
    - 단수 개월 수 선택 (숫자 입력 — 몇 개월 연체 시 단수 예고)
  - `저장` 버튼 클릭 시 전체 항목 일괄 저장

### 3.2 탭 ② — 계좌 설정

- **기능**: 관리비·이사정산 입금 계좌 등록 및 변경
- **규칙**:
  - 설정 항목:
    - 관리비 입금 계좌 (**최대 2개 등록 가능** — 각각 은행명 / 계좌번호 / 예금주, 계좌별로 고지서 **출력 / 미출력** 선택)
    - 이사정산 입금 계좌 (은행명 / 계좌번호 / 예금주)
  - 변경 후 `저장` 버튼 클릭 시 저장
  - 저장 즉시 고지서·이사정산 내역서에 변경된 계좌 자동 반영

### 3.3 탭 ③ — 이사정산 설정

- **기능**: 이사정산 처리 방식 관련 설정
- **규칙**:
  - 설정 항목:
    - 이사정산 시 수도 단가 반영 여부 (반영 / 안함 선택)
    - 이사정산 시 전기 단가 반영 여부 (반영 / 안함 선택)
    - 공실 처리 시 관리비 수납 처리 방식 (수동 / 자동 선택)
    - 이사정산 체크 항목 등록 및 변경 (항목명 자유 등록, 추가·삭제 가능)
  - `저장` 버튼 클릭 시 전체 항목 일괄 저장

### 3.4 탭 ④ — 시스템 설정

- **기능**: 시스템 전반에서 사용되는 기준 데이터 등록·관리
- **규칙**:
  - 관리 항목 (각각 목록 조회 + 추가·수정·삭제):
    - 룸타입 등록·관리
    - 정화조 업체 등록·관리
    - 협력업체 등록·관리
    - A/S 구분 명칭 등록·관리
    - 청소팀 등록·관리
    - 자주 보내는 문자 내용 등록·관리
  > 직원 계정·담당자(관리·검침·청소) 등록·관리는 별도 **계정·직원 관리 페이지(`staff-management.md`)**로 이관
  - 항목별 `+ 추가` 버튼 + 행별 수정·삭제 버튼 제공
  - 변경 즉시 각 화면 드롭다운·목록에 반영

### 3.5 탭 ⑤ — 장기수선비

- **기능**: 건물별 장기수선 공사 이력 및 영수증·사진 관리
- **규칙**:
  - 건물 선택 드롭다운 → 해당 건물의 장기수선비 이력 목록 표시
  - 이력 1건당 입력 항목: 공사명 / 공사일 (달력 선택) / 금액 / 영수증 파일 업로드 / 사진 업로드
  - 파일 업로드: 이미지·PDF, 파일 수 제한 없음
  - `+ 이력 추가` 버튼으로 행 추가, 행별 삭제 버튼 제공
  - `저장` 버튼 클릭 시 전체 이력 일괄 저장

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 화면 진입 | 첫 번째 탭(고지서 설정) 자동 선택, 기존 설정값 로드 |
| 로딩 | 탭 전환 시 데이터 조회 중 | 해당 탭 영역 로딩 인디케이터 |
| 저장 완료 | `저장` 버튼 클릭 후 성공 | "저장되었습니다" 토스트 메시지 |
| 저장 실패 | 필수 항목 미입력 | 해당 필드 강조 + 안내 메시지 |
| 에러 | 데이터 조회·저장 실패 | "오류가 발생했습니다. 다시 시도해 주세요." + 재시도 버튼 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 전체 설정값 | 내부 DB — 설정 테이블 (tenant 격리 RLS 적용) | 탭 진입 시 자동 조회 |
| 계좌 변경 | 내부 DB — 설정 테이블 | 저장 시 고지서·이사정산 내역서에 즉시 반영 |
| 시스템 설정 항목 | 내부 DB — 기준 데이터 테이블 | 저장 시 전체 화면 드롭다운·목록에 즉시 반영 |
| 장기수선비 파일 | 파일 스토리지 (S3 or 동등) | 업로드 시 즉시 저장 |
