## 3. UI

### 3.0 빈 상태 (건물 미선택)

- **규칙**: 상단에서 건물을 아직 선택하지 않았으면 입주민 영역은 안내만 표시.
  - 청록 아이콘 칩 + 제목 `건물을 선택해 주세요`
  - 부제 `위 전체 건물 목록에서 건물을 선택하면 해당 건물의 입주민이 여기에 표시돼요`

### 3.1 상단 액션 영역 (건물 선택 시)

- **규칙**:
  - 헤더: `{건물명} 호수·입주민` + 인원 배지(`N명`) + `⤓ 엑셀 다운` + `＋ 호수·입주민 등록`
  - `＋ 호수·입주민 등록` → `/buildings/:id/tenants/new` (입주자 등록 화면)
  - `⤓ 엑셀 다운` — 세대 목록 엑셀 다운로드(엔드포인트 준비 중, 후속 배선)

### 3.2 입주민 표 (33컬럼, 가로 스크롤)

- **기능**: 선택 건물 내 전체 세대(호실)를 행 단위로 표시. 행 클릭 시 해당 세대의 입주민 관리카드 모달을 연다.
- **표시 컬럼(33, 순서 고정)**:
  호실 / 입주자명 / 입금자명 / 룸 / 인원 / 전화번호 / 차량번호 / 입주일 / 관리비 / 이사청소 / 인상액 / 평형 / 수도 / 전기 / 공용 전기 / 가스 / 부과금 여부 / 고지서 출력 여부 / 고지서 이름 출력 유형 / 퇴실일자 / 입주예정일 / 연체료 부과 여부 / 단수 출력 여부 / 이체 방식 / 문자 수신 / 적요 / 인증 / 홈피 비번 / 발송 / 한전고객번호 / 한전계기번호 / 부과일 / 등록일
- **규칙**:
  - 현재 배선(`list_tenants` 기준): **호실·입주자명·룸·인원·전화번호·입주일**. 나머지 컬럼은 빈 셀로 노출(가용 데이터 우선 결정).
    - 미배선 필드 대부분은 `occupancies`/`unit_meters`/`unit_accounts`에 이미 존재 → RPC 확장 시 `tenantColumns.ts`의 `get`만 채우면 배선 완료.
  - 공실 세대는 입주자명 대신 `공실` 표시
  - 행 **클릭** → 선택 건물과 해당 `unitId`의 **입주민 관리카드 모달** 표시
  - 행 클릭은 `입주자카드 및 부과내역 출력` 모달을 열지 않음. 출력 모달은 화면 상단 출력 버튼으로만 진입
  - 키보드 포커스 후 **Enter/Space**도 클릭과 동일하게 동작
  - 기본 정렬: 호실명 오름차순
  - 컬럼이 넓어 표는 가로 스크롤(헤더 고정)
