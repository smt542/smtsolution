## 3. UI

### 3.0 상단 액션 영역

- **기능**: 입주자 신규 등록 + 해당 건물 출력물(입주자카드·관리비부과내역서) 출력 버튼 제공
- **규칙**:
  - `입주자 등록` 버튼 클릭 → `/buildings/:id/tenants/new` (입주자 등록 화면)
  - `입주자카드 출력` 버튼: 해당 건물 전체 세대의 입주자카드 출력 (등록된 세대 1건 이상일 때 활성화, 빈 상태에서는 비활성화)
  - `관리비부과내역서 출력` 버튼: 해당 건물 관리비부과내역서 출력 (등록된 세대 1건 이상일 때 활성화, 빈 상태에서는 비활성화)
  - 출력물에는 회사명 워터마크 적용 (설정 I-6 정책 연동)

### 3.1 세대 목록 테이블

- **기능**: 건물 내 전체 세대(호실)를 행 단위로 표시. 행 더블클릭 시 입주자 상세 화면으로 이동
- **규칙**:
  - 표시 컬럼: 호실명 / 입주자명 / 룸타입 / 인원 / 입주일 / 공실여부 / 연체여부
  - 행 **더블클릭** → `/buildings/:id/tenants/:tenantId` (입주자 상세·등록 화면)
  - 공실 세대는 입주자명 대신 "공실" 표시
  - 기본 정렬: 호실명 오름차순

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 빈 상태 | 등록된 세대 없음 | "등록된 세대가 없습니다" 안내 + `입주자 등록` 버튼 |
| 로딩 | 목록 조회 중 | 테이블 영역 로딩 인디케이터 |
| 성공 | 세대 1개 이상 존재 | 목록 정상 표시 |
| 에러 | 조회 실패 | "데이터를 불러오지 못했습니다. 다시 시도해 주세요." + 재시도 버튼 |
