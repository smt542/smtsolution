## 3. UI

### 3.-1 로그인 화면 (`/m/login`)

- **기능**: 현장관리자 인증
- **규칙**:
  - 로그인 방식: ❓ (기능정의서 미기재 — 미결정)
  - 로그인 완료 후 해당 계정의 현장직원 권한 확인
  - 권한 확인 성공 시 `/m` 홈 화면으로 자동 이동
  - 미등록·권한 없는 계정: ❓ (안내 문구 미정)
  - 로그인 상태 유지: 앱 재진입 시 자동 로그인

### 3.0 상단 헤더

- **기능**: 로그인한 현장관리자 이름·소속 표시 + 로그아웃 버튼
- **규칙**:
  - 표시: "[이름] 님 / [소속 관리업체명]"
  - 로그아웃 버튼 클릭 시 로그인 화면으로 이동

### 3.1 업무 현황 요약 카드

- **기능**: 당일 주요 업무 현황 숫자 요약 표시
- **규칙**:
  - 표시 항목: 당일 AS 미결 건수 / 당일 AS 완결 건수 / 담당 건물 수
  - 각 항목 탭 시 해당 화면으로 이동

### 3.2 주요 업무 바로가기 카드

- **기능**: 주요 기능으로 빠르게 진입하는 카드 목록
- **규칙**:
  - 바로가기 항목:
    - 지침 등록 → `/m/utility-charge`
    - AS 접수·처리 → `/m/as`
    - 수납 조회 → `/m/receipts`
    - 세입자 검색 → `/m/tenant-search`
    - 이사정산 → `/m/moving-settlement`
  - 카드 탭 시 해당 화면으로 이동
