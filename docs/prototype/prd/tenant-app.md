# 세입자 앱 정책서 (UI중심)

> **이 문서는 "이 화면이 어떤 규칙으로 동작하는가"를 정의합니다.**
> 화면을 위→아래 **UI 블록 순서**로 읽습니다. 각 블록은 **"무엇 + 동작 규칙"**만 적고, 디자인(색·여백·컴포넌트 모양)은 Figma에 둡니다. 미정은 줄 안에 `❓`로 표시하고 맨 아래 "미정" 섹션에 한 번 더 모읍니다.

| | |
|---|---|
| **화면** | 세입자 앱 (카카오 기반) · `/tenant-app` |
| **진입** | 카카오 로그인 → 메인 홈 자동 진입 |
| **Figma** | 미연결 (PRD 작성 후 와이어프레임 → Figma 순서로 진행) |
| **상태/작성자** | `반영중` · 최근 2026-09-07 (PR #150) |

> **앱 구조**: 카카오 로그인 → **세대 매칭 확인("이 세대가 맞나요?")** → 홈 화면 → 각 기능 페이지 (관리비 확인 / 공지사항 / 퇴실 신청 / 고지서 신청 / 내 정보)
> **실 라우트**: `/resident/*` (login·verify·home·bill·notice·me 등). 문서의 일부 구 라우트(`/tenant-app/*`) 표기는 순차 갱신 대상.

---

## 1. 목적

세입자가 카카오 계정으로 로그인하여 본인 세대의 관리비 확인, 공지사항 조회, 퇴실 신청, 고지서(카카오/스마트) 신청을 처리하는 모바일 웹 앱.

---

## 2. 권한

| 사용자 | 접근 | 비고 |
|---|---|---|
| 세입자 (카카오 로그인) | O | 본인 세대 데이터만 조회 가능 |
| 미로그인 | X | 카카오 로그인 필수 |

## 3. UI

### 3.0 카카오 로그인 (`/resident/login`)

- **기능**: 카카오 간편로그인으로 세입자 인증 + 본인 세대 자동 매칭
- **규칙**:
  - `카카오톡으로 시작` 버튼 탭 → 카카오 OAuth. 수집 동의항목(전부 **필수 동의**): 프로필(닉네임)·카카오계정(전화번호)·**이름(실명)** — `scope=profile_nickname,phone_number,name`.
  - 로그인 후 **카카오 전화번호와 세대(occupancy) 연락처를 정규화 대조**해 본인 세대를 자동으로 찾는다(RPC `resident_automatch`).
  - 매칭 1건 이상 → 세대 매칭 확인(3.0.1) / 0건 → "등록된 세대 정보가 없습니다. 관리사무소에 문의해 주세요." 안내.
  - 하단에 이용약관·개인정보 처리방침 링크(로그인 전에도 공개 열람 가능).
  - 로그인 상태 유지(세션 쿠키).

### 3.0.1 세대 매칭 확인 — "이 세대가 맞나요?" (`/resident/verify`)

- **기능**: 전화번호로 찾은 세대가 본인 세대인지 확인하고 연결(link).
- **규칙**:
  - 카드 구성(클로드 디자인 정본): 아바타(이름 첫 글자) + **이름·전화번호** / 구분선 / **건물 · 호수 · 입주일 · 관리주체(관리사무소 org명)** 표 / 안내문("세대 정보는 관리사무소에 등록된 자료를 기준으로 확인해요").
  - 확인 전 단계라 **이름·전화번호는 마스킹**한다(예: `이O재` · `010-****-6933`). 이름은 로그인한 **카카오 본인 이름**(없으면 "사용자"), 나머지(전화·건물·호수·입주일·관리주체)는 매칭된 세대 자료.
  - `네, 맞아요` → 세대 연결(res_claims linked) → 알림 설정/홈. `제 세대가 아니에요` → 건물·호수 직접 검색 → 관리사무소 확인 요청(신청 → 승인 대기).

### 3.1 홈 화면 (`/tenant-app/home`)

- **기능**: 로그인 후 메인 진입 화면, 전체 기능 메뉴 버튼 제공
- **규칙**:
  - 상단 헤더: 좌측 = **건물명 호수**(제목) + `카카오 본인 이름`(없으면 "사용자") · 관리주체명(서브라인) — 본인 화면이라 실명 그대로(매칭 확인 카드의 마스킹과 다름). 우측 = **알림 벨**(미확인 공지 있으면 dot) → 탭 시 공지 목록(`/resident/notice`). 로그아웃은 내 정보(3.6)로 이동(2026-09-07 PR #150).
  - 홈 허브 카드(클로드 디자인 정본 정합):
    - **공지 카드**(최신 공지, amber) — 탭 시 홈 내 모달로 본문 표시(`resident_notice_detail`).
    - **관리비 카드** — 상태칩(미납 red / 완납 blue / 부분 amber) + **총 청구액(당월 부과액 + 연체료)** + 납부기한 + 당월 부과액·연체료 내역(연체료 있을 때) + `상세 내역 보기` → `/resident/bill`.
    - **관리비 추이** — 최근 3개월 세로 막대(당월 강조) + 최근 3개월 평균 대비 증감 문구 + 평균·당월 요약.
    - **퇴실 신청** — 3.4 참조.
  - 고지서 신청(3.5)은 별도 화면으로 접근.

### 3.2 관리비 확인 (`/tenant-app/bill`)

- **기능**: 본인 세대의 월별 관리비 항목별 부과 금액 및 수납 여부 확인
- **규칙**:
  - 월 선택 드롭다운: 조회할 월 선택 (기본값: 당월)
  - 표시 항목:
    - 관리비 항목별 부과 금액 목록
    - 항목별 수납 여부 (납부 완료 / 미납)
    - 합계 부과 금액 / 합계 수납 금액 / 미납 금액
  - 읽기 전용, 수정 불가
  - 자동이체 세대: "자동이체 세대입니다" 안내 표시
  - **관리비 상세보기 (로그인 없이 열람)**: 관리비 상세 내역을 카카오 로그인 없이 링크만으로 바로 열람 가능 (고령자·접근성 배려)
    - 링크 유효기간: **1년**
    - 상세 화면에 관리비 입금계좌 복사 버튼, 계좌번호+금액 함께 복사 버튼 제공

### 3.3 공지사항 확인 (`/tenant-app/notice`)

- **기능**: 본인 거주 건물의 공지사항 목록 조회
- **규칙**:
  - 표시: 건물별 공지사항 목록 (제목 / 등록일)
  - 공지 탭 시 상세 내용 표시
  - 읽기 전용
  - **공지 알림톡 딥링크**: 관리업체가 공지사항 알림톡 발송 시 [공지확인하기] 버튼 포함 → 탭 시 세입자 웹의 '우리건물 공지'로 바로 연결
    - 공지 템플릿 구분: **신규 / 중요 / 긴급** 3종로 알림톡 템플릿 분리

### 3.4 퇴실 신청 (`/tenant-app/move-out`)

- **기능**: 앱에서 퇴실 의사를 관리업체에 신청
- **규칙**:
  - 입력 항목:
    - 희망 퇴실일 (달력 선택, 필수)
    - 퇴실 사유 (자유 텍스트, 선택)
  - `신청` 버튼 탭 시 관리업체에 퇴실 신청 알림 발송
  - 신청 완료 후 "퇴실 신청이 접수되었습니다. 관리사무소에서 확인 후 연락드립니다." 안내 표시
  - 중복 신청 방지: 이미 신청 중인 경우 신청 내역 표시 + 재신청 불가

### 3.5 고지서 신청 (`/tenant-app/bill-apply`)

- **기능**: 세입자가 관리비 고지서 수령 방식을 신청 (기존 찬반 투표 기능 대체)
- **규칙**:
  - 고지서 수령 방식 선택: **카카오고지서 / 스마트고지서** 중 선택 신청
  - `신청` 버튼 탭 시 관리업체에 고지서 수령 방식 신청 전달
  - 신청 완료 후 현재 설정된 수령 방식 표시, 재신청(방식 변경) 가능
  - 로그인 필요 기능 (카카오 로그인 후 이용)

### 3.6 내 정보 (`/resident/me`)

- **기능**: 본인 프로필·알림 설정·약관/처리방침·로그아웃·회원 탈퇴.
- **규칙**:
  - 이름 = 로그인한 **카카오 본인 이름**(없으면 "사용자"), 전화·건물·호수 등 세대 정보 표시(본인 화면이라 실명 그대로).
  - 알림 수신(카카오 알림톡/문자) 토글 저장.
  - 이용약관·개인정보 처리방침 링크(운영사 = 에스엠티솔루션㈜ 기준).
  - 로그아웃(확인 후 세션 종료) · 회원 탈퇴(res_claims·카카오 식별 삭제, auth 계정은 유지).

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 미로그인 | 앱 최초 진입 | 카카오 로그인 화면 표시 |
| 세대 매칭 실패 | 등록되지 않은 카카오 계정 | "등록된 세대 정보가 없습니다" 안내 |
| 로그인 완료 | 카카오 로그인 + 세대 매칭 성공 | 홈 화면 자동 진입 |
| 로딩 | 각 화면 데이터 조회 중 | 로딩 인디케이터 |
| 빈 상태 | 공지사항 없음 | "등록된 내용이 없습니다" 안내 |
| 에러 | 조회·저장 실패 | "오류가 발생했습니다." + 재시도 버튼 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 |
|---|---|---|
| 카카오 로그인 | 카카오 OAuth API (scope: profile_nickname·phone_number·name 전부 필수) | 로그인 버튼 탭 시 |
| 세대 매칭 | 내부 DB — occupancies (카카오 전화번호 ↔ 세대 연락처 정규화 대조) · RPC `resident_automatch` | 로그인 완료 시 자동 조회 |
| 관리비 데이터 | 내부 DB — 부과·수납 테이블 (RLS 적용) | 관리비 확인 화면 진입 시 |
| 공지사항 | 내부 DB — 공지사항 테이블 | 공지사항 화면 진입 시 |
| 퇴실 신청 | 내부 DB — 퇴실 신청 테이블 + 관리업체 알림 발송 | 신청 버튼 탭 시 |
| 고지서 신청 | 내부 DB — 고지서 수령방식 설정 테이블 | 신청 버튼 탭 시 |
| 관리비 상세 링크 | 내부 DB — 부과·수납 테이블 (로그인 없이 접근, 유효기간 1년 토큰) | 공유 링크 접근 시 |
| 공지 알림톡 딥링크 | NCP 알림톡 API (신규·중요·긴급 템플릿) | 관리업체 공지 발송 시 |
