## 3. UI

### 3.0 상단 액션 영역

- **기능**: 건물 선택 + 관리비 항목 관리 버튼 + 부과 확정 버튼 제공
- **규칙**:
  - 건물 선택 드롭다운: 관리 중인 건물 목록 표시, 선택 시 해당 건물의 전체 세대 부과 설정 목록 로드
  - 선택한 건물에 체크박스 확인 표시가 설정된 경우 → 건물 선택 시 "이 건물 셋팅 시 확인이 필요합니다" 팝업 표시 후 진행
  - `관리비 항목 관리` 버튼: 항목 등록·수정·삭제 모달 오픈
  - `부과 확정` 버튼: 현재 세대별 금액 설정을 당월 부과로 확정
    - 클릭 시 "당월 관리비를 부과 확정하시겠습니까?" 확인 팝업 → 확인 시 처리

### 3.1 관리비 항목 관리 모달

- **기능**: 건물별 관리비 항목(관리비·승강기유지비·정화조 등)을 자유롭게 등록·수정·삭제
- **규칙**:
  - 항목 1건당 입력값: 항목명 (텍스트, 필수) / 이월 여부 (Y / N)
  - 이월 Y: 다음 달 동일 금액 자동 이월
  - 이월 N: 매월 초기화 (예: 수리비)
  - `+ 항목 추가` 버튼으로 행 추가, 행별 삭제 버튼 제공
  - 저장 버튼 클릭 시 모달 닫힘, 세대별 부과 설정 테이블에 항목 반영

### 3.2 세대별 부과 설정 테이블

- **기능**: 건물 내 전체 세대의 관리비 항목별 부과 설정 및 금액 입력
- **규칙**:
  - 고정 컬럼: 호실명 / 룸타입 / 입주일 / 합계 관리비
    - 합계 관리비: 해당 세대의 전체 항목 금액 합산, 가장 앞에 표시 (관리비 문의 전화 시 빠른 응대용)
  - 가변 컬럼: 등록된 관리비 항목별 각각 1컬럼 (부과 Y/N + 금액 입력)
  - 항목별 부과 Y/N 설정: 세대별로 개별 설정 가능
  - 금액 입력: 항목별 금액 직접 입력, 이월 Y 항목은 전월 금액 자동 표시 (수정 가능)
  - 중간입주자 (당월 입주 세대): 입주일 기준 일할 계산 자동 적용
  - 최근 한 달 전후 입주자 변경 세대 색상 강조 표시
  - 부과 참조사항 입력란: 세대별 해당월 메모 입력 가능
  - 호실별 공지사항 입력란: 세대별 공지 입력 가능

### 3.3 신규 입주자 당월 부과 팝업

- **기능**: 당월 부과 셋팅 완료 후 신규 입주자 등록 시 해당월 관리비 부과 여부 확인
- **규칙**:
  - 당월 부과 확정 이후 신규 입주자가 등록되면 자동으로 팝업 표시
  - 팝업 내용: "이번 달 관리비를 부과하시겠습니까?"
  - 확인: 해당 세대 당월 관리비 부과 적용
  - 취소: 부과 미적용 (다음달부터 적용)

### 3.4 건물별 셋팅 확인 체크박스

- **기능**: 특정 건물에 셋팅 시 반드시 확인이 필요한 경우 체크박스로 표시
- **규칙**:
  - 건물 상세 설정에서 해당 건물의 체크박스 활성화 가능
  - 체크박스 활성화된 건물 선택 시 "이 건물 셋팅 시 확인이 필요합니다" 팝업 → 확인 후 진행

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 건물 미선택 | "건물을 선택해 주세요" 안내, 테이블 비표시 |
| 로딩 | 건물 선택 후 세대 목록 조회 중 | 테이블 영역 로딩 인디케이터 |
| 입력 대기 | 세대 목록 로드 완료 | 이월 항목 전월 금액 자동 표시, 입력 대기 |
| 부과 확정 완료 | `부과 확정` 버튼 클릭 후 성공 | "당월 관리비 부과가 확정되었습니다" 토스트 메시지 |
| 빈 상태 | 해당 건물 세대 없음 | "등록된 세대가 없습니다" 안내 |
| 에러 | 데이터 조회·저장 실패 | "오류가 발생했습니다. 다시 시도해 주세요." + 재시도 버튼 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 건물 목록 | 내부 DB (tenant 격리 RLS 적용) | 화면 진입 시 자동 조회 |

| 신규 입주자 감지 | 내부 DB — 입주자 테이블 | 부과 확정 이후 신규 입주자 등록 시 트리거 |
