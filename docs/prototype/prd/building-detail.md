## 3. UI

### 3.0 상단 헤더 영역

- **기능**: 현재 모드(등록/수정) 표시 + 저장 버튼 + 목록으로 돌아가기 버튼
- **규칙**:
  - 등록 모드(`/buildings/new`): 헤더 타이틀 "건물 등록"
  - 수정 모드(`/buildings/:id`): 헤더 타이틀 "건물 상세 — [건물명]"
  - `저장` 버튼: 전체 섹션 통합 저장 (섹션별 개별 저장 없음)
  - `목록으로` 버튼: 변경 사항이 있을 경우 "저장하지 않고 나가시겠습니까?" 확인 팝업 → 확인 시 `/buildings` 이동

### 3.1 섹션 1 — 기본 정보

- **기능**: 건물의 핵심 식별 정보 및 담당자 지정
- **규칙**:
  - 입력 항목:
    - 건물명 (텍스트 입력, 필수)
    - 주소 (텍스트 입력, 필수)
    - 관리담당자 지정 (직원 계정 목록 드롭다운 선택)
    - 검침담당자 지정 (직원 계정 목록 드롭다운 선택)
    - 청소담당자 지정 (직원 계정 목록 드롭다운 선택)
  - 건물명·주소 미입력 시 저장 불가, 필수 입력 안내 표시

### 3.2 섹션 2 — 시설 정보

- **기능**: 건물 내 시설 현황을 체크박스로 등록, 각 시설별 상세 메모 입력
- **규칙**:
  - 시설 항목 (각각 체크박스 + 텍스트 메모 입력란):
    - CCTV
    - 승강기
    - 청소담당
    - 검침담당
    - 관리담당
    - 정화조
    - 인터넷
    - 전기안전관리
    - 소방안전관리
  - 체크박스 미체크 시 해당 시설 메모 입력란 비활성화
  - 체크박스 체크 시 메모 입력란 활성화 (입력 선택사항, 필수 아님)

### 3.3 섹션 3 — 고객번호

- **기능**: 건물별 수도·전기·가스 고객번호 및 검침 관련 설정 등록
- **규칙**:
  - 고객번호 유형: 수도 / 공용전기 / 전기 / 가스
  - 각 유형별 **복수 등록 가능** (예: 1층 상가용·2층 이상 주택용 수도 고객번호 각각 등록)
  - 고객번호 1건당 입력 항목:
    - 고객번호 (텍스트, 필수)
    - 유형 선택 (수도·공용전기·전기·가스)
    - 검침일 (숫자 입력 — 매월 N일)
    - 부과기간 기준 (전월 / 당월 선택)
    - 고지서 출력 여부 (Y / N 선택)
    - 명의자 (텍스트 입력)
  - `+ 고객번호 추가` 버튼으로 행 추가, 행별 삭제 버튼 제공

### 3.4 섹션 4 — 협력업체

- **기능**: 건물과 계약된 협력업체 정보 및 계약서 사진 등록
- **규칙**:
  - 협력업체 유형: 승강기 / 소방안전 / 전기안전 / 정화조 / 기타
  - 업체 1건당 입력 항목:
    - 업체명 (텍스트, 필수)
    - 유형 선택
    - 계약서 사진 업로드 (이미지·PDF, 파일 수 제한 없음)
  - `+ 협력업체 추가` 버튼으로 행 추가, 행별 삭제 버튼 제공
  - 업로드된 파일은 썸네일 또는 파일명으로 목록 표시, 클릭 시 원본 보기

### 3.5 섹션 5 — 참고사항

- **기능**: 건물에 관한 자유 메모 기록
- **규칙**:
  - 자유 텍스트 입력란 1개 (멀티라인)
  - 글자 수 제한: 최대 1,000자, 잔여 글자 수 실시간 표시
  - 저장 시 다른 섹션과 함께 통합 저장

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 등록 모드 | `/buildings/new` 진입 | 모든 입력 필드 빈 값으로 초기화 |
| 수정 모드 | `/buildings/:id` 진입 | 기존 저장 데이터 불러와 각 필드에 표시 |
| 로딩 | 수정 모드 데이터 조회 중 | 각 섹션 로딩 인디케이터 표시 |
| 저장 성공 | 저장 버튼 클릭 후 성공 | "저장되었습니다" 토스트 메시지 → 수정 모드(`/buildings/:id`)로 전환 또는 유지 |
| 저장 실패 | 필수 항목 미입력 | 해당 필드 강조 + 안내 메시지 표시, 페이지 이동 없음 |
| 에러 | 데이터 조회·저장 실패 | "오류가 발생했습니다. 다시 시도해 주세요." 메시지 + 재시도 버튼 |
| 이탈 확인 | 변경사항 있는 상태에서 목록으로 이동 시 | "저장하지 않고 나가시겠습니까?" 확인 팝업 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 건물 상세 데이터 | 내부 DB (tenant 격리 RLS 적용) | 수정 모드 진입 시 자동 조회 |
| 담당자 목록 | 내부 DB — 직원 테이블 | 담당자 드롭다운 오픈 시 조회 |
| 협력업체 파일 | 파일 스토리지 (S3 or 동등) | 업로드 시 즉시 저장, 삭제 시 즉시 제거 |
| 저장 | 내부 DB | 저장 버튼 클릭 시 전체 섹션 일괄 저장 |
