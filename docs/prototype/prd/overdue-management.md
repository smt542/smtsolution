## 3. UI

### 3.0 상단 액션 영역

- **기능**: 건물 선택 + 채권 관리 필터 + 주요 액션 버튼 제공
- **규칙**:
  - 건물 선택 드롭다운: 선택 시 해당 건물 미납 세대 일괄 표시
  - 채권 관리 필터 버튼: 연체 3개월 이상 + 10만원 이상 세대만 필터링 (고정값, 변경 불가)
  - `미납대장 출력` 버튼: 현재 조회 결과 기준 미납대장 출력
    - 파일명: `[건물명]_미납대장_YYYYMM`
  - `독촉 문자 발송` 버튼: **공용 발송 모듈(`messaging.md`) 호출** — 수신처=선택/필터된 연체 세대, 템플릿=독촉 프리셋 상태로 발송 화면 오픈

### 3.1 미납 세대 테이블

- **기능**: 건물 내 미납 세대 목록 표시 및 발송 대상 선택
- **규칙**:
  - 표시 컬럼: 호실명 / 입주자명 / 연락처 / 연체 개월수 / 미납금액 / 최근 납부일
  - 전체 선택 체크박스 + 개별 세대 체크박스로 독촉 문자 발송 대상 선택
  - 채권 관리 필터 적용 시: 연체 3개월 이상 AND 미납금액 10만원 이상 세대만 표시
  - 단전·단수 예고 자동 적용 규칙:
    - 연체 2개월 이상 세대 → 3개월째 고지서 발송 시 "단전·단수 예고" 문구 자동 인쇄 (별도 설정 없음)

### 3.2 독촉 문자 발송

- **기능**: 선택된 미납 세대에 독촉 문자 발송 (공용 발송 모듈 호출)
- **규칙**:
  - 발송 방식 1: 채권 관리 필터 적용 → 필터된 세대 전체 선택 → 일괄 발송
  - 발송 방식 2: 개별 세대 체크박스 선택 → 발송
  - `독촉 문자 발송` 버튼 클릭 시 **공용 발송 모듈(`messaging.md`)을 수신처=선택 세대·템플릿=독촉 프리셋으로 호출**
  - 발송·확인·결과 표시(성공 N건 / 실패 N건)는 공용 모듈 규칙을 따름

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 건물 미선택 | "건물을 선택해 주세요" 안내, 테이블 비표시 |
| 로딩 | 건물 선택 후 조회 중 | 테이블 영역 로딩 인디케이터 |
| 전체 목록 | 건물 선택 후 | 해당 건물 미납 세대 전체 표시 |
| 채권 필터 적용 | 채권 관리 필터 버튼 클릭 | 연체 3개월↑ AND 10만원↑ 세대만 표시 |
| 빈 상태 | 미납 세대 없음 | "미납 세대가 없습니다" 안내 |
| 필터 결과 없음 | 채권 필터 조건 해당 세대 없음 | "채권 관리 대상 세대가 없습니다" 안내 |
| 문자 발송 완료 | 독촉 문자 발송 성공 | "독촉 문자가 발송되었습니다 (성공 N건 / 실패 N건)" 토스트 |
| 에러 | 조회·발송 실패 | "오류가 발생했습니다. 다시 시도해 주세요." + 재시도 버튼 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 미납 세대 목록 | 내부 DB (tenant 격리 RLS 적용) | 건물 선택 시 자동 조회 |
| 미납대장 출력 | 서버사이드 생성 | `미납대장 출력` 버튼 클릭 시 트리거 |
| 독촉 문자 발송 | 공용 발송 모듈(`messaging.md`) → NCP SMS API | `독촉 문자 발송` 버튼 클릭 시 프리셋 전달·호출 |
| 단전·단수 예고 인쇄 | 고지서 발행 로직 | 연체 2개월↑ 세대의 3개월째 고지서 발행 시 자동 적용 |
