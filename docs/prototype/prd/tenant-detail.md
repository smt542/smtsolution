# 입주자 상세·등록 정책서 (UI중심)

> **이 문서는 "이 화면이 어떤 규칙으로 동작하는가"를 정의합니다.**
> 화면을 위→아래 **UI 블록 순서**로 읽습니다. 각 블록은 **"무엇 + 동작 규칙"**만 적고, 디자인(색·여백·컴포넌트 모양)은 Figma에 둡니다. 미정은 줄 안에 `❓`로 표시하고 맨 아래 "미정" 섹션에 한 번 더 모읍니다.

| | |
|---|---|
| **화면** | 입주자 상세·등록 · `/buildings/:id/tenants/new` (등록) · `/buildings/:id/tenants/:tenantId` (수정) |
| **진입** | GNB > 건물·입주자 관리 > 입주자 목록 `입주자 등록` 버튼 또는 행 더블클릭 |
| **Figma** | 미연결 (PRD 작성 후 와이어프레임 → Figma 순서로 진행) |
| **상태/작성자** | `draft` · 2026-07-03 |

## 1. 목적

세대(호실)별 입주자의 기본 정보·부과 설정·계량기·임대차·시설 정보를 등록하거나 수정하는 화면. 신규 등록과 기존 수정을 하나의 화면에서 모드 분기로 처리한다.

## 3. UI

### 3.0 상단 헤더 영역

- **기능**: 현재 모드 표시 + 통합 저장 버튼 + 목록으로 돌아가기 버튼
- **규칙**:
  - 등록 모드: 헤더 타이틀 "입주자 등록"
  - 수정 모드: 헤더 타이틀 "[건물명] — [호실명] · [입주자명]"
  - `저장` 버튼: 전체 섹션 통합 저장
  - `목록으로` 버튼: 변경 사항 있을 경우 "저장하지 않고 나가시겠습니까?" 확인 팝업 → 확인 시 입주자 목록으로 이동

### 3.1 섹션 1 — 기본 정보

- **기능**: 입주자의 핵심 식별 정보 등록
- **규칙**:
  - 입력 항목:
    - 호실명 (텍스트, 필수)
    - 이름 (텍스트, 필수)
    - 입금자명 (텍스트, 필수 — 이름과 다를 수 있음)
    - 룸타입 (사전 등록된 목록 드롭다운 선택, 필수)
    - 인원 (숫자 입력)
    - 연락처 1 (전화번호, 필수)
    - 연락처 2 (전화번호, 선택)
    - 연락처 3 (전화번호, 선택)
    - 차량번호 (텍스트, 선택)
    - 입주일 (달력 선택, 필수) — 미래 날짜(입주예정일) 입력 가능
  - 호실명·이름·입금자명·룸타입·연락처 1·입주일 미입력 시 저장 불가
  - **입주예정일 알림**: 입주일에 미래 날짜(입주예정일)를 등록하면, 해당 입주일 도래 시 **대시보드(첫 진입 화면) 팝업**으로 알림 발생 (신규 입주 대상 세대 상기) — 팝업 노출 규칙은 `dashboard.md` 참조

### 3.2 섹션 2 — 부과·출력 설정

- **기능**: 세대별 관리비 부과·고지서 출력 관련 세부 설정
- **규칙**:
  - 설정 항목:
    - 부과 설정 (Y / N 선택)
    - 출력 설정 (Y / N 선택)
    - 공실 처리 여부 (Y / N 선택) — Y 선택 시 목록에서 "공실"로 표시
    - 퇴실일자 (달력 선택, 선택사항)
    - 연체료 부과 여부 (Y / N 선택)
    - 단수 출력 여부 (Y / N 선택)
    - 적요 (자유 텍스트, 멀티라인)
    - 이사정산 시 적요 (자유 텍스트, 멀티라인 — 이사정산 화면과 연동)

### 3.3 섹션 3 — 계량기·계좌

- **기능**: 세대별 각 계량기 번호, 고객번호, 납부 계좌번호 등록
- **규칙**:
  - 계량기 항목 (수도·전기·가스 각각):
    - 계량기 번호 (텍스트)
    - 고객번호 (텍스트)
  - 계좌번호 항목 (수도·전기·가스·관리비 각각 별도 입력):
    - 은행명 (텍스트)
    - 계좌번호 (텍스트)
    - 예금주 (텍스트)

### 3.4 섹션 4 — 임대차 정보

- **기능**: 세대의 임대차 계약 정보 및 이전 전출자 이력 확인
- **규칙**:
  - 현재 임대차 입력 항목:
    - 보증금 (금액 입력)
    - 월세 (금액 입력)
    - 계약 시작일 (달력 선택)
    - 계약 종료일 (달력 선택)
    - 계약 만료 알림 여부 (Y / N 선택) — Y 선택 시 만료일 전 알림 발송
  - 이전 전출자 정보:
    - 퇴실 처리 시 해당 시점의 입주자 정보가 자동으로 이력에 누적 저장
    - 이력 목록은 퇴실일 내림차순으로 표시 (읽기 전용)
    - 표시 항목: 입주자명 / 입주일 / 퇴실일 / 룸타입

### 3.5 섹션 5 — 시설 정보

- **기능**: 세대 내 시설 현황 기록
- **규칙**:
  - 자유 텍스트 멀티라인 입력란 (시설 항목 자유 기재)
  - 저장 시 다른 섹션과 함께 통합 저장

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 등록 모드 | `/buildings/:id/tenants/new` 진입 | 모든 입력 필드 빈 값으로 초기화 |
| 수정 모드 | `/buildings/:id/tenants/:tenantId` 진입 | 기존 저장 데이터 불러와 각 필드에 표시 |
| 로딩 | 수정 모드 데이터 조회 중 | 각 섹션 로딩 인디케이터 표시 |
| 저장 성공 | 저장 버튼 클릭 후 성공 | "저장되었습니다" 토스트 메시지 → 수정 모드 유지 |
| 저장 실패 | 필수 항목 미입력 | 해당 필드 강조 + 안내 메시지, 페이지 이동 없음 |
| 에러 | 데이터 조회·저장 실패 | "오류가 발생했습니다. 다시 시도해 주세요." + 재시도 버튼 |
| 이탈 확인 | 변경사항 있는 상태에서 목록 이동 시 | "저장하지 않고 나가시겠습니까?" 확인 팝업 |

## 5. 데이터 & 연동

| 입주자 상세 데이터 | 내부 DB (tenant 격리 RLS 적용) | 수정 모드 진입 시 자동 조회 |

| 퇴실 처리 시 이력 저장 | 내부 DB — 입주 이력 테이블 | 퇴실 처리 실행 시 자동 누적 저장 |
