## 1. 목적

관리업체가 시스템을 사용하는 모든 계정을 한 화면에서 등록·관리하는 화면. **관리자 / 직원(내근·현장) / 청소담당자·관리실 직원 등 스태프 / 입주자** 계정을 이 페이지에서 생성·수정·비활성화한다. 각 화면(건물 담당자 지정, 문자 발송 수신처 등)이 참조하는 인물·연락처의 단일 출처(마스터)가 된다.

---

## 2. 권한

| 사용자 | 접근 | 계정 생성 | 계정 수정 | 권한 변경 |
|---|---|---|---|---|
| 마스터 직원 | O | O | O | O (직원 기능별 권한 설정 가능) |
| 직원 | O | O | O | X (다른 직원 권한 변경 불가) |
| 현장직원 | X | X | X | X |

> 직원의 기능별 권한(설정 변경·부과 확정 등 모든 기능)은 **마스터 직원만** 변경할 수 있다.

## 3. UI

### 3.0 상단 필터·액션 영역

- **기능**: 계정 유형 필터 + 검색 + 신규 등록
- **규칙**:
  - 유형 탭·필터: **전체 / 관리자 / 직원 / 스태프 / 입주자**
  - 검색: 이름 / 아이디 / 연락처 텍스트 검색
  - `+ 계정 등록` 버튼: 계정 등록 폼(모달) 열기

### 3.1 계정 목록 테이블

- **기능**: 등록된 계정 목록 조회 및 선택
- **규칙**:
  - 표시 컬럼: 이름 / 유형 / 아이디 / 연락처 / 권한 등급 / 담당 역할 / 상태(활성·비활성)
  - 행 클릭 시 계정 상세·수정 폼 열기
  - 상태 토글로 활성/비활성 전환 (삭제 대신 비활성 처리)

### 3.2 계정 등록·수정 폼

- **기능**: 계정 생성 및 정보 수정
- **규칙**:
  - **공통 입력 항목**: 이름 / 연락처(주·부번호) / 유형 선택
  - **모든 유형에 로그인 계정 발급**: 직원·현장관리자·스태프(청소담당자·관리실 직원)·세입자 모두 아이디·비밀번호 또는 연동 계정을 발급받아 로그인
  - **유형별 추가 항목**:
    - 직원: 아이디 / 비밀번호 / 마스터 여부 / 담당 역할(관리·검침·청소 등) / **기능별 권한 설정**
    - 현장관리자: 아이디 / 비밀번호 / 모바일 전용 표시
    - 스태프(청소담당자·관리실 직원 등): 아이디 / 비밀번호 / 담당 역할 / 소속(청소팀 등)
    - 세입자: 연결 세대(건물·호실) / 카카오 계정 연동 여부 — **생성은 입주자 상세(`tenant-detail.md`)에서 하며(세대 연결 필수), 이 화면에서는 조회·계정 발급/비활성만 처리** (신규 등록 불가, 입주자 상세와 양방향 연동)
  - 필수 항목 미입력 시 저장 불가, 안내 표시
  - `저장` 버튼 클릭 시 계정 생성·수정

### 3.3 기능별 권한 설정 (직원)

- **기능**: 직원 계정별로 사용 가능한 기능을 개별 허용/차단
- **규칙**:
  - 등급 선택이 아닌 **기능 단위 체크리스트**로 허용 범위 지정 (예: 설정 변경 / 부과 확정 / 고지서 발행 / 문자 발송 / 계정 관리 / 미납 관리 등 전 기능)
  - **마스터 직원만** 다른 직원의 기능별 권한을 변경 가능, 일반 직원은 조회만
  - 권한 차단된 기능은 해당 직원의 GNB·버튼에서 비활성/미노출

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 화면 진입 | 전체 계정 목록 표시 |
| 필터·검색 결과 | 유형 필터·검색 적용 | 조건에 맞는 계정만 표시 |
| 결과 없음 | 조건에 맞는 계정 없음 | "조건에 맞는 계정이 없습니다" 안내 |
| 등록·수정 완료 | 저장 성공 | "저장되었습니다" 토스트, 목록 갱신 |
| 에러 | 조회·저장 실패 | "오류가 발생했습니다. 다시 시도해 주세요." + 재시도 버튼 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 계정 목록 | 내부 DB — 계정·직원·입주자 테이블 (tenant 격리 RLS 적용) | 화면 진입 시 자동 조회 |

| 입주자 계정 | 입주자 상세(`tenant-detail.md`) | 입주자 정보와 양방향 연동 |
