## 3. UI

### 3.0 상단 액션 영역

- **기능**: 건물별·전체 AS 접수 현황 필터 + 신규 접수 버튼
- **규칙**:
  - 건물 선택 드롭다운: 담당 건물 필터링
  - `신규 접수` 버튼: 민원 입력 폼 표시

### 3.1 AS 접수 목록

- **기능**: 본인 담당 AS 접수 현황 + 건물별 접수 현황 조회
- **규칙**:
  - 표시 컬럼: 접수일 / 건물명 / 호실명 / 접수내용 요약 / 상태 (미결·완결·보류·반복)
  - 행 탭 시 상세 내용 및 처리 결과 입력 화면으로 이동

### 3.2 민원 접수 폼

- **기능**: 신규 민원 직접 접수
- **규칙**:
  - 입력 항목: 건물·호실 선택 / 접수내용 (텍스트) / 상태 선택
  - 저장 버튼 탭 시 접수 완료

### 3.3 처리 결과 기록

- **기능**: 업무 처리 후 현장에서 처리 결과 기록 및 사진 저장
- **규칙**:
  - 입력 항목: 처리 결과 (텍스트) / 사진 업로드
  - 사진 업로드: 카메라 촬영 또는 갤러리 선택, 자동 압축 적용
  - 상태 변경: 미결 → 완결·보류·반복 중 선택
  - 저장 버튼 탭 시 처리 결과 저장

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 목록 | 화면 진입 | 담당 AS 전체 목록 표시 |
| 빈 상태 | 접수 건 없음 | "접수된 민원이 없습니다" 안내 |
| 저장 완료 | 접수·처리 결과 저장 성공 | "저장되었습니다" 토스트 |
| 에러 | 조회·저장 실패 | "오류가 발생했습니다." + 재시도 버튼 |

---

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 |
|---|---|---|
| AS 접수 목록 | 내부 DB — 민원 테이블 (RLS 적용) | 화면 진입 시 자동 조회 |
| 사진 파일 | 파일 스토리지 (S3 or 동등) | 업로드 시 즉시 저장, 자동 압축 |
| 처리 결과 저장 | 내부 DB — 민원 테이블 | 저장 버튼 탭 시 트리거 |
