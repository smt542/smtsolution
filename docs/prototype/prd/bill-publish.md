## 3. UI

### 3.0 상단 액션 영역

- **기능**: 건물 선택 + 발행 유형 선택 + 주요 액션 버튼 제공
- **규칙**:
  - 건물 선택 드롭다운: 관리 중인 건물 목록, 선택 시 해당 건물 세대 목록 로드
  - 발행 유형 선택: 지로 / A4 / 카톡 / 팩스 (복수 선택 가능)
  - 그룹 선택 드롭다운: 건물별 그룹 선택 (부과기간이 다른 건물 그룹 구분)
  - 세대 표기 방식 선택: **코드출력 / 이름출력** 선택 (고지서·출력물의 세대 표시를 호실코드로 할지 입주자명으로 할지 선택)
  - `조정명세서 출력` 버튼: 조정명세서 출력 — **그룹별 분리 출력** 지원 (2개 그룹의 납기일·출금신청일이 상이한 경우 대응)
  - `자동이체 세대 출력` 버튼: 자동이체 등록 세대 목록 출력 — **그룹별 분리 출력** 지원 (그룹별 출금신청일 상이한 경우 대응)

### 3.1 세대 목록 테이블

- **기능**: 건물 내 전체 세대 목록 표시 및 발행 대상 선택
- **규칙**:
  - 표시 컬럼: 호실명 / 입주자명 / 고지서 유형 / 그룹 / 자동이체 여부 / 발송 상태
  - 자동이체 세대: 고지서에 "자동이체" 표시, 카톡 고지서에도 자동이체 여부 표시
  - 전체 선택 체크박스 + 개별 세대 체크박스로 발행 대상 선택
  - 일괄 발행: 건물 전체 세대 선택 후 발행 버튼 클릭
  - 개별 발행: 특정 세대 선택 후 발행 버튼 클릭

### 3.2 지로·A4 고지서 출력

- **기능**: 선택된 세대의 지로 또는 A4 고지서 출력
- **규칙**:
  - 고지서 내 자동 포함 항목:
    - QR코드 (카카오 고지서 신청용, 별도 설정 없이 자동 포함)
    - 프로그램 회사명 (고지서 하단에 작게 인쇄)
    - 자동이체 세대 표시
  - 지로 납부 세대: 지로 고지서 발행 (현행 유지)
  - A4 고지서: 일반 프린터 출력용

### 3.3 카톡 고지서 발송

- **기능**: 선택된 세대에 카카오 알림톡으로 고지서 발송 (공용 발송 모듈 호출)
- **규칙**:
  - `카톡 고지서 발송` 버튼 클릭 시 **공용 발송 모듈(`messaging.md`)을 수신처=선택 세대(그룹/개별, 주·부번호)·채널=알림톡·템플릿=고지서 프리셋으로 호출**
  - 즉시 발송 / 예약 발송(날짜·시간, 취소 가능), 그룹별·개별 발송, 주·부번호 발송 규칙은 공용 모듈을 따름
  - NCP(네이버 클라우드 플랫폼) 알림톡 API 연동

### 3.4 팩스 고지서 발송

- **기능**: 선택된 세대에 팩스로 고지서 발송
- **규칙**:
  - 세대별 팩스번호 등록 필요 (입주자 정보에서 관리)
  - 선택된 세대 팩스 일괄 발송

### 3.5 출력 옵션 설정 (단수·납기일)

- **기능**: 고지서 출력 화면에서 세대별 단수 표기·해지 및 납기일을 직접 조정
- **규칙**:
  - **단수 표기 설정**: 세대별로 단수(단전·단수 예고) 표기 여부를 고지서 출력 시점에 개별 설정 가능
  - **단수 해지 설정**: 단수 표기된 세대를 해당 회차 고지서에 한해 단수 표기 해제 가능
  - **납기일 자유 변경**: 출력 화면에서 해당 발행 건 납기일을 기본값과 무관하게 자유롭게 변경 후 출력

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 건물 미선택 | "건물을 선택해 주세요" 안내, 테이블 비표시 |
| 로딩 | 건물 선택 후 세대 목록 조회 중 | 테이블 영역 로딩 인디케이터 |
| 발행 대기 | 세대 목록 로드 완료 | 세대 목록 표시, 발행 대상 선택 대기 |
| 발송 완료 | 카톡·팩스 발송 성공 | "발송이 완료되었습니다" 토스트 메시지, 발송 상태 컬럼 업데이트 |
| 예약 등록 완료 | 예약 발송 설정 완료 | "예약이 등록되었습니다 (YYYY-MM-DD HH:MM)" 토스트 메시지 |
| 빈 상태 | 해당 건물 세대 없음 | "등록된 세대가 없습니다" 안내 |
| 에러 | 발송 실패 | "발송에 실패했습니다. 다시 시도해 주세요." + 재시도 버튼 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 건물·세대 목록 | 내부 DB (tenant 격리 RLS 적용) | 건물 선택 시 자동 조회 |
| 부과 확정 데이터 | 내부 DB — 부과 확정 테이블 | 고지서 발행 시 참조 |
| 카톡 고지서 발송 | 공용 발송 모듈(`messaging.md`) → NCP 알림톡 API | `카톡 고지서 발송` 버튼 클릭 시 프리셋 전달·호출 |
| 팩스 발송 | 팩스 연동 서비스 | 발송 버튼 클릭 시 트리거 |
| 조정명세서·자동이체 출력 | 서버사이드 생성 | 버튼 클릭 시 트리거 |
