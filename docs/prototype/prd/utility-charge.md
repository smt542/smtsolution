## 1. 목적

관리업체 직원이 건물별로 수도·전기·가스 지침값을 일괄 입력하고, 세대별 요금을 자동 계산·부과하는 화면. 지침 입력과 부과 계산을 하나의 화면에서 처리한다.

## 3. UI

### 3.0 상단 액션 영역

- **기능**: 건물 선택 + 탭(수도·전기·가스) 전환 + 주요 액션 버튼 제공
- **규칙**:
  - 건물 선택 드롭다운: 관리 중인 건물 목록 표시, 선택 시 해당 건물의 전체 세대 지침 목록 로드
  - 탭: **수도 / 전기 / 가스** 3개 탭으로 구분, 탭 전환 시 해당 유형의 지침 목록 표시
  - `부과 계산` 버튼: 현재 탭의 당월 지침값 기준으로 전체 세대 요금 자동 계산
  - `검침대장 다운` 버튼: 현재 탭(수도·전기·가스) 기준 검침대장 `.xlsx` 다운로드
    - 파일명: `[건물명]_[유형]_검침대장_YYYYMM.xlsx`
  - `6개월 이력` 버튼: 최근 6개월 부과액·단가 증감 팝업 표시

### 3.1 세대별 지침 입력 테이블

- **기능**: 건물 내 전체 세대의 당월 지침값을 일괄 입력하고, 자동 계산된 요금 확인
- **규칙**:
  - 표시 컬럼:
    - 호실명
    - 입주자명
    - 전월 지침값 (자동 불러옴, 읽기 전용)
    - 당월 지침값 (직접 입력, 필수)
    - 사용량 (당월 - 전월, 자동 계산, 읽기 전용)
    - 자동 계산 요금 (부과 계산 버튼 클릭 후 표시, 읽기 전용)
    - 수동 입력 요금 (자동 계산값 override 가능, 선택 입력)
    - 적요 (텍스트 입력, 선택)
    - 수도부과처리일자 (날짜, 자동 입력 — 부과 계산 실행일 기준)
  - 전월 지침값: 직전 월 저장된 지침값 자동 불러와 표시
  - 수동 입력 요금 입력 시 자동 계산 요금보다 수동 입력값이 우선 적용
  - 공실 세대는 지침 입력란 비활성화, 회색으로 표시
  - 수도 할인 세대 (수급자·다자녀) 자동 할인 적용:
    - 할인 금액은 입주자 정보에서 사전 등록된 값 사용
    - 할인 적용 세대는 별도 표시 (예: 할인 뱃지)
  - 수도계량기 없는 상가 세대: 매월 고정 사용량(톤) 자동 적용
    - 고정값은 입주자 설정에서 사전 지정
  - 고객번호별 층별 요금 부과: 건물 설정의 고객번호 구분에 따라 층별 단가 분리 적용
  - 최근 한 달 전후 신규 입주 세대는 파란색으로 강조 표시
    - 기준 날짜는 상단에서 직접 변경 가능

### 3.2 6개월 이력 팝업

- **기능**: 선택한 세대의 최근 6개월 부과액·증감·단가·단가증감 이력 조회
- **규칙**:
  - 세대 행 클릭 또는 `6개월 이력` 버튼 클릭 시 팝업 표시
  - 표시 항목: 월 / 부과액 / 전월 대비 증감 / 단가 / 단가 증감
  - 최근 6개월치 데이터 표 형태로 표시
  - 팝업 닫기 버튼으로 닫기

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 건물 미선택 | "건물을 선택해 주세요" 안내 문구, 테이블 비표시 |
| 로딩 | 건물 선택 후 세대 목록 조회 중 | 테이블 영역 로딩 인디케이터 |
| 입력 대기 | 세대 목록 로드 완료 | 전월 지침값 자동 표시, 당월 지침값 입력 대기 |
| 계산 완료 | `부과 계산` 버튼 클릭 후 | 자동 계산 요금 컬럼 값 표시, 수도부과처리일자 자동 입력 |
| 빈 상태 | 해당 건물 세대 없음 | "등록된 세대가 없습니다" 안내 |
| 에러 | 데이터 조회·계산 실패 | "오류가 발생했습니다. 다시 시도해 주세요." + 재시도 버튼 |
