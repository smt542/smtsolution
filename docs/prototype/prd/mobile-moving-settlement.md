## 1. 목적

현장관리자가 현장에서 퇴실 세대의 이사정산 내역을 작성하고 정산금을 계산·저장하는 화면. PC의 이사정산 화면과 동일한 데이터를 사용하되, 현장관리자는 `계산+저장` 버튼만 사용 가능하다.

---

## 2. 권한

| 사용자 | 접근 | 사용 가능 버튼 |
|---|---|---|
| 현장직원 | O | `계산+저장` 만 |
| 관리자·직원 | X | PC 웹에서 처리 |

---

## 3. UI

### 3.0 세대 선택 영역

- **기능**: 이사정산 대상 세대 선택
- **규칙**:
  - 건물 선택 드롭다운 → 호실 선택 드롭다운

### 3.1 이사정산 입력 영역

- **기능**: 퇴실 세대 정산 내역 입력 (PC와 동일한 항목)
- **규칙**:
  - 입력 항목: 퇴실일자 / 지침값 / 수리비 / 기타 항목 (PC와 동일)
  - 정산금 입금 계좌 자동 표시

### 3.2 하단 액션 버튼

- **기능**: 이사정산 처리 버튼
- **규칙**:
  - `계산+저장` 버튼만 활성화
  - 나머지 버튼 (중도퇴실 / 정산완료+공실 / 출력 / 빈양식) 비활성화 또는 미표시
  - 저장 후 퇴실자·건물주에게 정산내역서 문자 전송 버튼 제공
    - `정산내역서 문자 전송` 버튼: **공용 발송 모듈(`messaging.md`) 호출** — 수신처=퇴실자·건물주, 템플릿=정산내역서 프리셋 상태로 발송 (현장 캡처 후 전송 방식도 병행 안내)

---

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 세대 미선택 | "건물과 호실을 선택해 주세요" 안내 |
| 입력 대기 | 세대 선택 완료 | 기존 저장 데이터 표시, 입력 대기 |
| 저장 완료 | `계산+저장` 클릭 후 성공 | "저장되었습니다" 토스트 |
| 에러 | 조회·저장 실패 | "오류가 발생했습니다." + 재시도 버튼 |

---

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 |
|---|---|---|
| 세대 정보·정산 데이터 | 내부 DB (RLS 적용) | 세대 선택 시 자동 조회 |
| 이사정산 저장 | 내부 DB — 이사정산 테이블 | `계산+저장` 탭 시 트리거 |
| 정산내역서 문자 전송 | 공용 발송 모듈(`messaging.md`) → NCP SMS API | `정산내역서 문자 전송` 버튼 클릭 시 프리셋 전달·호출 |
