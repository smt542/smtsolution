## 3. UI

### 3.0 상단 검색·액션 영역

- **기능**: 수납현황 검색 + AS접수현황 팝업 열기 버튼
- **규칙**:
  - 검색 조건: 금액 / 이름 / 건물명 텍스트 검색 (복수 조건 동시 입력 가능)
  - `AS접수현황` 버튼: 클릭 시 AS접수현황 팝업 새 창으로 표시

### 3.1 수납현황 테이블 (상단)

- **기능**: 세대별 관리비 수납 현황 조회 및 문자 발송
- **규칙**:
  - 표시 컬럼: 건물명 / 호실명 / 입주자명 / 부과금액 / 수납금액 / 미납금액 / 납기일 / 수납상태
  - 검색 조건 적용 시 해당 조건으로 필터링된 목록 표시
  - 세대 행 선택 후 `고지서 문자 전송` 버튼: **공용 발송 모듈(`messaging.md`) 호출** — 수신처=선택 세대 세입자, 템플릿=고지서 프리셋 상태로 발송 화면 오픈
  - 빌라별 월별 총부과금액·관리비 항목별 부과금액·수납현황 요약 영역 제공
  - 미납내역·수납내역 조회·출력 버튼 제공
  - 호실별 관리비 수납 명세서 출력 (날짜 지정·항목별 확인·합계금액 표시)
  - 영수증 출력 버튼 제공 (인쇄=브라우저 인쇄 대화상자로 A4 영수증 출력)
  - **지로수납처리**: 은행에서 받은 지로 수납 파일(`txt`) 업로드 후 처리
  - **지로수납원장**: 처리 완료된 지로 내역 원장 — 조회일 기간 + 에러(전체/정상/이중수납) 필터, 지로일자별 소계, 총건수·총 수납액·총 수수료·총 실입금액 합계. 이중수납=동일 세대·금액·일자 중복 자동 감지
  - **지로처리일자 확인**: 월 달력에 처리일자별 지로 수납 금액 + 수납일자별 막대그래프
  - **은행 입금내역 업로드**: 입금내역 엑셀(`xlsx·xls·csv`) 드롭존 업로드 → 열 매핑 → 매칭 미리보기(미납 기준 자동 매칭·차액·중복 표시, 미매칭 건 수동 세대 지정) → 일괄 확정

### 3.2 민원접수 영역 (하단)

- **기능**: 세입자 민원 접수 및 처리 현황 관리
- **규칙**:
  - 상단 필터: 미결 / 완결 / 보류 / 반복 필터 버튼 제공 (복수 선택 가능)
  - 민원 목록 표시 컬럼: 접수일 / 건물명 / 호실명 / 입주자명 / 접수내용 / 상태 / 처리결과
  - 민원 상태값: 미결 / 완결 / 보류 / 반복
  - 신규 민원 접수(`A/S 접수 추가`) 버튼: 단일 플랫 폼 표시
    - 입력 항목: 건물* / 호수* / 접수자 / 담당자 / 접수일시* / 유형* / 입주자 전화번호 / 접수내용* / 처리결과(상태) / 시행일자 / 시간 / 처리결과 내용
    - 시행일자·시간·처리결과 내용은 해당 민원의 **최신 처리이력 1건**으로 저장(기존 이력 데이터는 보존)
  - 민원 행 클릭 시 `A/S 접수 상세`(추가와 동일 폼)로 열람·수정: **삭제 / 확인문자 보내기 / 저장**
  - `확인문자 보내기` 버튼: **공용 발송 모듈(`messaging.md`) 호출** — 수신처=입주자, 템플릿=민원·AS 처리 안내 프리셋(알림톡 자동 라우팅·미동의 시 SMS 전환)

### 3.3 AS접수현황 팝업

- **기능**: 별도 팝업 새 창으로 AS 접수 현황 조회
- **규칙**:
  - 팝업 내 필터: 건물별 / 날짜별 조회 가능
  - 표시 컬럼: 접수일 / 건물명 / 호실명 / 접수내용 / 상태 / 처리결과
  - 엑셀 다운로드 버튼: 현재 조회 결과 `.xlsx` 다운로드
    - 파일명: `AS접수현황_YYYYMMDD.xlsx`
  - 건물별 월별 AS 현황 출력 버튼 제공
  - 호실 **더블클릭** → 팝업 닫힘 + 해당 호실의 수납관리 페이지(`/receipts`)로 이동 및 해당 세대 자동 검색

### 3.4 진입 알림 모달 (화면 진입 시)

- **기능**: 수납관리 화면 진입 시, 담당자가 놓치기 쉬운 세대를 팝업으로 안내한다. 두 종류를 순차 표시한다.
- **규칙**:
  - **오늘 입주 예정 세대**: `입주예정일(move_in_date)`이 오늘인 입주중 세대 목록. 카드 = `건물명 호실 · 세대주` + `입주예정 YYYY.MM.DD`.
  - **임대 만료 예정 세대**: `임대 만료일(end_date)`이 오늘부터 30일 이내인 입주중 세대 목록. 카드 = `건물명 호실 · 세대주` + `만료예정 YYYY.MM.DD · D-N` + `만료 임박` 배지. 만료일이 가까운 순 정렬.
  - **표시 순서**: 입주 예정 → (닫은 뒤) 임대 만료 예정. 해당 목록이 비어 있으면 그 모달은 건너뛴다.
  - **닫기(X·닫기 버튼)**: 이번 진입에 한해 닫음(같은 화면 재진입·새로고침 시 다시 표시).
  - **오늘 그만보기**: 오늘 하루 해당 알림을 표시하지 않음(브라우저 localStorage, 조직·계정별 키. 자정이 지나면 다시 표시).
  - **알림 설정 ›**: 알림 설정 화면으로 이동.
  - 대시보드(`/staff`)의 입주예정 알림과 별개로 동작한다(중복 노출 허용).
