## 3. UI

### 3.0 상단 액션 영역

- **기능**: 건물·세대 검색 + 주요 액션 버튼 제공
- **규칙**:
  - 건물 선택 드롭다운 + 세대 검색 (이름·호실명 텍스트 검색)
  - `엑셀 업로드` 버튼: 은행 입금내역 엑셀 파일 업로드 → 자동 매칭 수납 처리
  - `자동이체 세대 다운` 버튼: 자동이체 등록 세대 목록 `.xlsx` 다운로드
    - 파일명: `자동이체세대목록_YYYYMMDD.xlsx`

### 3.1 수납 처리 테이블

- **기능**: 세대별 수납 처리 (수납·원금·취소·분할) 및 현황 조회
- **규칙**:
  - 표시 컬럼: 호실명 / 입주자명 / 부과금액 / 수납금액 / 미납금액 / 납기일 / 비고 / 수납상태
  - 납기일 표시: 해당 세대 납기일 명시
  - 비고란: 수납 처리 시 메모 입력 가능
  - 수납 처리 유형 (행 선택 후 처리 버튼 클릭):
    - **수납**: 전액 수납 처리
    - **원금**: 원금만 수납 처리 (연체료 제외)
    - **취소**: 기존 수납 취소
    - **분할**: 금액 분할 입력 후 부분 수납 처리
  - 자동이체 세대: 수납 처리 시 고지서·카톡 고지서에 "자동이체" 표시

### 3.2 지로 수납 처리 영역

- **기능**: 지로 납부 세대 수납 처리 및 원장 조회
- **규칙**:
  - 지로 수납 처리: 지로 납부 세대 선택 후 수납 처리
  - 지로 수납 원장 보기: 지로 처리 이력 조회
  - 지로 처리일자 확인 가능

### 3.3 엑셀 자동 매칭 수납 처리

- **기능**: 은행 입금내역 엑셀 업로드 후 자동 매칭으로 수납 처리
- **규칙**:
  - 엑셀 업로드 시 자동 매칭 순서:
    1. 고객번호 매칭
    2. 이름 매칭
    3. 금액 매칭
  - 3단계 모두 매칭된 건 → 자동 수납 처리
  - 미매칭 건 → 목록에 별도 표시, 수동 처리 대기
  - 미매칭 건 수동 처리: 해당 행에서 직접 세대 선택 후 수납 처리

### 3.4 자동이체 세대 관리 (효성CMS)

- **기능**: 자동이체 등록 세대 관리 및 효성CMS 대량청구 생성을 위한 엑셀 연동
- **규칙**:
  - 자동이체 세대 필터링 목록 표시
  - **효성CMS 자동이체 워크플로우**:
    1. 세대별 효성CMS 회원번호 등록
    2. `자동이체 세대 다운` 버튼 클릭 시 회원번호 포함 목록 엑셀 다운로드
    3. 회원번호 **오름차순 정렬** 상태로 출력 (효성CMS 업로드 포맷 정렬과 일치)
    4. 해당 엑셀에 청구금액을 붙여넣어 효성CMS 대량청구 파일 생성 (외부 효성CMS 업로드용)
  - CMS API 직접 연동은 범위에서 제외, 엑셀 다운·붙여넣기 기반으로 대량청구 생성

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 화면 진입 | 전체 세대 수납 현황 목록 표시 |
| 엑셀 업로드 중 | 파일 업로드 후 매칭 처리 중 | 로딩 인디케이터 + "매칭 처리 중입니다" 안내 |
| 매칭 완료 | 자동 매칭 처리 완료 | 자동 수납 처리 건수 + 미매칭 건수 결과 표시 |
| 수납 처리 완료 | 수납 버튼 클릭 후 성공 | "수납 처리되었습니다" 토스트 메시지 |
| 에러 | 처리 실패 | "오류가 발생했습니다. 다시 시도해 주세요." + 재시도 버튼 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 수납 현황 데이터 | 내부 DB (tenant 격리 RLS 적용) | 화면 진입 시 자동 조회 |
| 엑셀 업로드 자동 매칭 | 내부 매칭 로직 | 엑셀 업로드 시 트리거 |
| 수납 처리 저장 | 내부 DB — 수납 테이블 | 수납 처리 버튼 클릭 시 트리거 |
| 자동이체 세대 목록 다운 | 서버사이드 생성 | `자동이체 세대 다운` 버튼 클릭 시 트리거 |
| 지로 수납 원장 | 내부 DB — 지로 수납 테이블 | 지로 원장 보기 버튼 클릭 시 조회 |
