## 1. 목적

현장관리자가 현장에서 수도·전기·가스 지침값을 세대별로 직접 입력하고, 이상 사용량을 자동 검증받는 화면.

---

## 2. 권한

| 사용자 | 접근 | 지침 입력 |
|---|---|---|
| 현장직원 | O | O |
| 관리자·직원 | X | X (PC 웹에서 처리) |

---

## 3. UI

### 3.0 상단 액션 영역

- **기능**: 건물 선택 + 탭 전환
- **규칙**:
  - 건물 선택 드롭다운: 담당 건물 목록 표시, 선택 시 전체 세대 지침 목록 로드
  - 탭: 수도 / 전기 / 가스 3개 탭 (PC와 동일)

### 3.1 세대별 지침 입력 목록

- **기능**: 건물 내 전체 세대의 당월 지침값 입력
- **규칙**:
  - 표시 항목: 호실명 / 입주자명 / 입주일 / 전월 지침값 / 당월 지침값 입력란
  - 입주일 표시: 공실이었다가 최근 입주한 세대 확인용
  - 전월 지침값: 자동 표시 (수정 불가)
  - 최근 3개월 검침 이력 확인 버튼: 탭 시 해당 세대의 최근 3개월 지침 이력 표시 (계량기 고장·누수·검침 오류 판단용)
  - 당월 지침값 입력 후 저장 시 이상 사용량 자동 검증:
    - 검증 기준: 관리자가 셋업에서 설정한 기준값 초과 시 경고
    - 이상 감지 시: "이상 사용량이 감지되었습니다. 다시 확인해 주세요." 경고 팝업 표시
    - 경고 팝업 후 수정 재입력 요청 (저장 불가)
    - 재입력 후 정상 범위 확인 시 저장 가능
  - `저장` 버튼: 입력된 전체 세대 지침값 일괄 저장

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 초기 | 건물 미선택 | "건물을 선택해 주세요" 안내 |
| 입력 대기 | 건물 선택 후 | 전체 세대 목록·전월 지침값 표시 |
| 경고 | 이상 사용량 감지 | 경고 팝업 표시, 수정 재입력 요청 |
| 저장 완료 | 저장 성공 | "저장되었습니다" 토스트 메시지 |
| 에러 | 조회·저장 실패 | "오류가 발생했습니다." + 재시도 버튼 |

---

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 |
|---|---|---|
| 담당 건물·세대 목록 | 내부 DB (RLS 적용) | 화면 진입 시 조회 |
| 전월 지침값·3개월 이력 | 내부 DB — 지침 이력 테이블 | 건물 선택 시 자동 조회 |
| 이상 사용량 기준값 | 내부 DB — 셋업 설정 테이블 | 저장 시 자동 참조 |
| 지침값 저장 | 내부 DB — 지침 이력 테이블 | 저장 버튼 클릭 시 트리거 |
