## 1. 목적

관리업체 직원이 등록 건물을 조회하고, 선택한 건물의 호수·입주민을 같은 화면에서 관리하며, 건물 단위 입주자카드와 관리비 부과내역서를 미리보고 출력하는 진입 허브.

## 3. UI

### 3.0 상단 액션 영역

- **기능**: 화면 제목, `입주자카드 및 부과내역 출력`, `+ 건물 등록`을 제공한다.
- **규칙**:
  - `+ 건물 등록` → `/staff/buildings/new`.
  - 출력 버튼은 건물 선택 전에도 열 수 있다. 선택 전에는 모달의 안내 상태를 노출한다.
  - 화면에서 건물을 이미 선택했다면 출력 모달도 같은 건물을 초기 선택값으로 사용한다.

### 3.1 검색·필터와 건물 목록

- **기능**: 건물명·주소 검색 및 관리·검침·청소 담당자 필터.
- **규칙**:
  - 검색·필터 결과는 목록과 엑셀 다운로드에 함께 적용한다.
  - 컬럼: 코드 · 건물명 · 주소 · 관리담당 · 검침담당 · 청소담당 · 총 세대 · 입주 세대 · 동작.
  - 행 1회 클릭 → 건물 선택 및 하단 호수·입주민 로드.
  - 행 더블클릭 또는 `상세` → `/staff/buildings/:id`.
  - 페이지당 10/20/50건, 기본 20건.

### 3.2 호수·입주민 관리

- **기능**: 선택 건물의 세대 목록 표시 및 등록·상세 진입.
- **규칙**:
  - 건물 미선택 → `건물을 선택해 주세요` 안내.
  - 선택 시 컬럼: 호실 · 입주자명 · 연락처 · 룸 타입 · 인원 · 입주일 · 공실 · 연체.
  - `+ 호수·입주민 등록` → `/staff/buildings/:id/tenants/new`.
  - 행 더블클릭 → `/staff/buildings/:id/tenants/:unitId`.

### 3.3 입주자카드 및 부과내역 출력 모달

- **기능**: 건물을 선택하고 연·월 기준의 입주자카드와 관리비 부과내역서를 함께 미리보고 출력한다.
- **규칙**:
  - 좌측: 건물명·코드 검색 + 건물 목록. 단일 선택.
  - 우측 상단: 출력 기준 연도·월.
  - **건물 미선택 상태**: `출력할 건물을 선택해 주세요` 안내, `출력하기` 비활성.
  - **건물 선택 상태**: 선택 건물 강조, 입주자카드와 관리비 부과내역서 A4 미리보기 2장을 나란히 표시, 세대 수 표시, `출력하기` 활성.
  - 관리비 부과내역서의 부과금액은 선택 연·월의 세대별 확정 합계를 표시한다. 미확정 세대는 `-`로 표시한다.
  - 세대·관리비 자료를 불러오는 동안 미리보기 로딩 상태를 노출하고 `출력하기`를 비활성화한다.
  - 모달 내 건물 선택은 본 화면의 선택 건물과 동기화한다.
  - `취소`, 닫기, 배경 클릭, Esc → 모달 닫기.
  - `출력하기` → 두 문서를 함께 인쇄.

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 빈 상태 | 등록 건물 0개 | 건물 없음 안내 |
| 결과 없음 | 검색·필터 결과 0건 | 조건에 맞는 건물 없음 |
| 건물 미선택 | 건물 행 선택 전 | 하단 세대 안내 + 출력 모달 안내 상태 |
| 건물 선택 | 건물 행 또는 모달 목록 선택 | 행 강조 + 세대 목록/문서 미리보기 |
| 로딩 | 건물·세대 조회 중 | 해당 영역 로딩 |
| 에러 | 건물·세대 조회 실패 | 영역별 실패 안내 |
