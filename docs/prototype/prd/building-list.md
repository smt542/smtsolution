## 1. 목적

관리업체 직원이 등록된 건물 전체를 한눈에 파악하고, 원하는 건물로 빠르게 진입하거나 신규 건물을 등록하기 위한 진입점 화면.

---

## 2. 권한

| 사용자 | 접근 | 건물 등록 | 목록 조회 | 엑셀 다운 |
|---|---|---|---|---|
| 관리자 | O | O | O | O |
| 직원 | O | O | O | O |
| 현장직원 | X | X | X | X |

> 현장직원은 모바일 전용 계정으로 이 화면에 접근 불가.

---

## 3. UI

### 3.0 상단 액션 영역

- **기능**: 화면 제목 표시 + 신규 건물 등록 버튼 + 엑셀 다운 버튼
- **규칙**:
  - `건물 등록` 버튼 클릭 → `/buildings/new` 로 이동 (건물 등록 화면)
  - `엑셀 다운` 버튼 클릭 → 현재 필터 조건이 적용된 목록을 `.xlsx` 로 다운로드
    - 다운로드 파일명: `건물목록_YYYYMMDD.xlsx`
    - 포함 컬럼: 건물명, 주소, 담당자(관리·검침·청소), 총 세대수, 입주 세대수

### 3.1 필터 영역

- **기능**: 담당자 유형별로 건물 목록을 필터링
- **규칙**:
  - 필터 조건: **관리담당자 / 검침담당자 / 청소담당자** (각각 드롭다운 선택)
  - 필터 적용 시 목록과 엑셀 다운 모두 필터 결과 기준으로 동작
  - 검침담당자 필터 적용 시 엑셀 다운은 **검침일자 오름차순** 정렬로 출력
  - 필터 초기화 버튼으로 전체 목록으로 복귀

### 3.2 건물 목록 테이블

- **기능**: 등록된 건물을 행(row) 단위로 표시. 행 더블클릭 시 건물 상세 화면으로 이동
- **규칙**:
  - 표시 컬럼: 건물명 / 주소 / 관리담당자 / 검침담당자 / 청소담당자 / 총 세대수 / 입주 세대수
  - 행 **더블클릭** → `/buildings/:id` (건물 상세·등록 화면)으로 이동
  - 기본 정렬: 등록일 최신순
  - 페이지네이션: 페이지 번호 방식, 페이지당 노출 건수 드롭다운 선택 (10 / 20 / 50건)

## 4. 화면 상태

| 상태 | 발생 조건 | 노출 / 동작 |
|---|---|---|
| 빈 상태 (empty) | 등록된 건물이 0개 | "등록된 건물이 없습니다" 안내 문구 + `건물 등록` 버튼 노출 |
| 로딩 | 목록 조회 중 | 테이블 영역 로딩 인디케이터 표시 |
| 성공 | 건물 1개 이상 존재 | 목록 정상 표시 |
| 결과 없음 | 필터 조건에 맞는 건물 0건 | "조건에 맞는 건물이 없습니다" 안내 문구 + 필터 초기화 버튼 |
| 에러 | 목록 조회 실패 | "데이터를 불러오지 못했습니다. 다시 시도해 주세요." + 재시도 버튼 |

## 5. 데이터 & 연동

| 항목 | 출처 / 연동 | 트리거 · 비고 |
|---|---|---|
| 건물 목록 | 내부 DB (tenant 격리 RLS 적용) | 화면 진입 시 자동 조회 |
| 담당자 목록 (필터용) | 내부 DB — 직원 테이블 | 필터 드롭다운 오픈 시 조회 |
| 엑셀 다운로드 | 서버사이드 생성 | 버튼 클릭 시 트리거 |
