네이티브 <select> 사용 금지. 셀렉터는 버튼(닫힌 상태)과 드롭리스트(열린 목록)를 항상 함께 디자인 시스템 UI로 만들고, 작업 후 열린 목록까지 확인합니다.
마이너스 값은 var(--red). 증감·차액·감면액 등 모든 수치에 적용하고 양수에는 색을 쓰지 않습니다.
Primary 컬러는 강조가 꼭 필요한 곳에만. 카드·패널·보조 버튼은 흰 배경 + --line.
모달 버튼은 h40 · r11 · 13.5/700 · gap 7로 페이지 버튼과 동일.
모든 화면은 동일한 :root 토큰 블록과 .hf-* 셸 클래스를 복사해 사용합니다. 새 색·새 반경을 즉석으로 만들지 않습니다.
